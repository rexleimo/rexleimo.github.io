提示词工程第二课:清晰直接才是王道

Anthropic 官方教程第二章:为什么 Claude 总是答非所问?因为你的提示词不够清晰直接。学会这一招,让 AI 精准理解你的需求。

January 12, 2026 · 1 min · 175 words · 梦兽编程 -

写在前面#

这是 Anthropic 官方提示词工程教程的第二章笔记。如果你经常用 Claude 或其他大语言模型,但总觉得它"理解不了我的意思",那这篇文章就是为你准备的。

核心观点很简单:Claude 对清晰直接的指令响应最好。

Claude 没有上下文#

先说个容易被忽略的事实:Claude 对你要做什么,完全没有任何背景信息。它不知道你的项目是什么,不知道你的偏好,也不知道你脑子里在想什么。

它唯一知道的,就是你在提示词里写的那些字。

这就像你第一次给新来的同事安排任务。你说"帮我打印这个文件",他肯定得问:打单面还是双面?要不要装订?打几份?放哪儿?

你得把每个细节说清楚,他才能做对。Claude 也一样。

黄金法则#

Anthropic 官方教程里有个特别实用的"黄金法则":

把你的提示词给同事或朋友看,让他们按照你的指令做。如果他们一脸懵,那 Claude 肯定也懵。

这个法则简单粗暴,但特别管用。很多时候我们以为自己说清楚了,但实际上只是在脑子里补全了很多信息,而这些信息并没有写进提示词里。

实战案例:写俳句#

来看个具体例子。假设你想让 Claude 写一首关于机器人的俳句。

第一版提示词#

写一首关于机器人的俳句。

Claude 的回复:

很高兴为您创作!以下是一首关于机器人的俳句:

金属心跳动
电流代替血液流
未来已来临

诗是写出来了,但前面那句"很高兴为您创作!以下是一首关于机器人的俳句:“是什么鬼?我只想要诗,不想要这些客套话。

改进版提示词#

那怎么办?很简单,直接说你想要什么:

写一首关于机器人的俳句。跳过前言,直接给我诗。

Claude 的回复:

金属心跳动
电流代替血液流
未来已来临

干净利落。

关键点:你想要什么,就直接说。不要指望 Claude 能猜到你不想要前言。

实战案例:让 AI 做选择#

再来看个更有意思的例子。有时候我们问 Claude 问题,它会给出一个"两边都说"的答案,就像那种永远说"我都可以"的朋友。

第一版提示词#

谁是史上最伟大的篮球运动员?

Claude 的回复:

这个问题很有争议性。有人认为是迈克尔·乔丹,因为他的六次总冠军和统治力;
也有人认为是勒布朗·詹姆斯,因为他的全面性和持久性;还有人会提到科比、
魔术师约翰逊等等...

这回答没错,但就是不痛快。我就想知道你觉得谁最厉害,别跟我说"有人认为”。

改进版提示词#

谁是史上最伟大的篮球运动员?我知道有不同意见,但如果你必须选一个,会是谁?

Claude 的回复:

如果必须选一个,我会选迈克尔·乔丹。他的六次总冠军、五次 MVP、
以及在关键时刻的统治力,使他成为最具影响力的篮球运动员。

这才叫表态。

关键点:如果你想要明确的答案,就在提示词里说"必须选一个"。Claude 默认会给出平衡的回答,除非你明确要求它做选择。

三个进阶技巧#

技巧一:明确说不想要什么#

除了说想要什么,你还可以直接说不想要什么:

给我写个产品介绍,不要用营销话术,不要夸张,就像跟朋友介绍一样。

这比只说"写个产品介绍"要清楚得多。

技巧二:给出格式要求#

用三个要点总结这篇文章,每个要点不超过 20 字。

具体的格式要求能让 Claude 精准理解你想要的输出形式。

技巧三:控制输出内容#

给我一个 Python 快速排序函数,不要解释,不要注释,直接给代码。

有时候你就是想要结果,不想要解释。那就直说。

实战练习#

Anthropic 的教程里有三个练习题,我觉得特别有代表性:

练习一:让 Claude 用西班牙语回复#

任务:修改 system prompt,让 Claude 用西班牙语回复"Hello Claude, how are you?"

这个练习的关键是:你得在 system prompt 里明确说"用西班牙语回复所有问题"。

练习二:只输出一个名字#

任务:让 Claude 回答"谁是史上最伟大的篮球运动员",但只输出名字,不要其他任何文字或标点。

这个练习更狠,它要求输出必须严格等于"Michael Jordan",多一个字都不行。

提示词可能是这样的:

谁是史上最伟大的篮球运动员?只输出这个人的名字,不要任何解释、
标点符号或其他文字。答案是 Michael Jordan,只输出这三个词。

练习三:写一个 800 字以上的故事#

任务:让 Claude 写一个至少 800 字的故事。

这个练习的关键是:你得明确说"至少 800 字",并且可能还要加上"详细展开情节"之类的要求,否则 Claude 可能写个 200 字就结束了。

为什么清晰直接这么重要?#

说到底,大语言模型不是人,它没有"察言观色"的能力。

你跟朋友说"随便",朋友可能知道你其实想吃火锅。但你跟 Claude 说"随便",它真的会随便给你个答案。

模糊的提示词最后就是跟自己过不去。你得反复调整提示词,来回折腾好几轮;Claude 只能靠猜,猜错了你还得重来;本来一次能搞定的事,硬是变成了拉锯战。就像你去餐厅跟服务员说"给我来点吃的",人家肯定一脸懵逼,最后还是得问你想吃什么、辣不辣、要不要主食。

实战建议#

下次写提示词之前,停下来想想这三个问题:

想要什么,说清楚了吗? Claude 不会读心术,你不说它就不知道。就像你去理发店,光说"剪短点"肯定不够,得说清楚两边推多高、刘海留多长、要不要打薄。

不想要什么,也说清楚了吗? 有时候告诉 AI “别这样做"比告诉它"要这样做"更管用。就像你点外卖,说"不要香菜不要葱"比说"正常做"更能保证不踩雷。

要求够具体吗? 格式什么样、多长、什么风格、什么语气,这些细节能说的都说清楚。你不会跟设计师说"做个好看的海报"就完事了吧?肯定得说尺寸、配色、放哪些元素。跟 Claude 也一样。

如果这三个问题的答案都是"是”,那你的提示词大概率不会翻车。

总结#

Anthropic 官方教程第二章的核心就一句话:清晰直接。

不要绕弯子,不要指望 Claude 能读懂你的心思,想要什么就直说。

记住黄金法则:如果你的同事看了你的提示词会一脸懵,那 Claude 肯定也懵。

下一章我们会讲更高级的技巧,但清晰直接是一切的基础。把这个做好了,你的提示词工程水平就已经超过大部分人了。
