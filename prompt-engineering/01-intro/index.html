提示词工程入门指南：让 AI 真正听懂你在说什么

别再对着 AI 干瞪眼了！这篇文章带你从零开始掌握提示词工程，让 Claude 成为你的得力助手。基于 Anthropic 官方教程改编，系统学习 9 大核心技能。
January 4, 2026 · 1 min · 149 words · 梦兽编程 -  | Translations:
  • En未翻译

你有没有这种经历：对着 ChatGPT 或者 Claude 说了半天，结果它给你的回答完全不是你想要的？我见过太多朋友抱怨这事了——“帮我写个代码”，它写了，但跟你的需求差了十万八千里；“总结一下这篇文章”，它总结了，但全是废话，重点一个没抓住；“分析一下这个数据”，它分析了，但分析了个寂寞。

别急，真不是 AI 太蠢，是你们俩"语言不通"。

就好比你去国外餐厅点菜，你说"来个好吃的"，服务员一脸懵——好吃的是什么？甜的还是咸的？热的还是凉的？主食还是甜点？AI 也是一样，它很强大，但它需要你把话说清楚。这就是我们这个系列要聊的东西：提示词工程（Prompt Engineering）。

说实话，“提示词工程"这名字听着挺玄乎的，但简单说就是学会怎么跟 AI 说话的技术。你可以把它想象成"AI 翻译术”——把你脑子里模糊的想法，翻译成 AI 能准确理解的指令。或者更直白一点：提示词工程就是让 AI 从"差不多先生"变成"精准执行者"的方法论。这不是什么玄学，而是一套有迹可循的技巧，掌握了它，你和 AI 的协作效率能翻好几倍。

为什么我要专门写这个系列？因为现在会用 AI 的人很多，但会用得好的人太少。大部分人还停留在"打开 ChatGPT → 输入问题 → 复制答案"的阶段，这就像是买了一辆跑车，结果只会踩油门，连档位都不会换。而那些真正把 AI 用好的人，他们问一次就能得到你问三次才能拿到的结果，这就是差距。

接下来这个系列，我会带你系统学习 Anthropic 官方出品的提示词工程教程——没错，就是开发 Claude 的那个公司。整个系列有 9 个核心章节加上 3 个进阶附录，我帮你把内容捋成了一条学习路径：

我们会从最基础的 Claude API 结构开始，搞清楚消息格式是什么、系统提示词怎么写；然后聊怎么把需求说清楚——就像点菜要说具体菜名，不能说"来个好吃的"；接着是角色扮演，让 AI 进入特定角色；还有把数据和指令分开写、让 AI 按你要的格式输出、教 AI 一步步推理、用例子教 AI 怎么做、防止 AI 胡说八道，最后是从零构建复杂提示词。进阶部分会聊链式调用、工具使用和搜索增强，学完这些，你就能从"AI 小白"进阶成"AI 调教师"了。

不过理论说多了容易困，咱们先跑起来一个最简单的例子。首先你得能调用到 Claude。有两条路：一是你自己去 Anthropic Console 外部链接 注册账号，按 token 付费；二是用我们打包好的 AI 编程工具，180 块一天给 25 美金额度，300 块一天给 50 美金额度，Codex、Claude Code、Gemini 三大工具都能用，省得自己折腾账号和充值。搞定了调用之后，安装 Python SDK：

pip install anthropic

接着写个最简单的调用：

import anthropic

client = anthropic.Anthropic(api_key="你的API_KEY")

def get_completion(prompt: str):
    message = client.messages.create(
        model="claude-haiku-4-2025-01-23",
        max_tokens=2000,
        temperature=0,
        messages=[{"role": "user", "content": prompt}]
    )
    return message.content[0].text

response = get_completion("你好，Claude！")
print(response)

跑通了？恭喜，你已经迈出第一步了。这里有两个参数你以后会经常碰到：temperature 控制回答的"随机性"，设为 0 回答很稳定，设为 1 更有创意但也更不可预测；max_tokens 限制回复的最大长度，一般 2000 够用了。学习阶段建议 temperature 设成 0，这样你能更清楚地看到提示词的效果。

在正式开始学习之前，先给你打几针预防针。第一，千万别把 API Key 提交到 GitHub 上去！用环境变量管理：client = anthropic.Anthropic(api_key=os.environ.get("ANTHROPIC_API_KEY"))。第二，Claude 的模型名是有格式的，写错一个字符都会报错，记得用最新的模型 ID，比如 claude-haiku-4-2025-01-23。第三，Messages API 要求消息必须是 user 和 assistant 交替出现，而且第一条必须是 user，这个我们后面会详细讲。
