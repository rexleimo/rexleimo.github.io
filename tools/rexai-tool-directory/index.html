视频与社媒下载#

这三个工具解决的是同一类问题：你在刷视频的时候看到一条想收藏的内容，结果平台不给下载按钮，或者下载出来带个大水印。Rex 工具集帮你把这个流程缩短到"粘贴链接 → 点下载"两步。

  • YouTube 下载：支持视频与音频提取，高速稳定。粘贴链接即可获取 4K/8K HDR 视频或纯音频，支持 Shorts 和播放列表，自动合并音轨，零广告。
    直达：https://tool.rexai.top/youtube 外部链接

  • Instagram 下载：支持公开图片、视频与快拍下载。Reels、IGTV、Story 都能抓，多图帖子批量保存，优先无水印输出，不需要登录 Instagram 账号。
    直达：https://tool.rexai.top/instagram 外部链接

  • TikTok 无水印下载：支持公开视频下载，优先无水印版本。三步操作：复制链接 → 粘贴 → 下载，提供多种清晰度选择，跨设备浏览器直接使用。
    直达：https://tool.rexai.top/tools/tiktok/landing 外部链接

内容创作工具#

写公众号的朋友应该都体会过：本地用 Markdown 写得好好的，一粘贴到微信编辑器格式全乱。这两个工具就是专门治这个毛病的。

  • 微信 Markdown 转换：Markdown 一键转微信富文本，复制即用。在线粘贴 Markdown（最大 512KB），右侧实时预览公众号风格排版，支持 VS Code 风格代码块配色。
    直达：https://tool.rexai.top/tools/wechat-markdown 外部链接

  • 微信图片提取：提取公众号文章图片并去重，支持打包下载。遇到一篇公众号文章里的配图想全部保存？粘贴文章链接就能批量抓取，自动去除重复图片。
    直达：https://tool.rexai.top/tools/wechat-image-extract 外部链接

图片工具#

  • 16 宫格图片分割：手动分割 4x4 宫格图，或 AI 生成表情包（支持黄历运势）。朋友圈九宫格发腻了？试试 16 宫格，还能用 AI 直接生成带文字的表情包。
    直达：https://tool.rexai.top/tools/split-16-grid 外部链接
