群公告速递：REX AI 已开放 Claude Code（CC）体验池，每天约 100 美金额度供大家预热场景。跑通自己的代码流程，再决定是否上月卡或 Codex 拼车，把钱花在刀刃上。

为什么这页值得收藏？#

  • 官方口径信息聚合：基于 Claude Code & Codex 套餐页 外部链接 逐条整理，保证价格、权益和接入流程一致。
  • 双模型定位更清晰：Claude Code 擅长跨文件重构与架构解释；Codex 擅长高频补全、写脚本与 SQL。组合使用更平衡成本与效率。
  • 引导闭环：文末提供闲鱼二维码 + 跳转链接，方便扫码下单或继续在旺旺沟通售后排期。

Claude Code × Codex 能力对照#

模型长项典型场景
Claude Code“读懂 + 改造”整个项目，能跨文件分析依赖、解释遗留业务，并在 IDE 里直接修改重度重构、多人合作项目交接、补充文档与回顾 PR
Codex“写作 + 补全”速度快，适合短 prompt 高频触发写函数 / 工具脚本 / SQL、批量生成测试、自动补全/重写代码片段

推荐搭配：让 Claude Code 思考整体方案，Codex 负责快速补全；随时通过统计页观察 7/30 天真实消耗曲线。

人民币套餐 & 拼车方案#

Claude Code 月卡（额度越高越适合重度开发者）#

套餐月费每日可用额度适合人群
CC 月卡 · 35 刀/日400 元约 35 美金全天写代码、负责大规模改造的重度开发者
CC 月卡 · 25 刀/日300 元约 25 美金白天主业 + 晚间副业/学习
CC 月卡 · 15 刀/日180 元约 15 美金中度使用者，查 BUG、写脚本为主

备注：额度按官方账单核算，可能有小幅波动，建议结合统计页的「最近 7 天 / 30 天」曲线评估真实成本。

Codex 拼车（按人头平摊，兼顾性价比与稳定度）#

拼车类型月费使用体验
4 人车300 元单人均摊最优，适合轻中度写代码
3 人车400 元带宽与并发更稳，适合高频补全或自动化脚本

Codex 更像「高频写手」，短 Prompt + 多次调用的场景越多，拼车越划算。

三步完成接入与本地调试#

  1. 阅读接入文档：https://happycoding.online 提供鉴权、模型列表与 API 示例，基础调用先对照官方手册。
  2. 安装配置切换工具：开源仓库 claude-config-switcher 可以快速在本地切换 CC / Codex 的 key，命令行管理更省心。
  3. 延伸阅读 Code 文档：飞书 Wiki 收录了更多最佳实践与调试案例，访问受限时可在交流群内索要最新链接。

  • 能否先试用？ 可以，用站内每天 ~100 美金体验额度先跑真实场景，再决定是否续费。
