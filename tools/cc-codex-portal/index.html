常见问题

订阅后能用哪些模型？

Codex 套餐可用 Codex 系列（专为 Coding 设计）。全模型标准池套餐可用国产模型、GPT 系列、Claude 系列、Gemini 系列等 20+ 模型。具体模型会随平台可用列表更新，以开通时可用列表为准。

每日额度和「一刀」怎么理解？

页面里的 $25/天、$100/天是每天可用的标准额度上限；30 天总额度 = 日额度 × 30。「一刀」就是 1 美元标准额度。不同模型会按公平使用策略消耗额度，Claude / Gemini 等高成本模型设有公平使用额度。

每日 15 张生图是什么意思？

所有套餐均包含每日 15 张 AI 生图额度，每天 0 点自动重置，当天未用不累计到次日。

日额度用完了怎么办？

当天额度用完后，次日 0 点自动恢复。如果经常用完，建议升级到更高档套餐，或减少高成本模型的集中使用。

怎么选套餐？

只做 AI Coding，优先选 Codex：体验从 ¥69/月开始，日常编码从 ¥99/月开始，重度 Coding Agent 选 $100/天以上。需要 GPT、Claude、Gemini 多模型切换，选全模型标准池：日常从 ¥369/月开始，高频多模型用 $100/天以上。
