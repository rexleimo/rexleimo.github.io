GPT-5 发布：API 大幅降价、Agentic Coding 与多模态缺席

2025 年 8 月 8 日 OpenAI 发布 GPT-5：API 价格大幅下调，新增 Agentic Coding 能力，但多模态能力未随本次发布升级。本文整理发布会核心信息与待核验数据。

August 8, 2025 · 1 min · 76 words · 梦兽编程 -

2025 年 8 月 8 日，OpenAI 发布 GPT-5。本次发布的核心信息：API 价格大幅下调、新增 Agentic Coding（智能体式编程）能力、多模态能力未随本次发布升级。以下内容整理自发布会口径，具体数据以 OpenAI 官方文档为准。

价格：API 大幅下调#

发布会称 GPT-5 的 API 价格约为 Claude Opus 4.1 的 1/15（发布会口径，具体定价请以 OpenAI 官方定价页为准）。对 API 成本敏感的应用开发者，这是本次发布中最直接的影响。

Agentic Coding：从补全代码到独立修项目#

GPT-5 新增的 Agentic Coding 能力是本次发布的核心：

  • 给定一个模糊需求（如"修复这个拥有上千个文件的项目里的 bug"），模型自主阅读代码库、理解上下文、定位问题。
  • 代码运行报错后，模型读取错误日志并自行修改迭代，直到通过。
  • 现场演示：一个 400 行的飞机空气动力学模拟，约 2 分钟完成。

类比：此前的模型像"需要你跟在后面收拾烂摊子的实习生"，Agentic Coding 更像"能自己读代码库、自己验证结果的资深工程师"。

其他发布会数据（待核验）#

  • 幻觉率：发布会称较 GPT-4o 降低约 45%（建议以第三方独立评测为准）。
  • 上下文窗口：400K（发布会口径）。
  • 上述数字均未在发布会现场给出完整评测方法，落地前建议用自有数据集实测。

局限：多模态缺席#

GPT-5 本次发布不支持音频、视频输入输出，也未提供图片生成能力。与同期主打多模态生成的产品（如 Google Genie 3）相比，本次发布明显聚焦文本与编程场景。

小结#

对开发者生态，这是一次定位清晰的发布：更低的价格 + 更强的编程能力，直接影响 API 应用成本和 Coding Agent 的上限。对期待"全能多模态模型"的用户，则是一次未达预期的更新。两类判断都基于发布会信息，后续以 OpenAI 官方文档和独立评测为准。
