Module 9: A2A and Cross-Language Interoperability

Agent-to-Agent is the part of the ADK ecosystem where documentation versions most easily fail to line up: the A2A protocol version, the ADK implementation version, and each language SDK’s version are three separate curves. This module separates the curves first, then writes code.

Fact boundaries

  • The A2A protocol v2 implementation is not exclusive to 2.x: server/adka2a/v2 and agent/remoteagent/v2 already existed in the v1.7.0 tree. What 2.x adds is mostly consolidation and security fixes.
  • Underlying dependency: github.com/a2aproject/a2a-go v0.3.15 (measured from the v2.4.0 go.mod).
  • Two directly relevant v2.4.0 fixes:
    1. pinning the interface URL of a fetched agent card to the origin it came from (so a card cannot steer traffic to another host);
    2. remoteagent/v2 now runs the after-callback correctly after aggregating artifact events (it previously skipped it).
  • The runtime entry point is cmd/launcher/web/a2a (already composed into the full launcher).
  • Version curve comparison (measured 2026-09-26): Python google-adk 2.10.0, Go google.golang.org/adk/v2 2.4.0, plus Java / Kotlin / TypeScript / ADK Web each with independent version numbers. When an English tutorial does not line up, first establish which implementation it describes.
