Module 1: Environment and Project Layout

Setting up 2.x has two more hurdles than 1.x: the Go toolchain is a hard requirement (go 1.26.6) and the module path carries /v2. This module pours the foundation, and every snippet afterwards assumes it.

Prerequisites

  • You have read The Go Toolchain Floor (why 1.26.6+ is mandatory)
  • You have a working Gemini API key, or Vertex AI ADC already configured

What you will learn

  • Bring up a v2.4.0 environment in one pass, and prove the version yourself instead of guessing
  • Tell adkgo (a deployment CLI) apart from the launcher (runtime subcommands) — two completely different things
  • Establish a 2.x directory and go.mod convention that survives CI and multi-person work
