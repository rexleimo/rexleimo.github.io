Module 1: Daily Workflow

Once it is installed, this module answers “how do I use it every day”: mouse first, keyboard second, then a complete understanding of state. Article 3 is the one most often skipped and the one people most often pay for skipping — because “is my agent still there after I close the window” has five different answers depending on which path you are on.

Baseline: herdr 0.9.2 stable · documentation source pinned at v0.9.2

Prerequisites

  • You completed the install and verification in module 0 article 2
  • You read the four-layer concepts in module 0 article 3 (otherwise the state paths in article 3 will not make sense)

Learning goals

After this module you can answer:

  • What you can do purely with the mouse and which things require the keyboard, with no bindings memorised
  • How the prefix key works (press ctrl+b, release, press the action key), and why binding ctrl+alt combos directly sometimes does “absolutely nothing”
  • How to enter copy mode, select, and search; and why the editing keys in text fields are not the same set as the keys in a pane
  • How to configure a prefix-free scheme, and which combinations in the official ctrl+alt recommendation are safe
  • In each of the four cases — detach, machine reboot, herdr update, the agent exiting on its own — what stays alive, what dies, and what can be restored
  • The difference between “pane history replay” and “agent-native session restore”, and why the latter needs an integration installed
  • What problem live handoff (herdr update --handoff) solves, its prerequisites, and its known side effects

The short version

Newcomer route: use article 1 with the mouse only to get one workspace plus one agent running; that is enough for a while. Only then touch the bindings in article 2. But please do read article 3 — it decides whether you dare close your laptop lid while an agent is running a long task.
