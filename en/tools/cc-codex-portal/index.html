Why this page is worth bookmarking#

Three steps to plug it into your workflow#

  1. Read the integration docs: https://tool.rexai.top/api-stats covers auth, model catalog and basic API examples. Start by mirroring the official requests.
  2. Install the config switcher: the open-source claude-config-switcher helps you quickly swap between CC and Codex keys in your local environment via CLI.
  3. Dive into the Code docs: a Feishu (Lark) Wiki hosts more examples and best practices. If you can’t access it directly, ask in the user group for the latest link.

FAQ#

  • Can I try it before paying? Yes. The shared CC pool exposes around USD 100/day of trial credit so you can run your real scenarios first.
  • What does the stats page show? It summarizes your last 7 / 30 days of spending, call counts per model and error breakdowns, so you can keep close tabs on cost.
  • Can one person use both CC and Codex? Absolutely. The recommended pattern is “CC thinks, Codex types”—CC for global reasoning and large changes, Codex for high‑frequency completions—so you get strong results without overspending.
