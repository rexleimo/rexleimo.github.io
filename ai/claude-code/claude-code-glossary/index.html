术语表——Claude Code概念速查

Claude Code完整术语表，涵盖架构、上下文管理、提示词工程、权限系统、Agent系统等核心概念的简明定义。

June 5, 2026 · 2 min · 403 words · 梦兽编程 -

这份术语表整理了Claude Code架构中的核心概念，按主题分类，方便快速查阅。

A#

Adaptive Thinking#

自适应思维。Claude 4.6模型支持的thinking模式，模型自行决定思考多少，而非固定token预算。比enabled模式更灵活。

Agent#

代理/智能体。Claude Code的核心概念，指能够感知环境、执行工具、完成任务的AI实体。包括主Agent、子Agent、Fork Agent等多种形态。

Agent Loop#

Agent循环。Claude Code的核心执行流程：用户输入 → 模型推理 → 工具调用 → 结果处理 → 响应生成，循环往复直至任务完成。

Agent Memory#

Agent记忆。子Agent特有的持久化机制，支持user/project/local三级作用域，用于存储Agent特定的偏好和知识。

Agent Swarm#

Agent集群。平面结构的Agent团队，通过消息传递协作，禁止嵌套派生。

Auto-Compact#

自动压缩。当上下文接近容量上限时自动触发对话摘要，释放token空间的机制。

Auto-Dream#

自动梦想。夜间记忆整合机制，定期扫描记忆文件、合并重复、消除矛盾、修剪过期内容。

B#

Beta Header#

测试头。Anthropic API的实验性功能开关，如fast-mode、caching等。一旦发送过某个Beta Header，Claude Code会锁存继续发送以保持缓存稳定。

Bash Tool#

Bash工具。执行shell命令的工具，内置Git安全协议和沙箱机制。

C#

Cache Break Detection#

缓存中断检测。追踪20+个字段的状态变化，识别导致提示词缓存失效的原因。

Cache Creation#

缓存创建。Anthropic API的计费概念，首次发送提示词前缀时产生的成本。命中缓存便宜90%。

Cache Editing#

缓存编辑。在已有缓存前缀基础上修改部分内容的优化技术，比完全重建缓存更省成本。

Circuit Breaker#

熔断器。当自动化流程连续失败时强制停止的机制，防止无限重试浪费资源。

CLAUDE.md#

CLAUDE.md文件。项目级配置文件，存储编码规范、架构约束、团队流程等不应被自动修改的指令。

Compact#

压缩。将多轮对话历史摘要为关键信息的上下文管理技术，用于释放token空间。

Coordinator Mode#

协调者模式。多Agent架构之一，主Agent作为"总指挥"派任务给Worker，自己不直接编码。

Context Collapse#

上下文折叠。当上下文超过容量限制时，最旧的消息被移除或摘要的过程。

Context Window#

上下文窗口。模型能处理的token数量上限，Claude Code支持200K。

D#

Denial Tracking#

拒绝追踪。YOLO分类器的安全机制，连续3次或总计20次被拒绝后回退到手动确认。

Dynamic Boundary#

动态边界。系统提示词中标记静态/动态内容分界的特殊标记，用于优化缓存策略。

E#

Effort#

努力度。Claude API的推理深度参数，可选值：low、medium、high、max。

Extract Memories#

提取记忆。每轮对话结束时自动分析并提取值得持久化信息的机制。

F#

Fail-Closed#

失败关闭。安全设计原则，默认选择最安全选项，只有显式声明后才允许危险操作。

Fast Mode#

快速模式。将非Opus模型的请求路由到Opus 4.6以获得更高质量响应的机制。

Feature Flag#

功能开关。通过构建时代码开关控制功能启用/禁用的技术，Claude Code有89个Feature Flag。

Fork#

Fork模式。实验性的子Agent派生方式，继承父Agent的完整对话上下文。

G#

Git Worktree#

Git工作树。为Agent创建隔离的git工作副本，保护主分支不被意外修改。

GrowthBook#

GrowthBook。A/B测试和Feature Flag管理平台，Claude Code用于远程配置控制。

H#

Harness Engineering#

驾驭工程。从Claude Code源码提炼的六条核心架构原则：提示词即控制面、缓存感知设计、失败关闭、A/B测试、先观察再修复、锁存以求稳定。

Hook#

钩子/拦截点。Claude Code生命周期中的事件拦截机制，支持before/after两种触发时机。

I#

Isolation#

隔离模式。子Agent的执行隔离选项，可选值：none、worktree。

K#

KAIROS#

KAIROS。Claude Code的后台自主Agent模式，支持焦点感知、定时唤醒、简报通信等功能。

L#

Latch#

锁存。一旦进入某个状态就不再改变的技术，用于防止缓存抖动和状态波动。

LSP#

Language Server Protocol。Claude Code支持的代码智能协议，用于符号跳转、引用查找等。

M#

MCP#

Model Context Protocol。Anthropic推出的开放协议，用于标准化AI与外部数据源/工具的集成。

Memdir#

记忆目录。跨会话记忆的存储层，包含MEMORY.md索引和主题文件。

Microcompact#

微压缩。比自动压缩更精细的上下文清理机制，包含时间戳清理、缓存感知清理、API Context Management。

Model Routing#

模型路由。根据配置将请求路由到不同模型提供商（Anthropic、Bedrock、Vertex等）的机制。

O#

OpenSpec#

OpenSpec。Claude Code使用的变更管理规范，用于规划、实施、验证架构变更。

P#

Permission Mode#

权限模式。Claude Code的安全等级：default、acceptEdits、plan、bypassPermissions、auto、dontAsk。

perToolHashes#

每个工具的哈希。用于精确检测哪个工具描述变化导致缓存失效的字段。

Post-Compact Restoration#

压缩后恢复。自动压缩后选择性恢复最近使用的文件和技能，避免模型从零开始。

Prompt Cache#

提示词缓存。Anthropic API的特性，相同提示词前缀可复用，显著降低成本。

R#

Read Before Edit#

编辑前先读取。强制模型在编辑文件前必须先读取当前内容的设计模式。

Remote Control#

远程控制。通过网络协议远程控制Claude Code实例的能力，基于BRIDGE_MODE。

S#

Schema#

Schema。工具的结构化描述，包含名称、参数、返回值等元数据，用于模型理解工具用法。

SendMessage#

发送消息。Agent间通信的工具，支持点对点、广播、UDS、Bridge等多种寻址方式。

Session Memory#

会话记忆。滚动会话摘要，为压缩系统提供"什么是重要的"信号。

Skill#

技能。可复用的Agent能力单元，包含提示词、工具、工作流等，可通过技能系统动态加载。

Soft/Double/Hard Interrupt#

三级中断。Claude Code支持的用户取消级别：软中断（优雅停止）、双重中断（强制停止）、硬中断（立即终止）。

SubAgent#

子Agent。由主Agent派生的独立Agent实例，用于并行处理任务。

System Prompt#

系统提示词。发送给模型的指令集合，定义AI的行为准则、输出格式、安全规则等。

System Reminder#

系统提醒。在对话中间插入的临时系统消息，用于传递当前回合的特定指令。

T#

Teammate#

队友。Agent Swarm中的成员Agent，通过平面结构协作。

Thinking#

思考模式。Claude API的特性，让模型显式输出推理过程。模式包括adaptive、enabled、disabled。

Token#

Token。大语言模型的处理单元，约等于英文单词的1/4或中文汉字的1/2。

Token Budget#

Token预算。为各类内容设定token上限的上下文管理策略。

Tool#

工具。AI Agent可调用的能力单元，包括文件操作、命令执行、代码搜索等。

Tool Description#

工具描述。工具的自然语言说明，告诉模型这个工具是做什么的、怎么用。

Tool Result#

工具结果。工具执行后返回的内容，会被注入到上下文中供模型参考。

Transcript#

会话记录。JSONL格式的完整对话持久化，支持会话恢复。

Tree Sitter#

Tree Sitter。增量解析库，Claude Code用于代码语法分析。

U#

Ultrathink#

Ultrathink。Claude Code的交互设计，在消息中包含ultrathink关键词自动将Effort提升到high。

V#

Verification Agent#

验证Agent。专门用于验证实现正确性的Agent类型，禁止修改项目，只读验证。

W#

Whitelist#

白名单。YOLO分类器的第一道关卡，明确允许的操作直接放行。

Worktree#

Worktree。Git功能，创建独立的工作目录，Agent隔离模式基于此实现。

Y#

YOLO Classifier#

YOLO分类器。Claude Code的权限分类器，四层架构：白名单、输入过滤、Stage 1快速分类、Stage 2深度推理。
