OpenAI 替 Claude Code 出外掛：讓 Codex 進駐敵營，專抓 Claude 的 bug

OpenAI 發布 Codex Plugin for Claude Code，讓你在 Claude Code 裡直接呼叫 Codex 執行跨模型程式碼審查。本文介紹三個指令的用法、安裝流程，與官方文件的定價和用量說明。

你在用 Claude Code 寫程式，身後站著一個叫 Claude 的幫手，幫你生成、重構、 Debug。問題來了：誰來幫你檢查 Claude 寫的東西有沒有問題？

以前你得另開一個視窗，把程式碼複製貼上到 Codex（或乾脆靠肉眼審查）。2026 年 3 月 31 日，OpenAI 工程師 Vaibhav Srivastav 發布了一個叫 Codex Plugin for Claude Code 的外掛，讓你直接在 Claude Code 裡喊 Codex 過來幫忙。相當於讓競爭對手給你打工。

三個指令，三種場合#

外掛裝好之後，會在 Claude Code 裡注册三個指令。各自對應不同的使用情境。

/codex:review：例行審查#

最基礎的用法。相當於你對著 Claude Code 說：「幫我叫個 Codex 過來看一眼。」

適合場景：

  • 提交前的最後把關
  • 多人協作時檢查別人的 PR
  • 任何你想多一雙眼睛盯著的情況

多檔案改動的話，建議加 --background 丢到背景跑，你繼續幹你的活。加 --base <分支名> 還能指定跟哪個版本比。

/codex:review --background
/codex:status
/codex:result

/codex:status 查進度，/codex:result 取結果，/codex:cancel 中途喊停。

這是唯讀操作，不會修改任何程式碼。

/codex:adversarial-review：唱反調審查#

這個厲害了。Codex 不只檢查語法，還會主動質疑你的實作邏輯和設計決策。

什麼意思？比如你寫了一個快取策略，標配版本的 Codex 會說「這裡用了 LRUCache，很好」。對抗版本會問你：「如果 Cache 失效了怎麼辦？並發寫入的時候邏輯對不對？」

適合用在：

  • 資料庫遷移
  • 認證授權邏輯修改
  • 基礎設施脚本文重構
  • 任何「危險藏在隱性假設裡」的高風險變更

你也可以在指令後面加上一句話，告訴 Codex 要重點挑戰哪裡：

/codex:adversarial-review 請特別檢查權限邏輯
/codex:adversarial-review --base main look for race conditions

同樣是唯讀，不改程式碼。

/codex:rescue：直接交棒#

適合場景：任務卡關了，實在想不出來怎麼處理。

直接把你的問題丢給 Codex：

/codex:rescue investigate why the build is failing in CI
/codex:rescue fix the failing test with the smallest safe patch
/codex:rescue --resume apply the top fix from the last run

加 --model gpt-5.4-mini --effort medium 之類的參數還能指定用什麼模型、思考多深。--fresh 從頭開始，--resume 繼續上次中斷的任務。

背景執行也支援，長任務建議 --background 丢出去。

安裝流程#

硬體需求很親民：

  • ChatGPT 帳號（免費版即可）或 OpenAI API Key
  • Node.js 18.18 或更新版本

第一次設定四步搞定：

/plugin marketplace add openai/codex-plugin-cc
/plugin install codex@openai-codex
/reload-plugins
/codex:setup

注意 /reload-plugins 這步不能省，少了外掛不會生效。

如果本機還沒裝 Codex，/codex:setup 會提示你安裝。你也可以自己動手：

npm install -g @openai/codex
!codex login

設定完成後，三個指令就緒，可以開始折騰了。

輕量設計：不做加法#

很多開發者看到「外掛」兩個字就怕，覺得要裝一堆東西安裝半小時。這個外掛的設計哲學剛好相反。

它本質上是一層調用層，封裝了你本機已經裝好的 Codex CLI。所有認證、環境變數、MCP 設定都是複用現成的，不需要另外折騰。

如果外掛檢測到 ~/.codex/config.toml 或專案根目錄的 .codex/config.toml，也會直接讀取。你之前對 Codex 的所有配置，原封不動繼續生效。

審查閘門：讓 Claude 必須等 Codex 點頭#

進階功能。加一行設定就能開啟：

/codex:setup --enable-review-gate

開了之後，Claude Code 在執行某些操作前會先叫 Codex 做一次定向審查。如果 Codex 發現問題，Claude Code 會被攔下來，讓你先處理問題再繼續。

但作者特別提醒：這個功能有可能觸發 Claude 和 Codex 的來回呼叫，額度消耗速度會比預期快。建議「有需要才開，開了就要盯著」。

用量與設定注意事項#

用這個外掛的次數，會計入你的 Codex 用量配額。根據 OpenAI Codex 定價頁面 外部链接 ，免費 ChatGPT 帳號有額度上限，大量執行審查或開著閘門放著跑，額度會很快燒光。

如果想控制成本或指定模型，可以在專案資料夾或家目錄新建 .codex/config.toml：

model = "gpt-5.4-mini"
model_reasoning_effort = "xhigh"

model_reasoning_effort 決定 Codex 思考多深。開高固然更穩妥，額度也燒得更快。

適合誰用#

如果你符合下面任何一種情況，這個外掛就值得一試。

用 Claude Code 寫了一段時間，想在提交前多一道安全檢查。手上剛好有免費 ChatGPT 帳號，懶得折騰新工具。高風險變更（資料庫遷移、重構之類的）不敢裸上，想找另一雙眼睛把關。

平常只用一個 AI 工具的話，裝這個等於白嫖了一次跨模型審查的機會。OpenAI 和 Anthropic 表面上打得火熱，底層基礎設施倒是挺配合的。

原始碼開源在 GitHub：openai/codex-plugin-cc 外部链接 ，Codex CLI 的詳細配置可參考 OpenAI 官方 Codex 文件 外部链接 。

FAQ#

Q: 裝了這個外掛還需要另外開 Codex 帳號嗎？

如果本機已經裝過 Codex 並登入過，那同一個帳號直接複用。如果完全沒用過 Codex，用免費 ChatGPT 帳號登入即可，不需要付費訂閱。

Q: 會不會影響我原來 Claude Code 的使用體驗？

幾乎不會。外掛是純增量的，不會修改 Claude Code 原本的行為。只有你主動呼叫 /codex:* 指令時才會出發。另外注意 --background 模式適合長任務，能避免干擾你的主要工作流。

Q: 免費版 ChatGPT 額度多久會用完？

取決於使用頻率。每一次程式碼審查都會消耗 Codex 配額，免費版配額有限。如果你是重度用戶或長期開著審查閘門，燒完的速度會比預期快。可以透過 model_reasoning_effort 參數降低思考深度來省一點。
