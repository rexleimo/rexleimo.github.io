OpenAI 替 Claude Code 出插件：让 Codex 进驻敌营，专抓 Claude 的 bug

OpenAI 发布 Codex Plugin for Claude Code，让你在 Claude Code 里直接呼叫 Codex 执行跨模型代码审查。本文介绍三个指令的用法、安装流程，与官方文档的定价和用量说明。

你在用 Claude Code 写程序，身后站着一个叫 Claude 的帮手，帮你生成、重构、Debug。问题来了：谁来帮你检查 Claude 写的东西有没有问题？

以前你得另开一个窗口，把代码复制粘贴到 Codex（或干脆靠肉眼审查）。2026 年 3 月 31 日，OpenAI 工程师 Vaibhav Srivastav 发布了一个叫 Codex Plugin for Claude Code 的插件，让你直接在 Claude Code 里喊 Codex 过来帮忙。相当于让竞争对手给你打工。

三个指令，三种场合#

插件装好之后，会在 Claude Code 里注册三个指令。各自对应不同的使用场景。

/codex:review：例行审查#

最基础的用法。相当于你对 Claude Code 说：「帮我叫个 Codex 过来看一眼。」

适合场景：

  • 提交前的最后把关
  • 多人协作时检查别人的 PR
  • 任何你想多一双眼睛盯着的情况

多文件改动的话，建议加 --background 丢到后台跑，你继续干你的活。加 --base <分支名> 还能指定跟哪个版本比。

/codex:review --background
/codex:status
/codex:result

/codex:status 查进度，/codex:result 取结果，/codex:cancel 中途喊停。

这是只读操作，不会修改任何代码。

/codex:adversarial-review：唱反调审查#

这个厉害了。Codex 不只检查语法，还会主动质疑你的实现逻辑和设计决策。

什么意思？比如你写了一个缓存策略，标配版本的 Codex 会说「这里用了 LRUCache，很好」。对抗版本会问你：「如果 Cache 失效了怎么办？并发写入的时候逻辑对不对？」

适合用在：

  • 数据库迁移
  • 认证授权逻辑修改
  • 基础设施脚本重构
  • 任何「危险藏在隐性假设里」的高风险变更

你也可以在指令后面加一句话，告诉 Codex 要重点挑战哪里：

/codex:adversarial-review 请特别检查权限逻辑
/codex:adversarial-review --base main look for race conditions

同样是只读，不改代码。

/codex:rescue：直接交棒#

适合场景：任务卡住了，真想不出来怎么处理。

直接把你的问题丢给 Codex：

/codex:rescue investigate why the build is failing in CI
/codex:rescue fix the failing test with the smallest safe patch
/codex:rescue --resume apply the top fix from the last run

加 --model gpt-5.4-mini --effort medium 之类的参数还能指定用什么模型、思考多深。--fresh 从头开始，--resume 继续上次中断的任务。

后台执行也支持，长任务建议 --background 丢出去。

安装流程#

硬件需求很亲民：

  • ChatGPT 账号（免费版即可）或 OpenAI API Key
  • Node.js 18.18 或更新版本

第一次设定四步搞定：

/plugin marketplace add openai/codex-plugin-cc
/plugin install codex@openai-codex
/reload-plugins
/codex:setup

注意 /reload-plugins 这步不能省，少了插件不会生效。

如果本机还没装 Codex，/codex:setup 会提示你安装。你也可以自己动手：

npm install -g @openai/codex
!codex login

设定完成后，三个指令就绪，可以开始折腾了。

轻量设计：不做加法#

很多开发者看到「插件」两个字就怕，觉得要装一堆东西安装半小时。这个插件的设计哲学刚好相反。

它本质上是一层调用层，封装了你本机已经装好的 Codex CLI。所有认证、环境变量、MCP 配置都是复用现成的，不需要另外折腾。

如果插件检测到 ~/.codex/config.toml 或项目根目录的 .codex/config.toml，也会直接读取。你之前对 Codex 的所有配置，原封不动继续生效。

审查闸门：让 Claude 必须等 Codex 点头#

进阶功能。加一行配置就能开启：

/codex:setup --enable-review-gate

开了之后，Claude Code 在执行某些操作前会先叫 Codex 做一次定向审查。如果 Codex 发现问题，Claude Code 会被拦下来，让你先处理问题再继续。

但作者特别提醒：这个功能有可能触发 Claude 和 Codex 的来回调用，额度消耗速度会比预期快。建议「有需要才开，开了就要盯着」。

用量与配置注意事项#

用这个插件的次数，会计入你的 Codex 用量配额。根据 OpenAI Codex 定价页面 外部链接 ，免费 ChatGPT 账号有额度上限，大量执行审查或开着闸门放着跑，额度会很快烧光。

如果想控制成本或指定模型，可以在项目文件夹或家目录新建 .codex/config.toml：

model = "gpt-5.4-mini"
model_reasoning_effort = "xhigh"

model_reasoning_effort 决定 Codex 思考多深。调高固然更稳妥，额度也烧得更快。

适合谁用#

如果你符合下面任何一种情况，这个插件就值得一试。

用 Claude Code 写了一段时间，想在提交前多一道安全检查。手上刚好有免费 ChatGPT 账号，懒得折腾新工具。高风险变更（数据库迁移、重构之类的）不敢裸上，想找另一双眼睛把关。

平常只用一个 AI 工具的话，装这个等于白嫖了一次跨模型审查的机会。OpenAI 和 Anthropic 表面上打得火热，底层基础设施倒是挺配合的。

源代码开源在 GitHub：openai/codex-plugin-cc 外部链接 ，Codex CLI 的详细配置可参考 OpenAI 官方 Codex 文档 外部链接 。

FAQ#

Q: 装了这个插件还需要另外开 Codex 账号吗？

如果本机已经装过 Codex 并登录过，那同一个账号直接复用。如果完全没用过 Codex，用免费 ChatGPT 账号登录即可，不需要付费订阅。

Q: 会不会影响我原来 Claude Code 的使用体验？

几乎不会。插件是纯增量的，不会修改 Claude Code 原本的行为。只有你主动呼叫 /codex:* 指令时才会触发。另外注意 --background 模式适合长任务，能避免干扰你的主要工作流。

Q: 免费版 ChatGPT 额度多久会用完？

取决于使用频率。每一次代码审查都会消耗 Codex 配额，免费版配额有限。如果你是重度用户或长期开着审查闸门，烧完的速度会比预期快。可以通过 model_reasoning_effort 参数降低思考深度来省一点。
