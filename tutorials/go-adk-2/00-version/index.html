模块 0：版本与迁移

动手写代码之前，先把版本这件事钉死：上游现在是 v2.4.0，模块路径带 /v2，go.mod 要求 go 1.26.6。 本模块把「2.0 到底改了什么」「怎么从 1.x 迁」「Go 版本为什么不再是自由选项」三件事一次讲清楚。

前置要求

  • 会用 Go（写过 HTTP 服务，理解 goroutine 和 channel）
  • 知道 Go 版本策略 外部链接 里 go 指令的含义（不确定的话，读本模块第 3 篇）

学习目标

完成本模块后，你能回答：

  • v2 相对 v1 的破坏性变更清单，以及哪些是「改 import 就行」、哪些必须重写编排逻辑
  • ToolContext/CallbackContext 合并成 agent.Context 之后，测试 mock 怎么处理
  • 为什么 go install .../cmd/adk@latest 这类命令现在直接失败
  • 依赖模块的 go 1.26.6 指令会怎样影响你的 CI 镜像和 GOTOOLCHAIN

一句话结论

如果你的项目还在 1.x，先读第 2 篇再决定要不要迁；如果你是新项目，读完第 3 篇把工具链钉住，然后直接从模块 1 开始。
