模块 2：核心对象模型

2.x 的对象模型只有一处根本变化：agent.Context 成为唯一上下文。它同时是 context.Context、会话句柄、事件发射器和 state 入口。理解这一点，platform、launcher、runner 的位置就都清楚了。

本模块会讲清的三件事

  1. launcher.Config 在 2.x 是一等公民的能力开关：SessionService、ArtifactService、MemoryService、AgentLoader、A2AOptions、PluginConfig、TelemetryOptions、Authenticator(authn)、Authorizer(authz)、Compaction。注意 Authenticator 默认 authn.NewNoop，Authorizer 默认 authz.Noop，另有 authz.Strict 校验调用者身份与 payload 用户一致。
  2. Compaction 是进程级设置：一个 launcher 通过 agent loader 服务多个应用，它们共享同一份 compaction 配置与同一个 Summarizer 实例（同一个模型）。需要不同压缩策略就必须分开跑——这个约束源码注释里写明了，很多人会踩。
  3. 模型接入的分工：model/gemini（1.x 就有）、model/openaimodel 与 model/apigee（2.x 树里 openaimodel 是 v2 独有包）。
