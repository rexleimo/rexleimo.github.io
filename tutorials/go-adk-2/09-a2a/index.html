模块 9：A2A 与跨语言互操作

Agent-to-Agent 是 ADK 生态里最容易「文档版本对不上」的一块：A2A 协议版本、ADK 实现版本、各语言 SDK 版本是三条独立曲线。这个模块先把曲线分清楚，再写代码。

篇章列表

序号篇名slug状态
1暴露与消费：server/adka2a / server/adka2a/v2、agent/remoteagent / agent/remoteagent/v2、launcher.Config.A2AOptionsgo-adk2-a2a-v2✅
2跨语言互操作：Python 2.10 / Java / Kotlin / TypeScript ADK 与 Go 2.4 的版本对齐与踩坑go-adk2-cross-language✅

事实边界

  • A2A 协议 v2 的实现不是 2.x 独有：server/adka2a/v2 与 agent/remoteagent/v2 在 v1.7.0 树里就已存在。2.x 的增量更多在收口与安全修复。
  • 底层依赖：github.com/a2aproject/a2a-go v0.3.15（v2.4.0 go.mod 实测）。
  • v2.4.0 两个直接相关的修复：
    1. 把抓取到的 agent card 的接口 URL 钉在其来源 origin 上（防止卡片把流量指向别的 host）；
    2. remoteagent/v2 在聚合 artifact 事件后正确执行 after-callback（此前会跳过）。
  • 运行期入口：cmd/launcher/web/a2a（full launcher 已组合进来）。
  • 版本曲线对照（2026-09-26 实测）：Python google-adk 2.10.0，Go google.golang.org/adk/v2 2.4.0，另有 Java / Kotlin / TypeScript / ADK Web 各自独立版本号。看英文教程对不上号时，先确认它讲的是哪个实现。
