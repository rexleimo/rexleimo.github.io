ADK Go 2.x 安装与验证：go get /v2、adkgo CLI、跑通第一个 Agent

六步装好 ADK Go v2.4.0：绕开 go 指令坑、配凭据、跑通第一个 Agent，附开机自检清单。

September 26, 2026 · 3 min · 430 words · 梦兽编程 -  |  English

验证版本： google.golang.org/adk/v2 v2.4.0 · Go 1.27.1（下限 1.26.6）· 2026-09-26

装软件就三件事：看系统要求、下载安装、配账号。ADK Go 也一样，只是每一步都有个「装完怎么证明装对了」的自检动作。六步走完，全绿才算数：① 查工具链 ② 建模块拉依赖 ③ 配凭据 ④ 最小 Agent ⑤ 跑起来 ⑥ 过验证清单。

① 查工具链：先看包装盒上的最低系统版本#

go version
# 例：go1.27.1 darwin/arm64   ← 要求 ≥ 1.26.6

低于 1.26.6 先升 Go，否则下一步一定撞墙，报错长这样：

go: google.golang.org/adk/v2@v2.4.0 requires go >= 1.26.6 (running go 1.25.6; GOTOOLCHAIN=local)

② 建模块拉依赖：有一处默认值坑，不抬就卡住#

mkdir myagent && cd myagent
go mod init myagent
go get go@1.27.1                      # 抬 go 指令，不是可选的
go get google.golang.org/adk/v2@v2.4.0 # 正式依赖，锁版本

坑在这：Go 1.26 起 go mod init 会故意把 go 指令写成「当前工具链低一截」（你装 1.27 它写 1.26.0），低于 ADK 要求的 1.26.6。所以中间那行 go get go@1.27.1 是必须的，不是可有可无。装完的 go.mod 应该长这样：

module myagent

go 1.27.1

require (
    google.golang.org/adk/v2 v2.4.0
    google.golang.org/genai v1.x.x   // 由 go get 解析
)

自证版本（别找 adkgo version，它不存在）：

go list -m google.golang.org/adk/v2

③ 配凭据：先有账号，再激活软件#

两条路线选一条，变量名都取自官方 v2.4.0 样例，不是我编的。

个人/最快：Gemini API Key

export GOOGLE_API_KEY="你的key"

企业/合规：Vertex AI（统一账号 + 项目）

gcloud auth application-default login
export GOOGLE_GENAI_USE_VERTEXAI=true
export GOOGLE_CLOUD_PROJECT="你的项目"
export GOOGLE_CLOUD_LOCATION="us-central1"

.env 一句话：官方样例不会自动读 .env（都用 os.Getenv 取），想要 .env 就自己引 godotenv；密码便签永远别提交进仓库，.gitignore 写 .env，留一份只有键名的 .env.example 给同事抄。

④ 最小 Agent：四十行，就改三处#

下面这份 main.go 是从官方样例砍到最短的版本。对照 1.x，只有三处必须改，其余照抄就能跑：

package main

import (
    "context"
    "log"
    "os"

    "google.golang.org/genai"
    "google.golang.org/adk/v2/agent"
    "google.golang.org/adk/v2/agent/llmagent"
    "google.golang.org/adk/v2/cmd/launcher"
    "google.golang.org/adk/v2/cmd/launcher/full"
    "google.golang.org/adk/v2/model/gemini"
)

func main() {
    ctx := context.Background()
    model, err := gemini.NewModel(ctx, "gemini-flash-latest", &genai.ClientConfig{
        APIKey: os.Getenv("GOOGLE_API_KEY"),
    })
    if err != nil {
        log.Fatalf("model: %v", err)
    }
    a, err := llmagent.New(llmagent.Config{
        Name:        "hello_agent",
        Model:       model,
        Description: "回答问题的最小 agent",
    })
    if err != nil {
        log.Fatalf("agent: %v", err)
    }
    l := full.NewLauncher()
    if err := l.Execute(ctx, &launcher.Config{
        AgentLoader: agent.NewSingleLoader(a),
    }, os.Args[1:]); err != nil {
        log.Fatalf("run failed: %v\n\n%s", err, l.CommandLineSyntax())
    }
}

三处就是：每个 import 带 /v2；gemini.NewModel 和 l.Execute 的第一个参数是 ctx。

⑤ 跑起来：先问它一句话，链路就通了#

go build ./... && go vet ./...   # 先过静态检查
go run . console                 # 进控制台，随便问一句

看到回答，说明模型、launcher、会话整条链路通了。不知道有哪些子命令？让它自己说：

go run . --help

别搞混 adkgo：它是「发货工具」不是「软件本体」。

go install google.golang.org/adk/v2/cmd/adkgo@latest

adkgo 只管 deploy（推到 Cloud Run / AgentEngine）；跑 Agent 的是你自己 main.go 编译出来的程序。旧专栏拿 adk version 当运行入口，那是 v0.x 遗留，现在失效。

⑥ 验证清单：新机开机自检，全绿才算装完#

go version                                  # ≥ go1.26.6
go list -m google.golang.org/adk/v2         # v2.4.0
go build ./... && go vet ./...              # 无输出
go run . console                             # 问一句有回答

上生产再加一条留痕（把依赖版本钉进发布记录）：

go version -m "$(go env GOPATH)/bin/myagent" | grep 'adk/v2'

卡住了看这 5 行#

现象 一句话原因 处理
requires go >= 1.26.6 Go 或 go 指令低 升 Go；go get go@1.27.1
卡在 toolchain 下载 代理没同步 toolchain 路径 换 GOPROXY，或 GOTOOLCHAIN 指本地工具链
unresolved import 只改了 go.mod 没改 import 按迁移篇 批量重写
400/403 API key 变量没导出 / .env 没加载 echo $GOOGLE_API_KEY 核对
找不到 adk 命令 2.x 叫 adkgo 重装 .../cmd/adkgo@latest，把 $(go env GOPATH)/bin 加进 PATH

（其余少见故障：@latest 拼错位置、Vertex 无凭据、首 build 慢，见站内完整版排查表。）

下一步#

装好之后先立项目结构规范，否则 2.x 的新包（workflow、platform、agentregistry）很容易全塞进一个 main.go 长成坨 —— 见项目结构与 go.mod 规范 。

常见问题

ADK Go 2.x 怎么安装？

在项目里执行 go get google.golang.org/adk/v2@v2.4.0；生产环境锁具体版本号，不要用 @latest。

adkgo 是什么，怎么装？

go install google.golang.org/adk/v2/cmd/adkgo@latest 装的是部署 CLI（adkgo deploy cloudrun / agentengine），它不用于运行 Agent，运行期子命令来自你 main.go 里的 launcher。

为什么 go install google.golang.org/adk/cmd/adk@latest 失败？

因为 2.x 树里没有 cmd/adk 包，CLI 已改名 cmd/adkgo；且 adkgo 没有 version 子命令，查版本请用 go list -m google.golang.org/adk/v2。

运行 Agent 前必须配置什么？

Gemini 路线设 GOOGLE_API_KEY；Vertex AI 路线设 GOOGLE_GENAI_USE_VERTEXAI=true、GOOGLE_CLOUD_PROJECT、GOOGLE_CLOUD_LOCATION 并完成 gcloud auth application-default login。

ADK Go 会自动读 .env 吗？

不会。官方样例统一用 os.Getenv 取值，没有内置 .env 加载器；需要 .env 就自己引入 godotenv 或用 direnv / systemd Environment。

第一个 Agent 怎么跑起来？

go run . console 进控制台；go run . --help 或让程序在报错时打印 l.CommandLineSyntax() 看当前 launcher 支持哪些子命令。
