模块 10：生产化

能跑 ≠ 能上线。这个模块处理三件事：谁能调我的 Agent（registry + authn/authz）、我怎么知道它跑成什么样（plugin + telemetry）、我怎么证明它没退化（评测）。

事实边界

  • 2.x 独有的包：agentregistry（client.go / factory.go / registry.go / requester.go / resolve.go）、auth + auth/gcp、server/authn、server/authz、plugin/agentanalytics（独立 go.mod，需单独 go get）。v1.7.0 树里都没有这几个。
  • agentregistry 的样例：examples/agentregistry。
  • 遥测实现：telemetry/{config,setup_otel,telemetry}.go；入口样例 examples/telemetry；launcher.Config.TelemetryOptions []telemetry.Option。节点级 span 有个专门开关：NodeConfig.EmitsOwnSpan——为 true 时调度器不再包 invoke_node span，因为节点自己会发 invoke_agent，这样 span 树才和直连路径以及 adk-python 对齐。
  • Go 侧没有独立的 eval 包（v2.4.0 全树只有一个内部路由 server/adkrest/internal/routers/eval.go）。因此「评测」不能照抄 Python ADK 的说法，本模块给的是可落地的三条路：事件序列 goldenfile、外部评测（Python ADK / 自建评分器打 REST 端点）、以及节点级断言 + StrictContextMock 单测。这是本专栏与多数二手教程的区别之一，写作时会把边界写死。
