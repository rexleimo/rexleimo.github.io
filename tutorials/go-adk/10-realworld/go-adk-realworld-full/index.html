端到端项目实战：从需求到部署的完整流程#

用一个完整项目——智能客服系统——串联所有知识点，体验从零到生产的完整过程。

项目需求#

智能客服系统：

  • 用户提问，Agent 自动回答
  • 涉及多个业务域：订单、物流、售后
  • 需要接入内部 API
  • 需要多轮对话记忆
  • 需要流式输出

架构设计#

用户 ──→ Web UI ──→ Go Agent（路由）──┐
                 │                      │
        ┌────────┼────────┐              │
        ↓        ↓        ↓              │
    订单Agent  物流Agent  售后Agent      │
        │        │        │              │
        └────────┼────────┘              │
                 ↓                       │
           内部 API（订单/物流/ERP）    │
                                        │
        A2A ← 其他 Agent（Python）←───┘

实现步骤#

1. 环境搭建#

go mod init customer-service
go install google.golang.org/adk/cmd/adk@latest

2. 实现 Tool#

type orderTool struct{}

func (t orderTool) Name() string    { return "query_order" }
func (t orderTool) Description() string { return "查询订单状态" }
// ...

3. 配置路由#

router := team.NewRouter(
    team.WithRoute("order", isOrderQuery, orderAgent),
    team.WithRoute("logistics", isLogisticsQuery, logisticsAgent),
)

4. 部署#

Docker 构建 → Cloud Run 部署 → HTTPS 配置

完整代码结构#

customer-service/
├── agent.go              # 主入口
├── tools/
│   ├── order.go
│   ├── logistics.go
│   └── after_sales.go
├── agents/
│   ├── router.go
│   ├── order_agent.go
│   └── ...
├── Dockerfile
└── docker-compose.yml

小结#

端到端项目完成。结合了以下模块的知识：

  • 模块 2：快速入门（Agent 基础）
  • 模块 3：工具使用（Tool 实现）
  • 模块 4：记忆（Session/State）
  • 模块 5：多 Agent（Router）
  • 模块 6：流式输出
  • 模块 7：部署（Docker/Cloud Run）
  • 模块 8：A2A（跨语言）
