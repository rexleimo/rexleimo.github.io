Web 界面部署与维护：让用户通过浏览器使用#

把 Agent 部署成 Web 服务，用户通过浏览器直接使用。不只是 API，还带 UI。

启动 Web 服务#

./my-agent web api webui --port 8080

服务地址：

  • API：http://localhost:8080
  • Web UI：http://localhost:8080/webui

HTTPS 配置#

生产环境必须用 HTTPS。

使用 Nginx 反向代理#

server {
    listen 443 ssl;
    server_name my-agent.example.com;

    ssl_certificate /etc/ssl/certs/my-agent.crt;
    ssl_certificate_key /etc/ssl/private/my-agent.key;

    location / {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE 支持
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 86400;
    }
}

使用 Let’s Encrypt 免费证书#

certbot --nginx -d my-agent.example.com

高可用方案#

多实例 + 负载均衡#

                    ┌─────────────┐
浏览器 ──→ Nginx ───│ Load Balancer │
                    └─────────────┘
                        ↓     ↓
                   ┌────────┐ ┌────────┐
                   │Runtime │ │Runtime │
                   │实例 1  │ │实例 2  │
                   └────────┘ └────────┘

配置多个 Runtime 实例，Nginx 负载均衡：

upstream runtime {
    server 127.0.0.1:8080;
    server 127.0.0.1:8081;
    server 127.0.0.1:8082;
}

server {
    location / {
        proxy_pass http://runtime;
    }
}

Session 共享#

多实例需要共享 Session，用 Redis：

runtime, _ := agentruntime.New(ctx,
    agentruntime.WithRedisStore(redisClient),
)

运维监控#

健康检查端点#

curl http://localhost:8080/health
# 返回：{"status": "ok"}

Prometheus 指标#

接入 Prometheus 监控：

runtime, _ := agentruntime.New(ctx,
    agentruntime.WithPrometheusMetrics(":9090"),
)

常见问题#

Q：Nginx 代理后 WebSocket 不工作 A：需要配置 WebSocket 支持：

proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";

Q：多实例下 Session 不一致 A：必须使用共享 Session 存储（Redis）。

Q：CORS 问题 A：配置 Nginx 允许跨域：

add_header 'Access-Control-Allow-Origin' '*';
