ADK Go 安装与快速验证：跑通你的第一个 Agent#

Go 环境就绪，开始装 ADK Go。装完跑官方 Quickstart 的例子——一个能回答"现在几点了"的简单助手。

安装 ADK Go#

方式一：go install（推荐）#

ADK Go 通过 go install 安装：

go install google.golang.org/adk/cmd/adk@latest

这个命令把 adk 装到 $GOBIN（通常是 $HOME/go/bin）。

验证安装：

adk version
# 输出：adk version v0.2.0 或类似

command not found 的话，确认 $GOBIN 在 PATH 里：

export PATH=$PATH:$HOME/go/bin
adk version

方式二：从源码编译#

想看源码或用最新版开发分支：

git clone https://github.com/google/adk-go.git
cd adk-go
go build -o adk ./cmd/adk
./adk version

获取 Gemini API Key#

ADK Go 用 Google Gemini 模型，需要 API Key。

获取方式：

  1. 访问 Google AI Studio 外部链接
  2. 点击 “Create API Key”
  3. 复制生成的 key

设置环境变量：

export GOOGLE_API_KEY="your-api-key-here"

每次运行 Agent 前加载这个 key，也可以写到项目根目录 .env（后面会讲到）。

快速验证：跑通 Hello World Agent#

ADK Go 项目最小只要两个文件：

my_agent/
├── agent.go      # Agent 代码
└── .env          # API Key

创建项目#

mkdir -p my_agent && cd my_agent
touch agent.go .env

写入 Agent 代码#

把下面代码写入 agent.go：

package main

import (
	"context"
	"log"
	"os"

	"google.golang.org/adk/agent"
	"google.golang.org/adk/agent/llmagent"
	"google.golang.org/adk/cmd/launcher"
	"google.golang.org/adk/cmd/launcher/full"
	"google.golang.org/adk/model/gemini"
	"google.golang.org/adk/tool"
	"google.golang.org/adk/tool/geminitool"
	"google.golang.org/genai"
)

func main() {
	ctx := context.Background()

	model, err := gemini.NewModel(ctx, "gemini-flash-latest", &genai.ClientConfig{
		APIKey: os.Getenv("GOOGLE_API_KEY"),
	})
	if err != nil {
		log.Fatalf("Failed to create model: %v", err)
	}

	timeAgent, err := llmagent.New(llmagent.Config{
		Name:        "hello_time_agent",
		Model:       model,
		Description: "Tells the current time in a specified city.",
		Instruction: "You are a helpful assistant that tells the current time in a city.",
		Tools: []tool.Tool{
			geminitool.GoogleSearch{},
		},
	})
	if err != nil {
		log.Fatalf("Failed to create agent: %v", err)
	}

	config := &launcher.Config{
		AgentLoader: agent.NewSingleLoader(timeAgent),
	}

	l := full.NewLauncher()
	if err = l.Execute(ctx, config, os.Args[1:]); err != nil {
		log.Fatalf("Run failed: %v\n\n%s", err, l.CommandLineSyntax())
	}
}

写入 API Key#

echo 'export GOOGLE_API_KEY="your-api-key"' > .env

运行 Agent#

source .env  # 加载环境变量
go run agent.go

正常会看到 ADK Go 交互式界面。试着问：

What time is it in Shanghai?

Agent 通过 Google Search 查询后回答。

Agent 运行的两种方式#

ADK Go 支持两种运行模式：

CLI 模式#

go run agent.go

纯命令行交互，适合调试和自动化脚本。

Web 模式#

go run agent.go web api webui

启动 Web 服务器（默认 localhost:8080），浏览器打开能看到聊天界面。

目录结构规范#

一个正式的 ADK Go 项目：

project_name/
├── agent.go              # 主入口
├── .env                  # 环境变量（不提交到 git）
├── .gitignore
├── go.mod
├── go.sum
└── README.md

.gitignore：

.env
.env.local
go.sum

常见问题#

Q：go install 报 certificate signed by unknown authority A：可能是公司网络有限制代理。用 go env -w GOPROXY=https://goproxy.cn,direct 切换代理，或关闭代理。

Q：运行 Agent 报 401 Unauthorized A：API Key 无效或未加载。确认 GOOGLE_API_KEY 环境变量正确设置：echo $GOOGLE_API_KEY 应该有值。

Q：运行 Agent 报 failed to create model A：通常是网络问题，无法访问 Gemini API。在中国大陆需要代理。
