Event 处理：实时捕获 Agent 输出#

Streaming 模式下，每个输出都是 Event。理解 Event 类型，才能实现实时、交互式的 Agent 输出体验。

Event 处理流程#

stream, _ := agent.RunStream(ctx, userInput)

for {
    event, err := stream.Recv()
    if err == io.EOF {
        break
    }
    // 处理 event...
}

各种 Event 的处理#

TextDelta：文本增量#

if event.Type == event.TextDelta {
    fmt.Print(event.Text)  // 实时打印
}

ToolCall：工具调用#

if event.Type == event.ToolCall {
    fmt.Printf("\n[调用工具: %s, 参数: %s]\n",
        event.ToolName, event.ToolArgs)
}

ToolResult：工具结果#

if event.Type == event.ToolResult {
    fmt.Printf("[工具返回: %s]\n", event.ToolResult)
}

Done：完成#

if event.Type == event.Done {
    fmt.Println("\n[Agent 执行完成]")
}

实战：Web 实时聊天#

func handleChat(w http.ResponseWriter, r *http.Request) {
    userInput := r.FormValue("input")

    stream, _ := agent.RunStream(ctx, userInput)

    flusher, _ := w.(http.Flusher)
    w.Header().Set("Content-Type", "text/event-stream")
    w.Header().Set("Cache-Control", "no-cache")
    w.Header().Set("Connection", "keep-alive")

    for {
        event, err := stream.Recv()
        if err == io.EOF {
            break
        }

        data, _ := json.Marshal(event)
        fmt.Fprintf(w, "data: %s\n\n", data)
        flusher.Flush()
    }
}

常见问题#

Q：Event 顺序有保证吗 A：是的，同一个 Stream 内的 Event 按生成顺序到达。

Q：可以中途取消吗 A：可以。stream.Cancel() 或关闭请求。

Q：ToolCall 和 ToolResult 的顺序 A：先 ToolCall（开始调用），后 ToolResult（返回结果）。
