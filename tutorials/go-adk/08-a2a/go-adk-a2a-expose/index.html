Exposing：暴露 Go Agent 给外部调用#

把 Go Agent 通过 A2A 暴露给外部，让其他 Agent 或系统可以调用它。

基础暴露#

server, _ := a2a.NewServer(ctx,
    a2a.WithAgent(myAgent),
    a2a.WithPort(8080),
)

server.Serve()

端点：http://localhost:8080/a2a

服务注册#

让其他 Agent 能发现这个 Agent：

server, _ := a2a.NewServer(ctx,
    a2a.WithAgent(myAgent),
    a2a.WithServiceInfo("weather-agent", "1.0.0"),
    a2a.WithPort(8080),
)

server.Serve()

认证配置#

生产环境应该加认证：

server, _ := a2a.NewServer(ctx,
    a2a.WithAgent(myAgent),
    a2a.WithAuth(a2a.APIKeyAuth("my-api-key")),
)

常见问题#

Q：Agent 暴露到公网安全吗 A：必须加认证（HTTPS + API Key 或 OAuth）。

Q：可以限制调用频率吗 A：配置限流：a2a.WithRateLimit(100, time.Minute)
