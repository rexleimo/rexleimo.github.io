Herdr 的日常使用：鼠标优先工作流（点击窗格、拖动分割线、右键菜单）、前缀键 ctrl+b 与 prefix-free 键位方案、以及 detach / 快照恢复 / 历史回放 / agent 原生 resume / live handoff 五条状态路径的准确差别。基线 herdr 0.9.2 stable。
3 篇内容

模块 1：日常操作

装好之后，这一模块解决「每天怎么用」：先鼠标、后键盘、再把状态这件事彻底搞明白。 其中第 3 篇是全专栏最容易被跳过、也最容易吃亏的一篇——因为「关掉窗口之后我的 agent 还在不在」 这个问题有五个不同的答案，取决于你走的是哪条路径。

基线：herdr 0.9.2 stable · 文档源 pinned v0.9.2

前置要求

  • 已完成模块 0 第 2 篇 的安装与验证
  • 读过模块 0 第 3 篇 的四层概念（否则第 3 篇的状态路径会看不懂）

学习目标

完成本模块后，你能回答：

  • 完全不背键位，靠鼠标能做哪些事，哪些事必须上键盘
  • 前缀键的工作方式（按下 ctrl+b、松开、再按动作键），以及为什么直接绑定 ctrl+alt 组合键有时会「什么都不发生」
  • copy mode 怎么进、怎么选、怎么搜；文本字段里的编辑键和 pane 里的键为什么不是一套
  • 怎样配出一套prefix-free 键位，以及官方推荐的 ctrl+alt 方案里哪些组合是安全的
  • detach、机器重启、herdr update、agent 自己退出——这四种情况下分别什么活着、什么死了、什么能恢复
  • 「pane 历史回放」和「agent 原生会话恢复」的差别，以及为什么后者需要装集成
  • live handoff（herdr update --handoff）解决什么问题，它的前提条件和已知副作用

一句话结论

新手路线：第 1 篇全程用鼠标跑通一个 workspace + 一个 agent，够用了再去碰第 2 篇的键位。 但第 3 篇请一定读——它决定了你敢不敢在跑着长任务的 agent 上合笔记本盖子。
