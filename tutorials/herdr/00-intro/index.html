模块 0：认识 Herdr

动手之前先把三件事钉死：Herdr 是什么（以及不是什么）、怎么装对并自证装对了、 六层概念模型各自该按什么粒度用。这三件事定了，后面所有模块都不会读歪。

基线：herdr 0.9.2 stable · 文档源 pinned v0.9.2 · 本机实测平台 macOS / Apple silicon

篇章列表

序号篇名slug状态

前置要求

  • 会用终端（能 cd、ssh、看懂环境变量）
  • 不需要任何 tmux / zellij / screen 经验——第 1 篇会解释为什么这次可以先不背键位
  • macOS / Linux / Windows x86_64 任一平台（Windows ARM64 走模拟，见第 2 篇）

学习目标

完成本模块后，你能回答：

  • Herdr 和 tmux 的本质差别在哪三条上，以及为什么这三条都是「pane 里跑 agent」之后才出现的需求
  • 五种安装渠道（直装脚本 / Homebrew / mise / Nix / 手动下载）分别怎么升级，为什么只有一种能用 herdr update
  • stable 和 preview 两个 channel 的取舍，以及 Windows 老 preview 安装为什么切不回 stable
  • session / workspace / tab / pane 四层的包含关系，以及「什么时候该开新 workspace、什么时候只该开新 tab」
  • 五种 agent 状态（blocked / working / done / idle / unknown）各自的准确含义，以及 done 和 idle 为什么容易混
  • terminal / prefix / navigate 三种模式分别在干什么，前缀键为什么默认是 ctrl+b

一句话结论

如果你只想先用起来：读完第 2 篇装好，直接跳到模块 1 用鼠标操作， 概念遇到再回来查第 3 篇。如果你是从 tmux 迁过来的：先读第 3 篇对齐术语， 否则你会一直拿 tmux 的心智模型套 Herdr，然后在 session 和 workspace 这两层上反复搞混。
