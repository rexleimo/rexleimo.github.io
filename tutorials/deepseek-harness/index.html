DeepSeek Harness 权威指南：架构解析与二次开发

本专栏是 DeepSeek Harness（dsh）的中文权威指南，兼顾框架原理讲解与二次开发实战两条线。所有代码都在本机真实构建运行过，所有界面截图来自真实 Web UI，所有架构结论都标注了源码位置。

2026 年 8 月 13 日，DeepSeek AI 开源了 DeepSeek Harness——3 天收获 12 万 star，npm 周下载量逼近 20 万。 它的口号只有一句话：Everything is a Plugin（一切皆插件）。模型适配器是插件，工具是插件，会话日志是插件，连 agent 主循环本身都是插件。

这个专栏要回答的问题是：“一切皆插件"到底是营销口号，还是真的做到了？如果做到了，它是怎么做到的？ 以及更实际的——你如何基于它做二次开发？

快速上手（3 步）

# 1. 需要 Node.js 22.19+
npx @deepseek-ai/dsh web
# 2. 打开 http://127.0.0.1:3080
# 3. 设置 → 模型 → 填入 API 密钥（支持 DeepSeek 或任意 OpenAI 兼容端点）

这个专栏和其他资料有什么不同

  • 官方文档是参考手册：告诉你每个字段在哪、每个配置是什么。它不回答"为什么”。
  • 本专栏是权威指南：每个架构决策都有推演过程（方案 A vs 方案 B、为什么淘汰 A），每个机制都配架构图或时序图，每个关键界面都有真实截图，每段代码都真实运行过。
  • 动手线：8 篇二开教程，从 hello world 到发布，含一个完整的端到端实战案例（代码在 rex-dhs-core 外部链接 仓库）。

阅读建议

  • 想先体验：读快速上手 → A 线第 1-2 篇 → B 线第 1-2 篇。
  • 想深入原理：按 A 线顺序读，第 3 篇（插件树）是理解一切的基础，建议精读。
  • 想直接二开：读 B 线第 1 篇后直接跳第 8 篇实战案例，回头再补原理。
  • 做选型对比：直接看 A 线第 1 篇的对比表。

需要什么

  • Node.js 22.19+（运行 dsh）
  • 一个 LLM API 密钥（DeepSeek / OpenAI 兼容端点 / Anthropic 兼容端点均可）
  • 想二开的话：TypeScript 基础 + pnpm
