    macOS 还是你认识的那个 macOS 吗？一个老用户的真心话

    从 High Sierra 到 Sequoia，macOS 从一个还算自由的操作系统，变成了一个封闭受控的 iOS 延伸。这不是进步，这是倒退。

    January 4, 2025 · 1 min · 191 words · 梦兽编程 -

    那个曾经属于你的房子，现在变成了酒店房间#

    还记得第一次用 Mac 的感觉吗？

    我是 2017 年开始用 Mac 的，那是 High Sierra 的时代。即便那时候，macOS 还算开放，起码感觉这台电脑是你自己的。想装什么软件就装什么，想改什么设置就改什么设置。

    现在的 macOS 呢？更像酒店房间。看着挺精致，但你不能动家具，不能改墙面颜色，连进自己房间都得前台同意。

    这哪是进步啊，这是倒退。

    那些消失的自由，咱一件一件说#

    恢复模式越来越复杂#

    听老用户说，以前的 Mac 出问题了，按住 Command+S 开机就能直接进 root shell 修复。就像家里有个急救箱，不舒服了自己能处理。

    现在呢？这个急救包早就没了。取而代之的是"恢复模式"——一个被严密看守的房间，系统卷只读，还得配合你的 Apple ID。Apple Silicon 上这套加密流程更复杂，复杂到你根本不知道自己在干啥。

    Apple 说这是为了安全。我说这是为了控制。

    Gatekeeper 和沙盒限制越来越严#

    刚用 Mac 那会儿，虽然已经有 Gatekeeper，但起码还能感觉到系统是开放的。想探索系统目录？可以。想装点开发者工具？也没那么多障碍。

    现在第三方应用被关进沙盒，关在 ~/Library/Containers/ 这个迷宫里。想访问系统文件夹？没门。想写底层工具？抱歉。

    最讽刺的是啥？Apple 自己的应用不受这些限制。就像你家人能随便进你房间，而你连自己客厅都不能进。

    他们说这是安全。你失去的是控制权。

    硬件淘汰：不是不能用，是不让你用#

    你那台还能跑得很好的 Intel Mac，突然就被宣布"不支持"了。没啥技术原因，就是市场原因。

    买新的吧，买 M 系列吧。旧东西虽然能用，但就是要让它变得难用。

    有些应用也会跟着"自动退役"，不管你硬件还能不能跑。整个生态系统都在推着你往前走，但只能走 Apple 指定的那条路。

    软件质量：一年一个半成品#

    以前有些版本发布就是为了稳定和修复。现在每年发一个新版本，不管有没有准备好。

    Finder 闪退？正常。应用崩溃？习惯了。新功能上线一年就消失？见怪不怪。

    以前修 bug 是版本卖点，现在发版本就是为了让旧版本看起来需要被替换。

    Disk Utility：从工具箱变成了玩具箱#

    看看以前的 Disk Utility：详细的日志，高级分区选项，RAID 工具，清晰的系统反馈。这是给专业人士用的工具。

    图：曾经功能强大的 Disk Utility

    现在的 Disk Utility 呢？大按钮，少选项，能做的事情少得可怜。你需要高级功能？去用命令行吧。或者买第三方工具。

    这不是简化，这是阉割。

    SIP 和 Secure Boot：你连自己机器都做不了主#

    System Integrity Protection，密封系统卷，T2 芯片。这些东西加在一起，让你连换个 SSD 都能让机器变砖。

    Apple 说这是为了防止恶意软件。我说这是为了防止你自己对自己机器做主。

    想装旧版本 macOS？在 Intel Mac 上就已经很难了，在 Apple Silicon 上根本不可能。Apple 控制整个启动链，验证每个组件。你不再拥有这台机器，你只是在借用它，只要 Apple 的固件允许。

    AppleScript 和 Automator：被 iOS 污染的遗产#

    AppleScript 和 Automator 曾经是 macOS 的骄傲，是让普通人也能自动化的魔法。

    现在它们被半放弃了，被 iOS 风格的 Shortcuts 取代。Terminal 还在，但它和系统的联系越来越弱，更像一个沙盒里的玩具。

    很多人现在用 Homebrew 来填补空白。但这不算真正的包管理，它只是在用户空间堆文件，活在 /usr/local 或 /opt/homebrew 的平行宇宙里。

    能用，但感觉像是补丁，不是方案。

    UI 设计：从清晰实用变成了模糊花哨#

    macOS 曾经有独特的身份：锐利，触感清晰，一眼就能认出来。

    现在呢？它是 iOS 的镜像，过度的半透明，对比度越来越差。Liquid Glass 设计风格本来是给 iOS 的流体感设计的，现在硬塞到 macOS 上。有些地方按钮真的会模糊进背景，对比度不一致，窗户像一层层磨砂塑料。

    不是灾难，但当你习惯了干净实用的桌面，现在的 macOS 有时候就是想硬凑 iPad 美学。

    Apple Silicon：技术奇迹，也是自由的葬礼#

    Apple 转用自己的芯片 M1、M2、M3 及以后，确实是技术奇迹。但这也是灵活性的最后一颗钉子。

    他们现在控制整个堆栈，从硅到软件，可以精确决定你的设备何时过时。最糟的是啥？这个决定不需要讲道理，只需要服务 Apple 的时间表。

    一个时代的结束#

    macOS 没有进化，它迁移了。

    从几年前还算是开放、可定制的系统，变成了 Apple 围墙花园里一个密封的、严格管理的组件。

    安全性和一致性确实提高了，但代价是自由、透明和信任。

    Apple 说这是进步。但对我们这些经历过 macOS 那个还算自由时代的人来说，这感觉像是所有让 macOS 变得可爱的东西正在一点点消失。

    我希望我是在悲观，但这确实就是现在的方向。

    最后想说的话#

    说了这么多，不是让你别用 Mac。Mac 依然是好用的生产力工具，只是它和以前不一样了。

    以前是你拥有一台 Mac，现在是 Apple 借给你一台 Mac。区别就在这儿。

    接受这个现实，然后在限制中找到最适合自己的用法。这才是我们能做的。

    这篇文章写的是 macOS，其实写的也是整个科技行业的趋势：开放变封闭，用户变消费者，工具变平台。

    趋势不可逆，但至少我们还能选择怎么用、用什么。
