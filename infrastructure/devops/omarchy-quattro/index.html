Omarchy Quattro 上手体验：DHH 把 Linux 桌面做成了

Omarchy 4（Quattro）发布，整个桌面壳用 Quickshell 重写。从安装到日常使用，聊聊这个由 DHH 主导、基于 Arch + Hyprland 的 Linux 发行版真实体验。

August 16, 2026 · 2 min · 288 words · 梦兽编程 -

Omarchy 4，代号 Quattro，在 2026 年 8 月 14 日正式发布了。这是 DHH（David Heinemeier Hansson，Ruby on Rails 和 Basecamp 的创始人）主导的 Linux 发行版自诞生以来最大的一次更新。

说实话，Linux 桌面折腾了这么多年，一直有人在试图回答一个问题：有没有一个发行版，既能让你享受到 Arch 的新软件、Tiling WM 的效率，又不需要先把命搭在配置文件里？ Omarchy 就是冲着这个答案去的。而 Quattro 这一步，更像是在说：我不光要解决这个问题，我还要让它好看、顺手、开箱即用。

这篇文章就从用户体验的角度，聊聊 Omarchy Quattro 到底用起来怎么样。

它不是另一个 Arch 衍生版#

Omarchy 基于 Arch、Hyprland 和 Quickshell，但核心卖点不是"Arch 系"，而是 opinionated（有主见）。

DHH 在手册里写得很直接：这不是 Windows，也不是 macOS，不打算让你觉得熟悉，而是想让你接受一种新的、他认为更美的工作方式。它预装的不是一堆默认软件，而是 DHH 自己日常在用的工具：Neovim、Chromium、Obsidian、LibreOffice、Kdenlive、OBS，甚至还有一个复古 Winamp 风格音乐播放器。

这种"我吃什么你吃什么"的思路，听起来很独裁，但对那些不想做选择的人来说，反而是一种解脱。你不用纠结用哪个终端、哪个编辑器、哪个截图工具，打开就用。

安装：比我想象中快得多#

Quattro 的安装体验给我最深的印象就是快。

官方说新版 ISO 压到了 6GB 以下，安装速度提升了 30%，在较新的机器上可以做到一分钟以内装完。我自己在虚拟机里跑了一遍，虽然没到一分钟那么夸张，但确实比普通 Linux 发行版快很多。

安装界面不花哨，但很清晰：全盘安装或利用空闲空间双系统安装（装 Windows 双系统要记得关 BitLocker）。默认会启用全盘加密。流程就是选语言、键盘、磁盘、账户、时区，然后等进度条跑完。

另外 Quattro 加了一个很贴心的功能：延迟首次启动配置。你可以先帮别人把系统装好，机器交给对方之后，对方在第一次启动时再设置账户、密码、时区。对 OEM 或者给家人装机的人来说非常实用。

桌面壳：这次是真的"一个东西"#

Quattro 最大的架构变化，是把整个桌面壳用 Quickshell 外部链接 重写了。

之前 Omarchy 的 top bar、启动器、通知、锁屏、OSD 等组件分别来自 Waybar、Walker、Mako、SwayOSD、hyprlock、hypridle、swaybg、polkit-gnome 等一堆独立程序。到了 Quattro，这些全被整合进一个长期运行的 Quickshell 进程，通过插件化方式管理。

从用户体验上来说，这个变化带来的最大好处是：统一。

主题切换时，不再是终端、bar、菜单、通知各自为政；现在一套主题同时作用于 Hyprland、GTK、Neovim、VS Code:、btop、菜单、通知、OSD 和锁屏。右键主题切换器就能看到所有主题实时预览，不用装完才发现某个地方颜色不搭。

启动器与菜单合二为一#

Quattro 把启动器合并进了 Omarchy 菜单。Super + Space 现在同时搜索应用、设置和命令，类似一个原生命令面板。

实际用下来，响应很快， fuzzy 匹配和首字母缩写都能工作，刚安装的软件图标也能立即出现。Super + Alt + Space 则只搜应用。如果你怀念之前 Walker 的网页搜索回车功能，那得自己补一下——社区已经有人在 GitHub 上提这个 issue 了。

控制面板：终于不用记命令了#

以前调音量、亮度、网络、蓝牙，在 tiling WM 环境下往往是命令行或独立小工具。Quattro 给这些常用功能都做了原生控制面板，快捷键也很好记：

  • Super + Ctrl + A：音频
  • Super + Ctrl + W：网络
  • Super + Ctrl + B：蓝牙
  • Super + Ctrl + D：显示
  • Super + Ctrl + P：电源

网络面板做得尤其细：实时上下行、ping、丢包、一键测速、DNS 选择、Wi-Fi QR 分享、附近网络列表，基本把日常要用的网络工具都包进去了。音频面板也能在输出/输入设备之间快速切换，还加了保持播放连续性的处理。

这种把"系统设置"直接做到桌面壳里的思路，让 Omarchy 比之前更像一个完整的桌面系统，而不是一堆工具的拼贴。

主题与视觉：这次确实好看#

Quattro 把主题色从 8 个基础色扩展到了 24 个语义色，并且新增了 Solitude、Last Horizon、Lupine 三个主题。

更实用的是，~/.config/omarchy/shell.toml 作为机器级覆盖配置，可以覆盖字体、间距、bar 位置等个人偏好，而且修改后会实时生效。这意味着你可以切换主题，但个人的微调不会被覆盖。

Bar 也支持拖拽放到屏幕四边，双击空白处切换透明/不透明。这些细节让桌面不再只是"能看"，而是真的"顺手"。

默认应用与 AI 代理#

Quattro 新增了三款默认小工具：

  • Omawrite：Markdown 写作工具，替代 Typora，绑定 Super + Shift + W
  • Omacut：基于 ffmpeg 的视频裁剪工具
  • Omacalc：计算器，替代 GNOME Calculator

另外，Quattro 把 AI 编程代理做进了默认配置。你可以在 Setup > Defaults > Agent 里选 Claude Code、Codex、OpenCode、Pi、Gemini、Grok、Copilot 等，首次使用时会懒加载安装。之后 Super + Shift + Ctrl + A 或终端里输入 a 就能启动，默认在 ~/Work 目录打开，让"信任上下文"这件事落到实处。

Bar 上还有一个模型使用量小部件，显示 Claude Code / Codex 的使用统计。当某个进程崩溃时，系统会弹出 toast，点击就能让默认代理基于 coredump 做诊断。

一些真实的槽点#

Quattro 毕竟是大版本刚发布，问题也不少。GitHub issues 里反馈比较多的包括：

  • NVIDIA 50 系显卡安装时会黑屏，需要加内核参数绕过
  • 部分用户升级时磁盘空间不足，导致迁移失败
  • 非美式键盘在新安装里偶尔会被忽略，需要手动修 vconsole.conf
  • 新菜单缺少 Walker 时代的"无匹配时网页搜索"回退
  • 剪贴板历史里的图片预览尺寸过大，会盖住桌面

这些大多是新架构切换期的阵痛，不是设计本身的问题。但从用户角度看，如果你现在就要把它当主力机，建议等一到两个补丁版本，或者在备用机上先体验。

它适合谁？#

Omarchy Quattro 给我的整体感觉是：DHH 终于把 Linux 桌面做成了一套连贯的产品。

它不是给 Linux 新手准备的——你仍然需要接受 tiling window manager、命令行、手动改配置这些概念。但它非常适合这样一群人：

  • 已经厌倦了自己配 dotfiles
  • 想要一个审美在线、开箱即用的 Hyprland 环境
  • 日常工作流以终端、浏览器、AI 代理、Markdown 写作为主
  • 愿意让系统替你做一些选择

如果你还在 Ubuntu 和 Arch 之间摇摆，或者想从 macOS 跳到 Linux 但又怕折腾，Omarchy Quattro 可能是目前最值得试的一个选项。

当然，前提是你的硬件别太冷门，并且做好了当早期用户的准备。

常见问题

Omarchy Quattro 是基于什么构建的？

它基于 Arch、Hyprland 和 Quickshell，由 DHH（David Heinemeier Hansson）主导开发。

Omarchy Quattro 的安装体验如何？

安装速度很快，官方称新 ISO 压到 6GB 以下，安装速度提升 30%，在较新机器上可一分钟内装完。支持全盘安装或利用空闲空间双系统安装，默认启用全盘加密，还提供了延迟首次启动配置功能。

Quattro 在桌面架构上有什么变化？

它用 Quickshell 重写了桌面壳，把 top bar、启动器、通知、锁屏、OSD 等组件整合进一个长期运行的 Quickshell 进程，主题切换时一套主题可同时作用于 Hyprland、GTK、Neovim、菜单、通知等，保持统一。

如何启动 AI 编程代理？

在 Setup > Defaults > Agent 里选择 Claude Code、Codex、OpenCode 等，首次使用时会懒加载安装。之后按 Super + Shift + Ctrl + A 或在终端输入 a 启动，默认在 ~/Work 目录打开。

Omarchy Quattro 目前有哪些已知问题？

主要有：NVIDIA 50 系显卡安装时可能黑屏需加内核参数绕过；部分用户升级时磁盘空间不足导致迁移失败；非美式键盘偶尔被忽略需手动修 vconsole.conf；新菜单缺少网页搜索回退；剪贴板历史图片预览尺寸过大。
