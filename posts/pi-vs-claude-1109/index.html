coding harness 成主战场：一个老用户为什么把 Claude Code 换掉

coding agent 的战场从模型挪到壳：配置两份、单会话、15k token 系统提示，迁移痛点全在 harness 上。

November 9, 2026 · 2 min · 278 words · 梦兽 -  |  English

一个用了 Claude Code 一年多的用户，某天决定把它撤下主力位，换到开源的 Pi。他做完决定才一天，Anthropic 就宣布 Claude Code 开始支持 AGENTS.md 文件，像是专门放出来留他的。他原话说，太晚了一步。

这事本身不算新闻，但它戳中的是一层更底的东西：coding agent 的战场，已经从模型挪到了模型外面那层壳。模型层越卷越像大宗商品，真正决定你每天用着顺不顺手、token 花得多不多、能不能长成一个团队的私有工作流，是 harness——那个负责组装上下文、描述工具、管会话、下权限的壳。这次迁移被列出来的每一个痛点，都长在壳上，不在模型上。

模型在收敛，摩擦沉进了壳里#

Claude Code 会写代码，这早不构成切换理由。它被抱怨的地方，没有一处是「模型不聪明」，全是指向壳：配置文件怎么放、会话怎么连、命令齐不齐、系统提示多长。一个用了一年的人把「哪不顺手」逐条列出来，那份清单本身就是一张产品体检表，比任何广告都诚实。

把视角拉高一点看，这层壳为什么成了竞争前沿。模型每代都在把「能不能写对」的差距抹平，编码能力成了大家都能打的底子。

真正拉开体感的，是你每天和那个壳打交道时的摩擦系数：上下文装得多不多、命令在不在、会话连不连得上、配置文件要不要两份。这些不在模型评测里，也不进 benchmark，却决定了一个工具是「顺手」还是「每步都卡」。壳做顺了，用户愿意把整个工作流搬进来；壳做糙了，再强的模型也留不住人。

格式割裂是封闭源的典型毛病#

AGENTS.md 和 CLAUDE.md 是两套记忆格式。前者是一个跨工具在推的标准，后者是 Claude Code 自己的私有格式。结果就是，同一个「项目约定」要维护两份，用户要在两种格式之间来回拷、建软链。CLAUDE.md 散在 GitHub 上一堆仓库里，对 Claude 是渗透式营销，对别的工具是负担。

耐人寻味的是顺序：标准是开源侧先立起来的，Anthropic 是后补的。用户用脚投票选了 AGENTS.md 阵营，Claude Code 才宣布支持。一家厂商靠补标准来留人，本身就说明它在这点上迟到了。私有格式当标准卖，是封闭生态的老毛病——先占坑，再喊「我们也支持」。

单会话、断掉的命令，是看不见的损耗#

Claude Code 在 VSCode 里只能有一个会话「连着」IDE。你另开一个 tab 起另一摊活，原来那个还在跑，新开的就收不到选中文本事件了。这个行为至少从 2025 年 12 月就被报过，issue 被当「和某个无关 bug 重复」关掉。官方 GUI 扩展能开多 tab，但一半内置 slash 命令在里面根本不生效，自定义状态行也不支持。

这类问题单个不致命，叠起来就是每天的小摩擦。用户切到 Pi 之后，写个多 tab 选择的扩展只花了大约 20 分钟——不是原产品做不出来的活，是没人负责把它当主线做。功能被拆散到扩展里，没人拍板优先级，用户就得自己捡起来补。

prompt 臃肿有一笔隐藏的账#

默认 Bash 工具的描述接近 3,000 token，一大半在教模型怎么用 git、怎么在 GitHub 上开 PR。模型早就知道这些，这些字每轮都在吃上下文。官方把系统提示砍了 80%，Claude Code 的开销仍然比 Pi 高得多——Pi 的设计起点是四个工具、系统提示压在一千 token 以内，而一份横向对照把 Claude Code 的系统提示记在一万五千 token 上下。

这不只是洁癖。把账拉大到规模上：假设一百万日活、每天上亿次请求，每请求砍一千 token，一年省下来的推理成本是七位数起步的量级。系统提示每多一行，都是全量用户在替你付。这是闭源工具很难公开算的一笔账，但用户端能感受到：上下文被塞满，真正留给你的任务的空间就被挤掉了。

工具描述里的废话，最后都以你的 token 账单形式落地。更隐蔽的是，3,000 token 的描述还在教模型用 cat <<'EOF' 这种写法，在自动模式普及前会反复触发人工审查规则——省下的 token 没到账，反而多绕了一道。把默认描述里模型本来就会的东西删掉，是纯粹的正收益：不降能力，只减负。闭源工具把默认配置当「最全」来做，开源壳把默认当「最少」来做，长期看后者的 token 账单和上下文干净度都占优。

Pi 的减法：四个工具，一千 token，其余靠扩展#

Pi 是个 TypeScript monorepo，拆成六个包：统一多供应商 LLM 接口、agent 运行时、终端 UI、coding agent CLI，再加 web UI 组件和 GPU 部署工具。核心只给模型 read、write、edit、bash 四个工具，子代理、plan 模式、MCP 都不内置，靠 TypeScript 扩展和 Pi 包按需装。它由 Mario Zechner 起步，2026 年 5 月转到 Earendil 名下，npm 包换到 @earendil-works，走 MIT，周下载在二十万次量级。

它还能以四种模式跑：交互式终端、打印或 JSON、给进程集成用的 RPC、以及嵌进你自己应用的 SDK。同一套 agent 循环，对着任何供应商的模型换着用，会话里随时 /model 切换。这套「把能力拆成可替换组件」的思路，和闭源工具「什么都内置、默认全开」正好对着来。

拿起来也快。一行脚本 curl -fsSL https://pi.dev/install.sh | sh 装好，Node 要 22.19 以上，进项目目录敲 pi 就能开工；/login 接现成订阅，或直接 export ANTHROPIC_API_KEY 走 API。不挑模型，接哪个供应商都行。对一个想先低成本试水的团队，这条装到跑的距离，比闭源工具短一截。

扩展还能打包分享。写好的 TypeScript 扩展、技能、提示模板、主题，能打成 Pi 包，走 npm 或 git 分发，pi install 一条命令装上，支持钉版本。团队把「这一摊活怎么干」沉淀成一个包，下一个人复用，不必每次都从头写。这套把工作流变成可分发包的思路，是闭源工具给不了的。

锁定与可切换：壳决定了你能用哪些模型#

Claude Code 只认 Claude，模型是锁死的。Pi 走 bring-your-own-key，十五个供应商以上都能接，Anthropic、OpenAI、Google、AWS、DeepSeek、xAI 这些云端，加上 Ollama、vLLM、SGLang、LM Studio 这些本地推理，会话里 /model 随时切。差别不只在省钱：多供应商意味着壳不绑死你，模型降价了能立刻换，本地有卡了能跑自己的，合规要数据不出门了能全落本地。

落到团队层面，这层可切换性改写的是采购和合规的牌局。单模型壳把「换模型」做成了换工具——要切供应商就得重训团队、重写提示、重接权限。多供应商壳把「换模型」降回一个成本项，甚至能按任务分派：难活挂旗舰模型，杂活挂便宜模型或本地跑，壳还是那套。

数据合规这条更硬：全落本地的选项在医疗、金融、政府这些场景里不是加分项，是准入门槛。壳能不能把模型层抽象掉，直接决定它够不够格进这些部门。

没有人负责说「不」#

迁走的人给 Claude Code 下的判断很直白：它像一个没有强产品观的产品。一群兴奋的工程师和 PM 各自往上面加符合自己工作流的功能，没有人站在高处专职对某些需求说不。产品工程里，「拒绝」和「实现」一样是核心工作，缺了它，工具就长成一堆功能的叠加，用户得自己收拾残局。

Pi 反过来，靠的是克制：能砍的都砍了，边界清楚，剩下的用扩展补。对想把 agent 长成一个团队私有工作流的人，这种可塑性比「开箱全功能」值钱。你能让它长成一摊一摊的分工，而不是被默认配置推着走。

诚实边界#

这是用户体感加产品分析，不是一份 benchmark。Pi 还年轻：没有内置子代理、没有 plan 模式、MCP 走扩展，生态比 Claude Code 薄得多；Claude Code 的成熟生态、官方支持、多模型订阅绑定也是真实价值。两者怎么选，取决于你要的是「稳定克制、可深度定制」还是「开箱即用的全家桶」。一个用了一年的人被小摩擦累积推走，是产品信号，不是「哪家模型更强」的结论。

FAQ#

Pi 是什么，和 Claude Code 什么关系？ 两者都是终端 coding agent 外壳。Pi 开源（MIT）、多模型可插拔，Claude Code 闭源、绑定 Claude。Pi 是「壳」的另一个选择，不是模型替代品。

为什么格式割裂这么致命？ AGENTS.md 是跨工具标准，CLAUDE.md 是私有格式。用户要在两者间拷、建软链，维护两份约定。标准由开源侧先立、闭源后补，靠补标准留人本身就说明迟到了。

prompt 臃肿具体有多大？ 默认 Bash 工具描述近 3,000 token，大半在教 git 和 PR；官方砍了 80% 系统提示，开销仍高于 Pi 的四工具、约千 token 起点，横向对照把 Claude Code 记在一万五千 token 上下。放大到日活上亿，是七位数的年度推理成本。

Pi 缺什么？ 不内置子代理、plan 模式、MCP 一等支持，生态较薄。要这些得靠扩展或 Pi 包自己装，或让模型现场写。

该不该跟着换？ 看你要可塑性还是要开箱全家桶。被小摩擦累积推走的是想要稳定克制、可深度定制的人；生态和官方支持仍是 Claude Code 的真实价值，没有绝对赢家。
