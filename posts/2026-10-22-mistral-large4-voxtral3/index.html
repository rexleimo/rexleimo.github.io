Mistral 一天两发：1T 参数 le Chonk 开预览，语音 agent 管道也一起给了

Mistral 两天两发：1T 旗舰 le Chonk 开预览，Voxtral 3 把语音 agent 整条管道一起给了

October 22, 2026 · 2 min · 254 words · 梦兽编程 -  | 

先说结论：我这两天把 Mistral 的发布节奏翻了一遍，10-06 的 Mistral Large 4 还在 preview 窗口里，10-20 又丢出 Voxtral 3。两发方向完全不同，一个是堆到 1T 总参数的旗舰，一个是把「听—想—说」三段焊成一条流式管道的语音全家桶。我分别拆一下。

Large 4：参数是真的 1T，先把几个数字钉死#

我拿到的官方数：Mistral Large 4 是细粒度 Mixture-of-Experts，总参数 1.05T、单 token 激活约 49B（官方另一处 changelog 写 52B，两处数字没拉平，我按 release post 的 49B 为准，官方自报，我未独立复现），视觉编码器 1.6B，上下文 1M token，原生多模态（图进文出），内置 function calling、结构化输出、文档问答、batch 和 Agents API。官方给的昵称就是 “le Chonk”，内部代号就这么叫的（release post 原词）。

价格官方自报：列表价 $1.36/百万 input、$0.14/百万 cached input、$4.18/百万 output；launch 两周 5 折到 $0.68/$0.07/$2.09。开放权重官方承诺 10 月底给，Hugging Face 上是占位仓库、写 10-31，我截到发帖时还没有权重文件。

能力侧官方说法：cyber 类任务官方自报进前五，legal 和 finance 上官方自报赢 GPT-6 Astra，coding 官方自报强于 DeepSeek 和 Qwen——这三条全是官方自报，我都没跑，仅供参考。

我的判断：1T 总参数 + 49B 激活这个比例，和 Mixtral 时代「小激活大总参」思路一脉相承，但激活 49B 已经接近上一代 Large 3 的总参了，等于把专家规模和激活规模同时往上顶。1M 上下文 + 多模态 + 开放权重（如果月底真给），这是它区别于纯闭源旗舰的卖点。preview 阶段 API 价 5 折，对想压旗舰活儿的人是窗口价。

Voxtral 3：不是发一个模型，是发一条语音 agent 管道#

Voxtral 3 是 10-20 发的，官方 framing 很明确：不做单一旗舰，做一个全家桶。四个模型 + 一个 SDK：

  • Voxtral Small Transcribe 3：高精度转写，官方自报 50+ 语言（含 24 个欧盟官方语言），带说话人分离、context biasing、说话人结束检测
  • Voxtral Mini Transcribe 3：4B 参数批转写，官方自报 $0.0035/分钟
  • Voxtral Mini Transcribe Realtime 3：实时流转写，官方自报 <500ms 延迟，$0.008/分钟
  • Voxtral Speech 3（TTS）：35+ 语言 50+ 方言，$13/百万字符，支持 30 分钟音频克隆

SDK 官方自报基于 LiveKit，把「听（Realtime 转写）→ 想（任意通用模型 + 工具调用）→ 说（Speech 3）」三段做成一条流式管道，官方说法是每段独立完成、互不阻塞，单轮 <1s，说话人打断时 agent 立即闭嘴。支持 SIP（电话）和 WebRTC（浏览器/app）双入口，能接进现有 IVR/contact-center 系统。

第三方数字（Artificial Analysis 实测，官方未自测）：Voxtral Small Transcribe 3 在语音转写榜排第 3，AA-WER 2.1%（ElevenLabs Scribe v2 2.2%、Grok Voice Transcribe 2.0 2.3%）；Realtime 版 960ms 档 3.3%、480ms 档 3.6%，比上代 5.2% 降了一截。TTS 侧两个 arena Elo 分别 1218 和 1068，排第 12。

社区一个实测（我未复现）：有人拿 1891 年 Gustave Eiffel 留声机录音跑 Small Transcribe 3，107 词里对了 100，WER 6.5%——带噪老录音能到这个数，说明对噪声鲁棒性还有一层余量。

争议也摆出来：Voxtral 3 全家桶目前是闭权，上一代 Voxtral 是开放权重，这一代官方没给开放承诺，社区有线程专门吐槽；官方 release post 也没写「以后再开权重」的路线图。

两个合起来看#

一天两发（实际 14 天两发）把「堆旗舰」和「做管道」两条腿都占了。Large 4 是「我比竞品旗舰还大一点、还能开权重」，Voxtral 3 是「我不跟你卷单模型，我把语音 agent 整条管道 + 可自托管打包卖给你」。两个合起来读，Mistral 现在的产品叙事已经很明确：欧洲主权 + 开放权重 + 全场景打包。

你们现在语音 agent 走的是单模型端到端（如 GPT-4o realtime）还是三段拼管道？Voxtral 3 这套 <1s 单轮，生产上能接受吗？开放权重 10 月底给、Voxtral 3 闭权，你们会等权重本地跑 Large 4，还是 API 先用着？
