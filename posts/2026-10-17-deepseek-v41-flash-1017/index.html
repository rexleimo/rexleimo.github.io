DeepSeek V4 半年复盘：今天 1017 更新，小模型正在吃掉旗舰

DeepSeek 今天更新 V4.1-Flash-1017：强化学习 self-feedback 做端到端项目、开源放 HF/ModelScope、Search/Fetch API 全量开放。我把 4 月到 10 月的官方 changelog 串成一条线，配官方 benchmark 表、成本曲线、KV cache 逐代账——每个数字都标了出处，我一句 benchmark 没跑过。

October 17, 2026 · 3 min · 522 words · 梦兽编程 -  | 

今天 DeepSeek 官方 changelog 又更了一条：V4.1-Flash-1017。四个要点，先摆出来：

  1. 强化学习 self-feedback——模型自己从 0 做完一个端到端项目再验收，官方 demo 直接是故宫 3D 建模、网页赛车游戏、Godot 复刻 Portal 2；
  2. 开源——模型权重 + tech report 放到了 Hugging Face 和 ModelScope；
  3. Search / Fetch 两个 API 全量开放，自家搜索引擎驱动，每端点 $0.75/千次；
  4. 官方一句 “Pareto 改进”：比上一版更快完成任务、输出更短，性能和成本同时变好。

光看今天这条没什么好说的。把 4 月到 10 月的 changelog 拉成一条线看，V4 这条路线下了一个很明确的赌注——用推理效率换参数量，把旗舰能力做进小模型，再把 agent 的真实使用成本当一等公民来设计。这篇把这条线串一遍，每个数字都配官方图、都标了出处。先说清楚：下面所有 benchmark 和价格都出自官方 changelog 和官方图表，我一句没跑过，本机也没有 DeepSeek 的 key 可实测。

1017 的 benchmark：把官方表读出来#

官方这次给了一张跨模型对比表，我把关键列转录出来（完整表见下图，数值以官方图为准）：

1017 相对上一版 V4.1-Flash 的增益（官方表）：

  • DeepSWE v1.1：74.2 → 77.0（软件工程，mini-swe-v2 harness），这一档上 1017 直接第一，超过 Claude Opus 5（74.0）和 GPT 5.6-Sol（73.0）；
  • NL2Repo-Bench：65.4 → 68.2（整库生成），第二，仅次于 Claude Opus 5（75.3）；
  • Apex Bench：64.6 → 72.1；Automation-Bench：54.8 → 60.5（这格 1017 全表第一）；
  • HLE（w/o tools）：36.8 → 42.6（纯文本子集 44.0）；
  • Terminal-Bench 4.0：31.2 → 42.3（Claude Code 框架下测）。

一句话读法：1017 的强项集中在开发向 / agent 向基准（DeepSWE、NL2Repo、Automation、Apex），通用认知（HLE、ProgramBench）仍让给 Claude Opus 5。官方挑开发场景打，是因为那才是"小模型吃旗舰"真正变现的地方。

成本曲线：$0.2 顶到 77% 是什么概念#

官方第二张图是 DeepSWE 的 Pass@1 vs 单任务成本（横轴对数美元），这是判断"小模型是否真省钱"最直观的一张：

从图里读出来的对照（官方图读数，非我实测）：

  • DeepSeek V41 Flash-1017：从 ~$0.1 起 73%，拉到 $0.18 到 77%，max 标注 77.0%——左上角最省区；
  • GPT-6.1 Sol：要 $0.4 才到 76%，比 1017 多花一倍价格换来几乎同分；
  • Claude Opus 5：曲线爬到 $10 才 75%——同 75% 档，成本是 1017 的 50 倍量级；
  • V4 Pro · max（星号点）：落在 $1.5、只有 ~63% 的"谷"里——旗舰反而比更便宜的选项分还低。

这张图基本就是"小模型吃旗舰"的物证：在同分档里，1017 的单任务成本压在所有人最左边。官方把右下角那批 $5–10 的旗舰点（Opus 5、Fable 5、GPT-6 Sol）画进来，就是让你看到"花 5–10 倍的钱买 2–3 个百分点"不划算。

KV cache 890 字节：三代压缩的账#

“效率路线"最硬的底子是 KV cache 的代际压缩，官方 260910 那张条形图（每 token 全局 KV 占用字节数）把这条线画得很直白：

  • V1（2023.11）：389,120 B
  • V3.2（2025.12）：48,068 B（比 V1 小 8.1×）
  • V4-Flash（2026.04）：3,514 B（比 V3.2 小 13.7×）
  • V4.1-Flash（2026.09）：890 B（比 V4-Flash 小 3.9×）

三年不到，单 token 的 KV 占用从 38 万字节压到 890 字节，累计约 437 倍。这就是"1M 上下文 + 低成本"能落到硬件账单上的物理基础——KV 越小，同样 HBM 塞得下越多并发、越长上下文，cache-hit 那部分成本（agent 场景的大头）才画得出来。

价格：峰谷 + cache 谷价才是命门#

官方 260910 的价格表（1M token，谷 / 峰）：

  • cache hit：$0.003 / $0.006
  • cache miss：$0.15 / $0.30
  • output：$0.60 / $1.20
  • 谷价 = 峰价 50%；并发上限 2500。

agent 一轮工具循环是几万个 token 的重复前缀，DeepSWE 77 分背后的大头就是缓存命中率，而 cache hit 谷价 $0.003/1M 这个价位，是整条"低成本百万 token"曲线能不能画平的开关。Search/Fetch 每端点 $0.75/千次、经 Harness/Claude Code/Codex 服务端工具调用 10/31 前免费——先免费喂习惯再收钱，是标准平台打法。

4 个 demo：self-feedback 到底做了什么#

1017 的核心卖点是"强化学习 self-feedback，模型从头到尾自己做完一个项目”。官方放了四个 demo（GIF，这里取静帧）：故宫 3D 建模、网页赛车游戏、Godot 复刻 Portal 2、以及"Valley of Ages"一个从史前到现代的 3D 演化场景。看两个代表性的：

这四个 case 的共同点是验收标准是"能不能跑/能不能玩"而不是"文本像不像"，所以官方才敢提"输出更短"——RL 的奖励函数直接挂在了"别废话、把项目做出来"上。落到 CI 修复、code review 这种日常工程场景，1017 比 9/10 版到底强在哪，官方没给对照，等社区数据。

我看到的路线赌注#

从 4 月的 1.6T 旗舰到 9 月的 552B 小模型把 Pro 吃掉，这条线的逻辑很清楚，且每一步都有官方图背书：

  • 非对称激活 + KV 压缩是 1M 上下文的成本解。8B 激活读 1M token、16B 激活生成，KV 压到 890 B/token——“低成本百万 token"在 4 月是口号，9 月才真正落到账单上。
  • cache hit 计价是 agent 经济的命门。agent 的成本曲线能不能画平，取决于命中率 × $0.003/1M 这个谷价。
  • 小模型吃旗舰是终局方向。官方自己写"多方测试 Flash 全面超 Pro、Pro 逐步退出”——旗舰让位于效率。

留两个问题给大家#

  1. 552B 总参、8B/16B 非对称激活，输入侧 8B 在长上下文下够不够——官方没给和 284B 上代的完整对照，谁有实测贴一下。

常见问题

V4 到现在发了多少版？

半年 5 个官方节点：4/24 V4 Preview（Pro 1.6T + Flash 284B 开源）、8/13 V4-Pro GA、8/21 Flash-Vision-Exp、9/10 V4.1-Flash、今天 10/17 V4.1-Flash-1017。

V4.1-Flash 为什么能干掉 V4-Pro？

552B 总参但非对称激活（输入 8B/输出 16B），KV cache 压到上一代 1/4 HBM、1/8 SSD；官方称多方测试其在性能/成本/速度/总耗时上全面超 Pro，9/14 起 Pro 的 API 流量已全量路由到 Flash。

价格怎么算？

官方 1M token 计价（谷/峰）：cache hit $0.003/$0.006，cache miss $0.15/$0.30，output $0.60/$1.20；并发上限 2500。谷价 = 峰价 50%。

1017 版最值得关注的是什么？

三件事：RL self-feedback 做端到端项目（官方 demo：故宫 3D 建模、网页赛车、Godot 复刻 Portal 2、3D 历史演化场景）、模型开源到 HF/ModelScope、Search & Fetch API 全量开放（$0.75/千次，经 Harness/Claude Code/Codex 服务端工具调用 10/31 前免费）。
