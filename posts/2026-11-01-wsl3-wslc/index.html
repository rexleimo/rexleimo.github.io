WSL 3 正式发布：Windows 原生跑 Linux 容器引擎，跨系统文件 2 倍速

9 月 29 日 WSL 3.0.1 转 GA，wslc 容器 CLI、Consommé 网络模式、virtiofs 文件加速一次到位。我在 Windows 11 上装了试，把架构、网络、边界拆开讲清楚。

November 1, 2026 · 2 min · 214 words · 梦兽编程 -  |  English

导读：9 月 29 日，微软把 WSL 3.0.1 推成了正式版，上一版还停在 2.9.13。这次跨过 3 的真正理由，是「WSL containers」终于转 GA。一句话：在 Windows 里跑一条 wsl –update，你就有了自己的 Linux 容器引擎，不用再装 Docker Desktop。这篇把我摸到的东西拆开讲。

先说结论#

WSL 3 把在 Windows 上跑 Linux 容器变成了一等公民：新的 wslc 命令装完就有，命令就是 docker 换个前缀；网络换成 Consommé 模式，企业 VPN 直接能用；文件协议换成 virtiofs，跨系统读文件快约 2 倍。

方向就一个：Windows 原生跑容器，不叠外部引擎。

我怎么装的#

我跑的就是 wsl –update，下完 wslc 就在。wslc version 报 3.0.1.0，不用登录、不用重启、没有授权弹窗。

我接着跑了 wslc run –rm hello-world，拉镜像、执行、出结果，一次通过。

wslc 是什么#

命令直接对着 docker 读：wslc container run、wslc container cp、wslc system info，把开头的 docker 换成 wslc 就行。

它拉标准 OCI 镜像，直接从 Docker Hub 取，单容器工作流够用。

会话隔离：一人一个 VM#

WSLC 不复用 WSL 2 那个共享 VM。有权限的 wslservice.exe 只负责创建虚拟机，每个用户会话由一个 wslcsession.exe 管，跑在你自己的用户权限下。

每个会话有独立的虚拟磁盘，镜像、容器、网络互不共享。好处是会话之间强隔离、出问题影响面小，操作层权限更低、安全边界更硬。

Consommé 网络模式#

为什么取个法文名字？Consommé 是法餐里一种澄清汤，意思是把油脂撇干净。这里的意思，就是把 WSL 网络的「隔离感」撇掉。

WSL 2 默认 NAT 是彻底隔离的，企业 VPN 够不着它。Consommé 让 VM 把流量当以太网帧走 virtio 队列出去，Windows 侧一个用户态进程接手，处理 DNS、路由、端口映射。

效果是：流量按你本人用户身份出去，VPN 和防火墙看它，跟看一个普通 Windows 程序没区别。

官方自己也承认这套模型还在演进，changelog 里好几条是修端口范围和网关回退的。别指望它一次到位。

文件性能：2 倍是官方的话#

老协议是 9P，跨系统文件慢是 WSL 2 多年的头号抱怨。官方文档让你把工程放 Linux 侧，那是绕不是解。

WSL 3 默认 virtiofs。官方架构博客的原话是：virtiofs 比 9P 大约快 2 倍。注意是「大约」，官方措辞很克制。内核也升到 6.18。

VS Code 集成：一行切换#

你用 VS Code Dev Containers，工作流不用变。这个扩展本来就是调 docker CLI 驱动容器，现在把 dev.containers.dockerPath 指向 wslc 就行。

之后 build、run、inspect、exec 全走 wslc。Docker Desktop 留着也不冲突，两个各用各的 VM，只是不共享镜像。

诚实的边界#

现在 wslc 没有的东西。compose 没有，官方博客原话说这是呼声最高的需求，下个迭代做。本地 k8s 没有，devcontainer 的 features 机制不支持。

GPU 直通可以，–gpus all 实测能用。所以结论分两档：跑单容器、做 devcontainer、学容器，现在就能切；重度依赖 compose 或 k8s，等 compose 落地再说。

我的看法#

微软这步棋不是「做个 Docker 替代品」，是把容器负载拉进 Windows 自己的企业治理框架——Intune 能一键禁用、Defender 能审计容器进程，这些 Docker Desktop 给不了。对个人开发者是省一个安装，对企业是省一套管控。

常见问题

要 Windows 11 吗？

它跟着 WSL 走，能跑带虚拟化的系统就行。

能跟 Docker Desktop 共存吗？

能。各跑各的 VM，镜像不互通，互不冲突。

我现有的 devcontainer.json 能用吗？

大部分能。compose file、features、runServices 这三项 wslc 不支持。

企业怎么管？

Intune 能一键禁用 WSL 容器、限镜像源；MDE 能审计容器里的进程、文件、网络活动。
