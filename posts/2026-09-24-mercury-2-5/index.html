Mercury 2.5：官方说 1107 tok/s，独立实测 770 —— 扩散 LLM 的分水岭数字

Inception 的扩散 LLM Mercury 2.5 上了 HN：官方口径 1107 tok/s、260K 上下文、首发 8 折 $0.04/$0.15。Artificial Analysis 独立测出 770.4 tok/s（全场第 2）、智力指数 12 分（中位水平）。两个数字都对，差在测量口径——这才是该读这篇的原因。

September 24, 2026 · 2 min · 304 words · 梦兽编程 -  |  English

9 月 8 日，Inception 发了 Mercury 2.5——他们家最大的扩散 LLM（diffusion LLM，dLLM）。HN 这条 53 分、25 条评论，讨论点集中在一句话上：“推理速度卷到夸张数字”。770 tok/s 的输出速度排 Artificial Analysis 全场 184 个模型的第 2 名，这个数字值得认真拆开看——因为它和官方自己报的 1107 tok/s 差了 30%，而两个数字都各自为真。

这篇只讲三件事：两个速度数字的口径差在哪、智力 12 分到底算什么档位、以及官方引用的生产案例数字你能信几成。没跑过 API 的地方下文全部标注，不混进正文。

先摆数字：官方 1107 vs 独立 770.4#

指标Inception 官方（9/8 blog）Artificial Analysis（独立）
输出速度1,107 tok/s（“广泛可用的 NVIDIA GPU”）770.4 tok/s（AA 推理基础设施，排名 2/184）
智力指数“比 Mercury 2 提升 40%"（自家口径）12 分 = 对比集中位数，排名 91/184
上下文260K tokens260K（页面换算约 390 页 12pt Arial）
价格标准 $0.20/$0.75，首发 8 折 $0.04/$0.15挂 $0.25/$0.75，缓存折扣 90%
输出 token 消耗—智力评测共烧 35M 输出 token（中位模型 84M，“比较克制”）

速度差 30% 的口径解释：厂商自测的条件是自己控制的（硬件、batch、调度、是否走缓存都算数的地方），独立基准是统一测试床。770.4 这个数字之所以值得单独记住，是因为 AA 页面上 184 个模型里没有第二个能上 770 的——第 1 名是它家的 Mercury 2 系列，而"全场第 2"这个位置本身就是这篇 HN 讨论的由头。

智力 12 分：中位，不是旗舰#

这是整篇里最该读反套路的一节。官方原文的措辞是"市场上最有能力的扩散 LLM”、“已知训练过的最大 dLLM”——限定词全是 dLLM。放到全量对比集里，12 分是中位数，91/184 的排名意味着恰好一半模型在它上面。

官方的对标清单是：GPT-5.6 Luna (Low)、Gemini 3.5 Flash-Lite、Claude Haiku 4.5。三个名字里两个带"低配/轻量"标签，一个本来就是轻量线。翻译一下就是：同价位里它智力不掉队，但它卖的不是智力，是智力×速度×单价这个乘积。40% 的智力增幅是相对自家 Mercury 2 说的，不是相对旗舰线说的——引用这个数字时务必带上参照系。

生产案例的三个数字：都出自客户之口，都指向延迟#

官方 blog 引了两家生产客户，数字我原样列出，归因也原样保留：

客户场景数字
OpenCall（电话语音 agent）实时客服通话P99 响应从"几分钟"降到 1 秒，P50 从 0.4s 降到 0.2s 以内（含推理）
Augment Code（编码 agent）上下文压缩 / 模型路由 / MCP 工具检索压缩延迟 -82%（约 150s → 27s），成本 -90%，工具检索摘要 1 秒内返回
（未具名的搜索基础设施公司）单次查询几十次模型调用官方原文只说"几家头部搜索基础设施公司已在生产运行"，没给数字

这类数字的共同特征：全是延迟/成本相对值，没有一张绝对智能对比表。语音场景的 P99 1 秒是产品级指标（电话那头的人在等），Augment 的 150s→27s 说明压缩环节以前是长会话的瓶颈。读法建议：延迟数字可以当参考，成本 -90% 需要自己的 workload 验证——压缩的 token 分布和价格折扣结构，换一家就是另一个数。

顺带两个预览：Mercury Voice（TTFT <170ms，专为电话延迟预算做的 dLLM）和 Mercury Router（用 dLLM 理解进向 prompt、在开放/闭源模型里路由到质量×速度×成本最优解）。Router 这个方向值得单开一篇，今天只点名。

一个 8 折，一条免费额度#

首发价 $0.04/$0.15 是标准价的 8 折，叠 1 亿 token 免费额度——按 770 tok/s 的输出速度，免费额度能撑的场景不小。价格面还有两处要对齐：Inception 模型页挂 $0.20 输入，AA 页面挂 $0.25 输入（AA 注明"中位价 $0.25"，即它按中位口径归的类），缓存折扣 90% 走的是 AA 口径。下单前确认自己走 Inception API、Baseten 还是 OpenRouter，价格面不一样。

诚实声明#

  • 本文没有调用 Mercury 2.5 的 API（没有跑过的不写正文），速度/智力/价格数字全部转引自 Inception 官方 blog（9/8）与 Artificial Analysis 模型页（9/2026），两组口径差异如上表，不做"哪个更对"的裁决——它们测的就不是同一个东西；
  • 生产案例数字（OpenCall、Augment Code）是厂商引用客户之口，无独立复核；
  • “扩散 LLM 可复现性/工具调用生态不如自回归"是业内通行判断，本文未实测，列在相关阅读；
  • 官方称"已知最大 dLLM”，无参数规模披露可比，按"没披露"处理。

常见问题

770 tok/s 和 1107 tok/s 哪个是真的？

两个都是真数字，口径不同。1107 是 Inception 官方在'广泛可用的 NVIDIA GPU'上测的输出速度（官方 blog 原话）；770.4 是 Artificial Analysis 在自己的推理基础设施上测的输出速度（AA 模型页原话，全场第 2 名/184）。厂商自测挑最优硬件与调度，独立基准用统一环境——差 30% 在这个赛道里不算异常，异常的是大家只会引用官方那个。

智力水平到底什么档位？

AA 智力指数 12 分，恰好等于该对比集的中位数，排名 91/184——中位水平，不是旗舰。官方的说法是'比 Mercury 2 智力提升 40%，与 GPT-5.6 Luna (Low)、Gemini 3.5 Flash-Lite、Claude Haiku 4.5 同档'——注意它对标的全是各家'压缩版'，不是全量旗舰。它强在速度×单价这个乘积，不在绝对智力。

扩散 LLM（dLLM）和普通自回归模型差在哪？

自回归模型一次吐一个 token，速度被串行卡死；dLLM 并行生成/精修一块 token，GPU 利用率高、吞吐和首 token 延迟都低。Inception 的卖点是'用扩散换并行'：同档位智能下 5-7 倍吞吐、TTFT 亚 300ms。代价是生态成熟度——可复现性、长尾工具调用兼容性还没有自回归那么厚（本文没实测，按'没跑过不写正文'的原则只列在相关阅读）。

多少钱能用？

标准价 $0.20/百万输入、$0.75/百万输出；首发 8 折 $0.04/$0.15，1 亿 token 免费额度。AA 页面上挂的是 $0.25/$0.75 且缓存折扣 90%——两个价格面并存，下单前看你要走哪条通道（Inception API / Baseten / OpenRouter）。

适合什么场景？

官方和引用它的客户给的画面很具体：搜索/RAG 管道（一次查询触发几十次模型调用，得压在单次交互的延迟预算里）、电话语音 agent（OpenCall 生产环境 P99 从几分钟压到 1 秒）、编码子 agent 的上下文压缩与工具路由（Augment Code 压缩延迟 150s→27s、成本 -90%）。共同点：调用量大、单次要求不高、延迟就是产品。
