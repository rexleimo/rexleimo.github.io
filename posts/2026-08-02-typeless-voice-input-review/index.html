Typeless 评测：当一个程序员决定用嘴写代码之后

深度体验 Typeless AI 语音输入法：它真的能让输入速度提升 4 倍吗？适合什么人、不适合什么人，以及如何用邀请链接免费领 $5 Pro 额度。

July 25, 2026 · 2 min · 266 words · 梦兽编程 -

我打字不算慢。

在标准键盘上，我大概 80～90 wpm；写技术文档或者回复 issue 的时候，这个速度够用了。但过去两年，我越来越明显感觉到一个瓶颈：手速追不上脑子转的速度。

经常是脑子里一段代码注释、一段架构说明，甚至是一整封邮件已经成型了，手指还在第二行。更糟的是，当我在手机上处理工作消息、在会议室里记录想法、在深夜不想吵醒家人但脑子里还有一段逻辑没想清楚时，键盘这个输入方式开始变得很碍事。

所以我开始认真用语音输入工具。从系统自带的听写，到讯飞、豆包输入法，再到最近用了快两个月的 Typeless。结论是：它不是完美的，但确实是目前我愿意付费留下来的那一个。

这篇文章不是功能说明书，是我作为一个程序员 + 技术写作者的真实使用体验。文末有我的 Typeless 邀请链接，通过它注册你可以免费领取 $5 Typeless Pro 额度——对，我们双方都能薅到官方羊毛。

一、Typeless 到底是什么？#

一句话解释：Typeless 是一个跨平台的 AI 语音输入法（语音键盘），它最大的特点是能在你任何输入框里把你说的话变成文字。

注意关键词：任何输入框。

它不是某个应用里的语音输入按钮，而是一个系统级的输入工具。我在这些地方都用过：

  • VS Code 里写注释和 commit message
  • Cursor 里给 AI agent 下指令
  • Notion、Obsidian 里写文档
  • 微信、Telegram 里回消息
  • Gmail、Outlook 里写邮件
  • 浏览器表单、搜索框、Slack、Linear

支持 macOS、Windows、iOS、Android。官方说法是“在你写作的每个地方都能使用”，用下来基本属实——只要你能在那个位置调出键盘或输入法，Typeless 就能接进去。

Typeless 支持 macOS/Windows/iOS/Android，基本覆盖了我日常所有需要输入文字的场景。

二、为什么我愿意把它留下来？五个真正打动我的点#

1. 它不只是“转文字”，而是“把废话修成能用的文字”#

这是 Typeless 和系统自带听写、普通语音输入法最核心的区别。

我们平时说话是这样的：

“呃……这个函数主要就是用来，嗯，处理那个用户输入的，你知道的，就是那个字符串……然后它会返回一个，一个结果对象。”

如果是普通语音转文字，你得到的就是上面这段带“呃”“嗯”“那个”的东西。Typeless 不会。它会自动做这几件事：

  • 去除填充词（“呃”“嗯”“你知道的”）
  • 去除重复和自我修正（“那个字符串……那个” → “用户输入的字符串”）
  • 自动格式化（你说“第一点……第二点……第三点”，它真的给你变成列表）
  • 保留最终意图（你说错了重说，它取你最后一次的意思）

这一点非常关键。很多时候我们不愿意用语音输入，不是因为识别不准，而是因为后期的文字清理工作量太大。Typeless 把这个清理工作做了 70% 以上，剩下的人工微调成本远低于重新打字。

2. 速度是真的快，尤其在“倾泻想法”的场景#

官方给的数据是普通键盘 45 wpm，Typeless 220 wpm。我没有严格测过，但体感和这个数据差距不大。

对我最高光的场景有两个：

  • 写长文章草稿：我坐在椅子上，看着提纲，一段一段说出来。Typeless 转成文字后，我只需要改连接词和格式。
  • 给 AI agent 下复杂指令：和 Claude Code、Cursor 说一大段需求时，用语音比打字流畅太多，尤其是多轮修改时。

普通键盘输入（左）和 Typeless 语音输入（右）的速度差异。倾泻式创作时，这个差距非常明显。

3. AI 不只是转录，还能“Ask Anything”编辑文字#

这是 Typeless 比较新、也比较狠的功能。你可以选中一段文字，然后用语音对它下指令：

  • “把这段话改得更正式一点。”
  • “翻译成英文。”
  • “缩短到 50 字以内。”
  • “给这段加一个总结。”
  • “把这段改成列表。”

对于写技术文档、写邮件、做会议总结的人来说，这个功能相当于把“语音输入 + AI 改写”合并成了一个快捷键。我不需要切到 ChatGPT 或 Claude 的网页里去复制粘贴，直接在原地完成。

4. 支持 100+ 语言和实时翻译#

我工作中中文和英文文档都写。Typeless 的一个隐藏强项是：它能识别我在说哪种语言，甚至支持中英夹杂，翻译输出也比较自然。

比如我说：

“这段 API 返回的结果，如果 status 是 failed，就直接提示用户‘操作失败，请重试’。”

它能把这句话里的中英文都识别得相当准确。如果你经常要写多语言文档或者和海外团队协作，这点很加分的。

5. 隐私设计让我没那么焦虑#

语音输入最大的心理障碍是“我的录音会不会被拿去训练”。Typeless 官方在这点上给了比较明确的承诺：

  • 零云端数据保留
  • 不会用你的数据训练模型
  • 历史记录存在本地

当然，这些都是官方声明。但至少在产品设计上，它把隐私作为一个卖点，而不是含糊其辞。对我来说，写代码注释和内部文档时安全感高一些。

三、什么人适合用 Typeless？#

我用了一段时间后，觉得 Typeless 最适合这几类人：

人群为什么适合
技术写作者 / 博客作者长文草稿、结构化输出、AI 润色
程序员 / AI 工具用户写注释、commit message、给 agent 下指令
需要大量邮件沟通的人快速写初稿，AI 调整语气
多语言工作者中英夹杂输入、边说边翻译
手机输入党手机端语音输入体验明显优于搓屏幕

反过来说，如果你主要是：

  • 在公共场合办公为主（语音输入会打扰别人）
  • 只需要偶尔打个几十个字的短消息
  • 对订阅制工具非常敏感

那 Typeless 免费版可以试试，但不一定值得 Pro。

四、免费版和 Pro 版的区别#

Typeless 的定价是：

  • Free：$0 / 月，每周 8000 字，功能基本完整，标准准确度。
  • Pro：按年 $12 / 月，按月 $30 / 月，无限字数、增强准确度、优先访问、团队功能等。
  • Enterprise：定制价，面向公司。

我个人建议：先用 Free 版试一到两周，看看它能不能真的替代你的一部分打字场景。如果确实好用，再考虑 Pro。

如果你的使用频率足够高，Pro 的“增强准确度”是有明显感知的——尤其是在中文人名、术语、中英混合这些场景下。

对于大多数个人用户，Free 版已经足够体验核心能力；Pro 更适合把它当主力输入工具的人。

五、我的上手建议：怎么最快用起来#

如果你是第一次用 Typeless，建议按这个顺序：

  1. 下载对应平台客户端，从自己最常用的设备开始。我首推 Mac 或 Windows 桌面端，因为语音输入在写长文时最有价值。
  2. 设置一个顺手的快捷键。我用的默认 Fn 键，说话的时候按住，说完松手。比手机输入法的长按空格体验好很多。
  3. 先从“倾泻式写作”开始用：不用管格式，先把想法说完，再回头看 Typeless 清理出来的版本。
  4. 逐步尝试 AI 编辑功能：选中文字后，用语音下指令改写、翻译、总结。
  5. 建立个人词典：把常用的专业术语、人名、缩写加进去，准确度会稳定提升。

快捷键是 Typeless 体验的核心。建议把唤起键放在手指自然能按到的位置。

六、Typeless 还不够好的地方#

为了不被当成硬广，我必须诚实地说几个限制：

  • 公共场所不方便：这是所有语音输入的通病。我一般在办公室独处、书房、车里或散步时用。
  • 中文口语化表达上限：普通话、中英夹杂识别不错，但太过随意的网络黑话、口音重的表达还是容易出错。
  • Pro 价格对轻度用户不算低：如果你只是偶尔用，免费版够；天天用才值得 Pro。
  • 初期需要一点磨合：快捷键、语气设置、个人词典都需要你花半小时配好，蜜月期之后会顺手很多。

八、总结#

Typeless 不是那种“下载了立刻改变人生”的工具，但它是我今年用上手之后最想留下来的效率工具之一。

它的价值不在于让你在所有场景都不用键盘，而在于把“脑子已经想好了但手还没打完”的那部分低效时间砍掉。对于经常写文档、写代码注释、给 AI 下指令的人来说，这种体验一旦建立，确实有点回不去。

如果你也在寻找一款能真正替代部分键盘输入的 AI 语音工具，建议先用免费版试两周。 bottled 住一个输入工具最贵的不是订阅费，而是你试完之后发现“好像也没那么好用”的沉默成本。Typeless 至少值得你给它 2000 字的机会。
