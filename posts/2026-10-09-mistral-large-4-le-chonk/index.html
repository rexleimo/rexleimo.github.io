Mistral Large 4「Le Chonk」规格核对：1T 参数 49B 激活，512K 上下文，10 月底开放权重

Mistral 2026-10-06 发 Mistral Large 4（Le Chonk）：1T 参数、49B 激活、原生多模态，API 即日开、开放权重 10 月底。我把流传说法逐条对了一手出处：早期爆料的 1M 上下文在 OpenRouter 实测是 512K；价格 $0.68/$2.09（$/M，公测期五折）是我本机 curl 公开端点跑出来的数字；Artificial Analysis 智能指数 38 分，与 GPT-6 Luna 同分。RL 还没跑完，现在是 preview，别当终版用。

October 9, 2026 · 3 min · 610 words · 梦兽编程 -  |  English

2026-10-06 那天，Mistral 官宣了一个他们内部管法很糙的名字——Le Chonk（chonk，网络黑话，指"大个子、敦实块头"），正式编号 Mistral Large 4。三个数字先甩出来：1T 参数、49B 激活、10 月底开放权重。当天 OpenRouter 直接挂出公测，Artificial Analysis 同步给了分——一天之内，规格、价格、第三方评测三样齐了，比大多数模型的发布节奏都密。

我做的事不复杂：把当天流传的这些说法逐条对到一手出处，能自己机器上验的验掉（价格、上下文、模态），验不了的标清楚是谁在说什么。这篇讲四件事：

  1. 1M 上下文的流传说法在 API 实测里没兑现，是 512K；
  2. “原生多模态"这四个字的实际含义——不是外挂视觉编码器；
  3. 3,800 张卡、欧洲自炼自部署，这条发布一半的篇幅是地缘叙事；
  4. 现在能用的是 preview 不是终版，RL 没跑完，权重 10 月底。

流传说法 1：1M 上下文——实测 512K#

发布当天流传最广的规格条是这条（X 上 @ItsmeAjayKV 的帖子，2026-10-06）：

“1.05T parameters / 49B active per token / 1M context / Natively multimodal.”

注意"1M context"这条没有出现在 Mistral 官方 X 帖里，也没出现在联创 Lample 的发布线程里——我抓了两条官方原文核对，两边都只写 1T/49B/原生多模态/月底权重，没提上下文长度。那 1M 从哪来？第三方转述。

API 侧我直接验了。2026-10-07 02:03 UTC 本机请求 OpenRouter 公开端点（无鉴权），取 mistralai/mistral-large-4-0 条目，原样输出：

$ python3 - <<'EOF'
import json,urllib.request
d = json.load(urllib.request.urlopen("https://openrouter.ai/api/v1/models"))
for m in d["data"]:
    if "mistral-large-4" in m["id"].lower():
        print("id:", m["id"])
        print("context:", m.get("context_length"))
        print("pricing:", json.dumps(m.get("pricing")))
        print("arch:", json.dumps(m.get("architecture"))[:400])
EOF
id: mistralai/mistral-large-4-0
context: 524288
pricing: {"prompt": "0.00000068", "completion": "0.00000209", "input_cache_read": "0.00000007"}
arch: {"modality": "text+image->text", "input_modalities": ["text", "image"], "output_modalities": ["text"], "tokenizer": "Mistral"}

context_length: 524288——512K，不是 1M。OpenRouter 模型描述里也写死 “512K-token context window with up to 256K output tokens”。结论：做工程按 512K 规划，1M 目前只算"某条转述帖的口径”，官方文档没背书之前不写进架构。MoE 模型的上下文长度经常训练/推理/服务三层各说各话，这是本次流传说法里唯一没对上的一档。

“原生多模态"四个字实际是什么#

上面实测输出里有一行："modality": "text+image->text"，input_modalities: ["text","image"]。

翻译成人话：图像和文本同进一个模型，不是"先跑个 CLIP/视觉塔、把向量塞进 LLM"那种拼接件——官方口径 “natively multimodal” 的意思就是训练阶段图文混排进同一个 transformer，而不是推理时挂个外挂适配器。工程上可感知的差异在视觉 grounding：官方帖原话 “surpasses closed frontier models on visual grounding”（视觉定位超过闭源前沿模型）。Lample 线程补了细节——在"complex multimodal grounding benchmarks"上 SOTA。

我没法在这台机器上跑视觉基准，这条按官方自报口径听；但它解释了一件事：为什么官方敢把"视觉 grounding 超闭源"写进发布公告——多模态是原生训出来的，不是补丁。

3,800 张卡：这篇公告有一半篇幅是地缘的#

Lample 线程第二格原话：

“ML4 was trained on 3,800 NVIDIA Grace Blackwell GPUs in our European datacenters — our cluster in Bruyères-le-Châtel built using our Series B fundraise. We are investing heavily in infrastructure, with our Series C and D clusters coming online soon.”

官方帖同句：”Forged in Europe end-to-end and is deployable from Europe via our own Mistral Cloud infrastructure."

把这两句放一起，这条发布的信息量一半在模型、一半在**“欧洲自炼自部署"这件事本身**：训练、机房、云、推理全链路不出欧洲。对受欧盟 AI 法案/数据主权约束的客户（官方点了名：cyber defense、manufacturing、finance），“模型跑在欧盟、权重开放"比基准分数值钱——它卖的不是分，是合规可用性。这是美系开放权重给不了的叙事位。

你现在拿到的只是 preview：RL 没跑完#

Lample 线程第一格最关键的一句：

“The RL run behind this preview is still in flight and shows no sign of saturation — we will release a final version before the end of the month along with the weights of the model.”

三件事叠一起：

  1. 现在 API 上是 Research Public Preview，RL 还没收敛，分数还会动；
  2. 终版与权重绑定 10 月底一起出——也就是说 10-06 到 10-31 之间你测出来的数字，届时大概率失效；
  3. “no sign of saturation” 是联创亲口，不是营销文案——按字面理解，最终版强于当前 preview 是官方预期，不是我的推测。

所以这篇文的所有数字有效期：到 10 月底权重落地为止。做采购决策的，等权重出来自己跑一遍再定。

价格实测：公测五折期是多少#

实测输出里 pricing 一行（2026-10-07 02:03 UTC，OpenRouter 公开端点）：

  • 输入 0.00000068 = $0.68/百万 token
  • 输出 0.00000209 = $2.09/百万 token
  • 缓存读 0.00000007 = $0.07/百万 token

OpenRouter 公告口径（经 ahot 收录，10-06）：“前两周五折”——即上面这组是折扣价。$1.36/$4.18 是按五折反推的恢复价，算术推算，官方未直接公布原价，引用时别当官方数字。缓存读 $0.07 比市面常见的 10-20% 缓存折扣更狠，长会话场景成本主要看缓存命中率。

对比锚点：等 10 月底权重落地，“API 价格"这个比较维度会被"自部署 TCO"取代——现在比 API 价意义有限，先把上下文 512K、输出 256K 这两个工程参数锁进架构就行。

“美欧最佳开放权重"能听几分#

Artificial Analysis 的评测条目（经 ahot 收录，10-05）给了个可核对的锚：Intelligence Index 38 分，与 GPT-6 Luna（max, 38）同分，评语"美国之外最智能模型”。Lample 线程把官方基准口径也端出来了：

“On important coding and agentic benchmarks such as DeepSWE, AutomationBench, and AA-Briefcase, ML4 matches the performance of the best open-weight models. It is SOTA on finance and legal workflows, as well as on complex multimodal grounding benchmarks.”

翻译：编码/agent 类是"打平最佳开放权重”（不声称超），金融/法律/视觉定位是"SOTA”（声称超）。这个措辞分层很克制——敢写 SOTA 的地方才写 SOTA，别的写 matches。第三方（AA）同分 GPT-6 Luna 是外部背书，但权重没出之前，任何第三方分数都只是评测侧的口径，我本机没复跑，按"官方自报 + 第三方转引"双轨听。

Arena 那边也已把 Large 4 挂进 Agent Arena 与 Code Arena（WebDev/Text/Vision），“分数稍后公布”（ahot 收录，10-06）——10 月底权重落地后这组分大概率才是终局参考。

本地部署：1T 总参意味着什么#

49B 激活 MoE 的算术（纯估算，本机无 GPU，一行都没跑）：

  • 1.05T 总参 × FP8（1 byte/param）≈ 1TB 显存；int4 约 550GB 量级
  • 单 token 计算量按 49B 稠密等价——显存是瓶颈，算力不是
  • 翻译：8×80GB（640GB）顶配单机在 int4 边缘，FP8 需双机；跑起来后吞吐参考 49B 稠密模型水平

结论：10 月底权重落地后，“能不能本地/私有部署"的答案是"能，但要为 1TB 显存规划”，不是 70B 时代一台 H100 节点的玩法。这是开放权重模型第一次把门槛推到"多机"档位——对私有化客户是机会，对个人玩家基本宣告：这档不在消费级硬件射程内。

诚实声明#

  • 本机实测部分：OpenRouter 公开端点的规格/价格/模态字段（2026-10-07T02:03Z，无鉴权 GET /api/v1/models）——输出可逐字复现，命令在"流传说法 1"节。
  • 未复现部分：AA 智能指数 38 分、DeepSWE/AutomationBench/AA-Briefcase 对标、视觉 grounding 超闭源——全部为官方自报或第三方转引，权重未出、本机无 GPU，未独立复跑。
  • 1M 上下文：仅第三方转述帖口径，API 实测 524K；在官方文档明确 1M 训练口径之前，按 512K 规划。
  • 五折价格反推（$1.36/$4.18）：算术推算，官方未直接公布原价。
  • 所有数字有效期到 10 月底权重+终版发布；届前评测分数视为流动值。

常见问题

Mistral Large 4 现在能用吗？

能。2026-10-06 起 API 公测：OpenRouter 已上线（mistralai/mistral-large-4-0，512K 上下文、最高 256K 输出、支持工具调用与结构化输出），Mistral Studio / 自家 API 同步。注意这是 Research Public Preview，官方明说 RL 还在跑，终版+权重 10 月底才出。

1M 上下文是真的吗？

流传的 1M（早期爆料帖）没在 API 侧兑现：OpenRouter 模型条目 context_length 实测 524288（512K），描述里也写 512K。1M 可能是训练侧口径或预告，上线前没有官方文档背书，按 512K 规划工程。

多少钱？

我 2026-10-07 本机 curl OpenRouter 公开端点实测：输入 $0.68/M、输出 $2.09/M、缓存读 $0.07/M——这是公测期五折价（官方称前两周 50% off），折后恢复约 $1.36/$4.18（按五折反推，官方未直接公布原价）。开放权重 10 月底出来后，自部署成本另算。

开放权重 10 月底出，本地能跑吗？

1.05T 总参（49B 激活 MoE）。纯算术估算（本机无 GPU，未实测）：FP8 权重大约 1TB 量级、int4 约 550GB 量级——单机顶配（8×80GB）都吃不下，得上多机推理框架；好在 49B 激活，推理算力开销按 49B 稠密模型算，显存大、算力轻。

它到底强在哪？

官方自报：聚合基准上是美/欧开放权重最佳，视觉 grounding、金融、法律工作负载 SOTA；Artificial Analysis 智能指数 38 分，与 GPT-6 Luna（max）同分，被称为美国之外最聪明的模型。但权重未出，第三方无法独立复跑，这些数字按官方自报口径听。
