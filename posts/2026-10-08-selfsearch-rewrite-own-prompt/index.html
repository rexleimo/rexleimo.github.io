SelfSearch：让 agent 自己改写自己的提示词，$4.03 打平 Codex

SelfSearch（arXiv 2609.37968）：不用下游奖励，agent 靠自我修改的历史记录改写自己的指令/工具/流程，$4.03 搜索成本做出 82.0% Terminal-Bench 2.1 的 harness，打平公开 9-harness 对比里的头部 Codex。提示词进化的极端版。

October 8, 2026 · 1 min · 201 words · 梦兽编程 -  |  English

提示词进化一直是手艺活：拍脑袋改 prompt → 跑一遍 → 手感决定下一版。SelfSearch（arXiv 2609.37968）把它变成搜索问题：agent 不改代码改自己——改写自己的指令、工具、执行流程，依据是"之前那轮自我修改的记录"，全程不给任务级奖励。结果：$4.03 搜索成本做出 82.0% Terminal-Bench 2.1 的 harness，打平公开 9-harness 对比里分最高的 Codex。这篇把官方摘要的数字全抠出来，说清它跟"手工调 prompt"到底差在哪。

先说结论：三个数字#

  1. $4.03 → 82.0%：无奖励搜索成本 $4.03，产出的 harness 在公开 9-harness 对比同设置下（DeepSeek V4 Flash）解出 82.0% Terminal-Bench 2.1，打平那组对比里分最高的 Codex。
  2. 单 agent 最高 +11.2pp：全部 6 组 model-benchmark 设置里 population-mean 成功率都涨；SWE-bench Multilingual +5.0pp，且双方都解出的任务上执行成本 -38.5%——改出来的 harness 不只更强，还更省。
  3. 依据是"经验"不是"奖励"：搜索过程不给下游任务奖励；agent 靠历史自我修改记录（推理 + 工具动作 + 结果）当经验库。这是它便宜的根本原因。

机制：agent 改写自己，用记录当经验#

官方摘要的措辞抠一遍（术语以原文为准）：

  • LLM agent 已经能检查并修改自己的指令、工具和执行流程（harness）。已有做法：反复跑下游评测来搜更好的 agent——“incurs substantial costs and ties the search to the evaluated tasks”（搜索贵，且被评测任务绑死）。
  • SelfSearch 改法：reward-free——agent 修改自己时，读的是"之前那轮自我修改尝试"的记录。每条记录存三样：推理（reasoning）、工具动作（tool actions）、结果（outcomes）。改出来的 agent 成为下一轮的改进者。
  • 效果：population-mean 成功率在 6 组设置全涨；单 agent 最高 +11.2pp（TB2.1）；SWE-bench 多语 +5.0pp 且成本 -38.5%；$4.03 做出打平 Codex 的 harness。

把它翻译成人话：你手工调 prompt 是"改一版、跑一批题、看分数"——分数就是奖励，贵且绑任务；SelfSearch 是"把前几轮自己怎么改的、为什么改、改成什么样，记下来，下一轮拿这些记录继续改"——不需要题面分数当引导，所以便宜（$4.03 量级）、不绑任务。

为什么"提示词"是主角#

harness 里模型直接读的、决定行为的，本质就是提示词 + 工具说明 + 流程约定。SelfSearch 改的"自己的指令、工具、执行流程"，拆开全是提示词族的东西。所以它的结论对提示词工程是实打实的：

  • 提示词是可被自动搜索的工程对象，不是只能人写的文本；
  • 搜索的燃料是自我修改的历史记录（含失败尝试），不是下游任务奖励；
  • 副产品是效率：进化出的 harness 在同解任务上花更少的钱（-38.5%）——改 prompt 不只是提成功率，还能降推理开销。

跟同批 Vercel 篇合看：一减一加#

同批第一篇（Vercel 14 条规则）是人做提示词减法：125 行长到 1000 行后失灵，把确定性砍成 14 条规则代码，模型只管判断。SelfSearch 是agent 做提示词进化：不靠人拍，靠自我修改记录搜索。两条放一起是提示词工程的两个方向——该砍的就砍成规则，该进化的就交给搜索；都是把提示词当可维护、可度量、可自动化的工程对象。

诚实声明#

  • 本机未复现：没有 Terminal-Bench 2.1 环境和 DeepSeek V4 Flash 访问，82.0% / +11.2pp / $4.03 全部为论文官方摘要自报数字（arXiv 2609.37968v2, 2026-09-30），我逐条对照了摘要原文，但没重跑。
  • “$4.03 打平 Codex” 的前提是公开 9-harness 对比的同设置——换基准、换模型档位，结论未必成立；Codex 是那次对比的分最高者，不是绝对最强 harness。
  • 论文 v1（09-29）→ v2（09-30）仅间隔一天，数字以 v2 摘要为准。

  • X 首发：@omarsar0（Elvis Saravia）转述 + 论文链接（aihot.news 2026-10-05 收录条目）

常见问题

SelfSearch 的'无奖励'是什么意思？

搜索过程中不给任务级奖励信号（不靠'做对几道题'引导）。agent 修改自己的依据是'历史自我修改的记录'——之前那轮改了什么、推理是什么、工具动作与结果，拿这些经验喂下一轮修改。

$4.03 是什么成本？

搜索阶段的总成本（把 harness 进化出来花了多少钱），不是跑 82.0% 那次的推理成本。$4.03 搜索后得到的 harness，在公开 9-harness 对比同设置下以 DeepSeek V4 Flash 解出 82.0% Terminal-Bench 2.1，打平分最高的 Codex。

改进有多大？

全部 6 组 model-benchmark 设置里 population-mean 成功率都涨；单个 agent 最高 +11.2pp（Terminal-Bench 2.1）。SWE-bench Multilingual：+5.0pp，且双方都解出的任务上执行成本 -38.5%。

和我手工调 prompt 比，价值在哪？

手工调是 1 个假设 1 轮；SelfSearch 是搜索——用历史自我修改记录当经验库批量试探，且搜索成本（$4.03）远低于'评测驱动搜索'基线。提示词从手艺活变工程对象。

我能直接用上吗？

本机没有 Terminal-Bench 环境和 DeepSeek V4 Flash，未复现。可落地的最低门槛：给自家 agent 加'自我修改记录'——把每轮改了什么 prompt/工具/流程连同结果存下来，下一轮改进喂给它，比拍脑袋改 prompt 有依据。
