SolidCraft：纯 Rust 参数化 CAD，AI agent 直接驱动建模——8 天 2400 星

10-07 建仓、8 天 2400 星：SolidCraft 是纯 Rust 写的开源参数化 CAD，几何内核 clean-room、零 GPL 依赖，桌面（egui+wgpu）、网页（wasm）、MCP server 三端通。我本机把 headless 建模链路拉通：369 条命令、40×30×20 盒子端到端建出且与解析解一致、MCP 握手可用。

October 15, 2026 · 2 min · 368 words · 梦兽编程 -  | 

一个 10 月 7 号建仓的项目，到 15 号拿了 2429 个 star。一周多一点，2400 星——放开源世界不算罕见，但它是 CAD，而且是纯 Rust 写的 CAD，这个组合本身就值得停下来看一眼。

SolidCraft 做三端：桌面（egui + wgpu）、浏览器（wasm32）、MCP server。最后这个端是它跟其他「Rust 写的 XX 工具」拉开距离的地方：AI agent 可以直接驱动它建模，不用人点鼠标。

我把 headless 链路在本机拉通了一遍，实测结果全在文里。

它是什么：一台 clean-room CAD#

先钉定义。SolidCraft 是一个参数化 3D CAD 应用：你在 sketch 上画几何、下约束（约束求解器算位置），然后跑参数化特征时间线（拉伸、倒角、抽壳…），改一个尺寸，模型自动重建。

它的技术路线有两个反直觉的点。

第一，内核是 clean-room 的。CAD 领域的公开几何内核基本都在 GPL 或者干脆闭源（OpenCASCADE 是 LGPL 但整套工具链纠缠很深）。SolidCraft 选了 Apache-2.0 的 truck 建模内核做 B-rep，配 spade 的约束 Delaunay + Ruppert 加密做曲面剖分。仓库纪律写得极死：GPL/LGPL/AGPL 的代码「连读都不许」，图标全是自己代码画的，资产必须登记 ATTRIBUTION.md。FreeCAD 只在 oracle 测试里以独立程序身份出现——用它的公开 Python API 算参考值，代码零链接。

第二，「永远不崩」是被写进 CI 的。所有库 crate unsafe_code = "forbid"；生产 crate 根文件 #![deny(clippy::unwrap_used, expect_used, panic, …)]；所有对外数字（命令参数、设计文件、控制通道输入）按敌对输入处理，get() 不是 [i]；每条命令在 Session::execute 外面还套了 catch_unwind 兜底，崩了就把设计和复现命令写进 crash 报告，solidcraft-cli crashes replay 可以直接重放。CAD 是「用户把设计文件托付给它」的软件，崩一次丢的是整个工程——这个优先级高于一切功能开发。

为什么「AI 建模」值得你多看一眼#

solidcraft-cli mcp 是一个 stdio 式 MCP server，讲 JSON-RPC。Claude Code 里一行挂上：

claude mcp add solidcraft -- solidcraft-cli mcp

它暴露的命令集是 Fusion 风格：sketch.create {plane: XY} → sketch.rectangle.two_point {p0, p1} → sketch.finish → solid.extrude {distance}，改尺寸走 Parameters，模型重建全自动。

仓库里已经有一个现成案例：@0xlillith 用 MCP 驱动建了一辆叫 SELENE 的科学火星车，3323 个时间线步骤，零 UI 点击，重放 9 倍速不报错。这是「agent 当工程师而不是画家」在 CAD 领域的第一个完整样本——不是画个图给你看，是产出一个可再编辑的参数化工程。

为什么 agent 能驱动它？核心设计是「一切皆命令」：工具栏、对话框、CLI、脚本、控制通道、MCP，全部落到同一套 CommandSpec（id + label + params JSON + enabled 规则）。agent 不需要模拟点 UI，直接跑 JSON 命令，确定性可重放。

我本机实测了什么（可复现）#

环境：2 核 EPYC，Linux。命令都在 data/solidcraft 下，全链路：

git clone --depth 1 https://github.com/bherbruck/solidcraft.git
cd solidcraft
cargo check -p solidcraft-mcp     # 2m12s 过
cargo build -p solidcraft-cli     # 524MB debug 二进制
./target/debug/solidcraft-cli commands
./target/debug/solidcraft-cli run tests/oracle/01-box/recipe.json
printf '%s\n' '{"jsonrpc":"2.0","id":1,"method":"initialize",…}' | ./target/debug/solidcraft-cli mcp
  1. commands 列出 369 条命令：SOLID 84、SKETCH 86、SURFACE 18、SHEET METAL 9、PLASTIC 6、RENDER 2，其余 163 条无面板归属
  2. box recipe 端到端：40×30×20mm 盒子，volume 24000mm³、area 5200mm²、6 面 12 边 8 顶点、质心 [20,15,10]，与 expected.json 的解析值（V=abc，A=2(ab+bc+ca)）完全一致
  3. MCP initialize 握手返回 capabilities + 建模指引（“Model like in Fusion… Units are millimetres and degrees, Z is up”），stdio 协议可用
  4. cargo check -p solidcraft-mcp 全 workspace 10 个 crate 通过，2m12s

实测边界（没跑的部分，我不吹）：GUI 渲染（egui+wgpu，需 Xvfb + GPU，本机只验了命令链路）、wasm 网页版、76 件完整 oracle 套件（官方 75/76，我没全量重放）、cargo xtask ci 全量质量门。

它值得进你工具链的时机#

给三句判断。

第一，当实验品它现在是「early but usable for simple parts」：画简单零件、拉伸、倒角、抽壳够用，复杂装配还别指望。官方把 76 件参考件的 75/76 对齐率摆出来，就是在替你划边界。

第二，真正值得收藏的是它的设计纪律：「一切皆命令」+「永不崩」+「UI 可换」三条合起来，就是一个给 agent 时代的软件架构模板——桌面工具做薄，能力全走命令，agent 走 MCP，人走 UI，两者共享同一套语义。

第三，Rust 做桌面工程工具这条路线，继 rust-analyzer、Fluent 家族之后又多了一个 2400 星样本，而且它证明的不是「Rust 能写 GUI」，是「Rust 能写一台带几何内核的重工程软件还不崩」。

参考：bherbruck/solidcraft（README、Cargo.toml、docs/oracle.md、crates 结构）；AGENTS.md（never-crash 纪律与 clean-room 约束）；HN 讨论（item 50064840，140 分 51 评，10-13）。

诚实声明：本机 2 核 EPYC，实测 = cargo check -p solidcraft-mcp 通过 + solidcraft-cli headless 命令链路（commands/box recipe/MCP 握手）；2429★/242 forks 为 10-15 时点 GitHub API 读数；「8 天 2400 星」按 10-07 建仓计；SELENE 3323 步与 75/76 oracle 为仓库自述，我未全量复放。

你拿 agent 干过什么「画外」的重活？我对三种方向有兴趣，评论区对一下：

  • A 方向：MCP 驱动的 parametric 工作流（SolidCraft/类似工具建过真零件的贴个案例）
  • B 方向：clean-room 内核选型（truck vs OpenCASCADE vs Jupyter 式自建），可以出一篇内核对比

常见问题

SolidCraft 是什么，和 FreeCAD 什么关系？

纯 Rust 的开源参数化 3D CAD（Apache-2.0）：约束求解 sketch、参数化特征时间线、B-rep 内核。clean-room 路线——不读/不抄 GPL 代码，几何内核用 Apache-2.0 的 truck 建模库，FreeCAD 只作为外部参考程序（oracle）通过公开 scripting API 算对照值，不是依赖。

AI 建模具体怎么用？

`solidcraft-cli mcp` 是 stdio 式 MCP server，Claude Code 里 `claude mcp add solidcraft -- solidcraft-cli mcp` 就能挂上。命令集是 Fusion 风格（sketch.create → sketch.rectangle → solid.extrude…），仓库自带案例：一辆 SELENE 火星车，3323 个时间线步骤，全程由 MCP 驱动、零 UI 点击。

成熟度到什么程度？

官方定位「early but usable for simple parts」：76 个公开参考件里 75 个与解析解或 FreeCAD 计算值对齐（体积/面积/质心/包围盒），另 1 个是已跟踪 bug。我本机实测 headless 链路通（box 端到端 24000mm³ 与解析解一致），GUI/渲染/wasm 未跑。
