不敲一行命令，小白也能搭自己的私人 AI 助手：Hermes Console 全教程

想养一个自己的 AI 助手，但一看到命令行、部署、配置就劝退？Hermes Console 把这件事变成全程点鼠标：双击启动、浏览器里配置、手机扫码接进微信。这篇从零走一遍完整流程，讲清它背后的架构，也讲清哪些地方需要你自己动手。

September 18, 2026 · 1 min · 193 words · 梦兽编程 -  |  English

想养一个自己的 AI 助手，但一看到"部署"“命令行"“yaml 配置"就想关掉页面？这篇教程就是写给这类读者的。

我们把 Hermes Agent 的整个配置流程做成了一个网页控制台 Hermes Console：双击启动，浏览器里点几下，手机扫个码，助手就住进你的微信。全程不写配置文件、不查环境变量、不复制粘贴密钥。

先说清楚这不是什么：它不是又一个"在线 AI 聊天站”。这个助手跑在你自己电脑上，能读写你的文件、执行你交代的任务、记住你说过的话，你在哪个聊天软件里都能指挥它。控制台只负责把它装好、配好、管起来。

先看最终效果#

装完之后你会得到什么？打开微信，给你的助手发一句"帮我总结今天的日程”，几秒后它把结果回在对话框里。你不需要开着任何网页，不需要记任何命令，就像给一个朋友发消息。

它背后跑在你自己的机器上：

  • 想让它整理下载文件夹，它真的去读你的目录
  • 想让它盯一个项目的报错日志，它可以持续观察
  • 想给它装新技能（比如生成图片、连数据库），控制台里点一下就装上
  • 不想用了，服务停掉，数据和代码都在本地磁盘上，随时可查可删

这就是"私人助手"和"网页版聊天机器人"的区别：前者有手，后者只有嘴。

为什么自己部署 AI 助手一直很难#

Hermes Agent 本身能力已经很强，但让一个不熟悉终端的人把它跑起来，会卡在四道门上：

第一道：环境。 Python 版本对不对、依赖装没装、这个报错是缺库还是缺权限——每一个问题都需要搜索引擎加半小时。

第二道：配置格式。 Hermes 用一个 config.yaml 管理上百个配置项，从模型名到网关端口，从记忆开关到审批级别。功能都在那里，但要"知道字段名叫什么"才能用上。

第三道：密钥流转。 API Key 该填在哪、会不会被同步到云端、会不会明文落在日志里，谨慎一点的用户会在这里停很久。

第四道：接入聊天软件。 微信、飞书、Telegram 各有各的 token 申请流程和回调配置，官方文档写得很全，但"很全"和"很好抄"是两件事。

Hermes Console 做的事，就是把这四道门全部变成表单和按钮。

从零开始：完整流程#

第一步：双击启动#

从 GitHub 克隆或下载 rexleimo/hermes-setup 外部链接 ：

git clone https://github.com/rexleimo/hermes-setup

Windows 用户双击 start.bat，macOS / Linux 用户把 start.sh 拖进终端回车。脚本会自动装 Python 依赖，第一次大约一分钟，之后几秒就起。

启动后浏览器会自动打开 http://127.0.0.1:8420，出现初始化向导——它认识你的机器（Windows 还是 macOS、有没有装过 Hermes），并据此决定后面每一步问什么。

第二步：装 Agent#

点"一键安装"，控制台在后台跑官方安装脚本，日志实时滚给你看。已经装过的会跳过这一步，直接进入配置。

不想让控制台动系统的，可以用"只配不装"模式：你自己按官方文档装好 Hermes，控制台只接管配置管理。

第三步：选大脑#

助手能不能干活，取决于接了哪家模型。控制台内置 13 家供应商预设：GLM、Kimi、DeepSeek、MiniMax、豆包、通义千问、Anthropic、OpenAI、OpenRouter 等，覆盖国内外主流选择。

操作上只有两个动作：点你想要的那家，粘贴从供应商官网拿到的 API Key。剩下的 base_url、模型名、协议类型全部预填好，不用改。

Key 不会出现在配置正文里——控制台把它写进独立的 .env 文件并把权限收到只有你能读，界面上永远显示"已设置"三个字，不回填明文。

第四步：接微信#

在"消息渠道"页找到微信，点"登录"，二维码直接弹在网页里。手机微信扫码、确认，控制台自动把 token 写回本地配置，界面状态变绿，不用你填任何东西。

一共支持 14 个消息平台：微信、飞书、QQ、钉钉、企业微信、Telegram、Discord、Slack、WhatsApp、Email、Matrix、Signal，加上 Webhook 和本地 API Server。接法类似，都在这一个页面里管理。

第五步：启动，说话#

点"启动 Gateway"，状态灯从灰变绿。打开微信，给助手发一句"你好"。

它回了。到这里，一个属于你自己的 AI 助手正式上线，全程没写过一行配置。

它到底做了什么#

把控制台关掉、看穿它，架构其实非常简单：

Hermes 官方已经把 Agent 本身、配置文件格式、消息网关全部定义好。Hermes Console 不碰这些内核，只做三件事：

  1. 读写 config.yaml。 你在界面上点的每一个开关，落到一个具体的配置字段上。改完 Agent 热重载或重启就生效。
  2. 拉起 Gateway 进程。 起停、看日志、跑诊断，都是围绕官方网关进程做运维。
  3. 管理密钥。 敏感值进 .env，配置里只留 ${VAR} 占位符引用。

这就是它没有把水搅浑的原因：Hermes 官方版本随时可以升，控制台只是一个外置管理面板。我们自己的主程序一直在用最新版 Hermes，控制台同期跟进，两边不打架。

配好之后，还能做什么#

教程到上线就结束，但实际用法才刚开始。控制台里几个值得点开看看的地方：

链路与别名。 主模型挂了自动切备选。你可以配一条降级链：主力用 GLM-4.6，额度用尽自动切 DeepSeek，再兜一层 Kimi。聊天时不用管谁在答。

记忆系统。 三种后端可选（内置内存、外部向量库、图记忆），决定助手能记多久、记多深。日常用内置即可。

技能与 MCP。 官方热门技能库 24 类一键安装，MCP 服务目录 64 个经过审核的条目一键添加。想让助手会生图、会查数据库、会操作浏览器，从这里扩展。

全家共用一个助手。 控制台支持多用户：一个 Gateway 同时连家里几台设备、几个成员的微信，每人的对话记忆相互隔离。给父母配一个"发语音问事情"的助手，这条路走得通。

完全离线。 内网部署 + 局域网访问，不暴露公网端口，适合对数据出域有要求的环境。

几件需要诚实说明的事#

  • 大模型的 API 费用是自付的，控制台不收钱也拿不到你的用量，但你的账单会随使用增长。
  • 微信接入依赖官方推荐的 iLink 通道，这类第三方 IM 接入策略可能随平台政策变化，届时控制台会跟进适配。
  • 它是开源工具，不是产品客服。遇到问题去 GitHub 提 Issue，或者评论区留言，维护者会看。
  • 安全边界：控制台默认监听 0.0.0.0（局域网可达），启动时会明确警告这一点。只想本机使用的话，设置环境变量 HERMES_CONSOLE_HOST=127.0.0.1 再启动即可收紧到回环地址；想让局域网或公网访问，务必启用控制台内置的账号鉴权，公网还应再加一层反向代理。

项目地址#

  • Hermes Console（本文主角，管理控制台）：https://github.com/rexleimo/hermes-setup 外部链接
  • Hermes Agent（底层内核）：https://hermes-agent.nousresearch.com 外部链接

常见问题

真的完全不碰命令行吗？

Windows 用户是的，双击 start.bat 即可。macOS / Linux 需要把 start.sh 拖进终端回车一次，除此之外全程浏览器点鼠标。

要花多少钱？

Hermes Console 和 Hermes Agent 都开源免费。唯一的成本是大模型的 API 费用，用哪家模型、充多少由你自己决定，国产供应商按量计费起步很低。

我的对话数据和密钥存在哪里？

全部在你自己机器上。配置和数据在 ~/.hermes，控制台代码独立放在 hermes-setup，重装互不影响。密钥只写入权限受限的 .env 文件，界面上永不回显。

除了微信还能接什么？

共 14 个消息平台：飞书、QQ、钉钉、Telegram、Discord、Slack、企业微信、WhatsApp、Email、Matrix、Signal 等，接法一样。
