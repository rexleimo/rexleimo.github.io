Fable 5.2 三十小时证完费马大定理：降价 20%，Pro 额度最高翻 1.5 倍

Anthropic 11-09 发布 Fable 5.2：API 降价 20%、综合智能榜 65 分登顶、RLI 翻倍，千个 agent 三十小时形式化费马大定理。性价比账单和 Pro 白嫖玩法全在这。

November 9, 2026 · 3 min · 533 words · 梦兽 -  |  English

11-09，Anthropic 发布了 Claude Fable 5.2。先把最硬的一个数字摆出来：一千个 Fable agent 用三十小时把费马大定理的证明形式化了——机器可逐步检查的版本。同样一千 agent 的配置换成 Opus 5.5，十八小时完成 26%，之后基本停住。上一次形式化是未发布的研发版模型干的，用了十一天。三十小时不是营销话术，是完成时。

这次发布三样东西一起来：降价、新档位、订阅用户白嫖额度。三样要连着读，别拆开：降价冲的是 API 侧，白嫖冲的是订阅侧，新档位冲的是性价比侧。今天把这笔账算清楚。

降价是真降#

API 价从 5.1 的每百万 token 输入 10 刀、输出 50 刀，降到 8 刀和 40 刀，两头各砍 20%。另外加了一个 fast mode：16 刀和 80 刀，吐字速度最高 2.5 倍。常规档的生成速度也比 5.1 快最多三成。

缓存价也动了：读取从 25 美分降到 20 美分，5 分钟档和 1 小时档的写入调到 10 刀和 16 刀（VentureBeat 从 System Card 拉的价目表）。重度缓存用户实际成本降得比 20% 还多。

最贵的模型降价，信号是给出来的：Fable 不是限量收藏品，是让你用的。Opus 5.5 的挂牌价其实更便宜，4 刀 20 刀。价目表排出来就是三档摆法：日用便宜的，硬题贵的，降档用是中间的活。

分数去哪了#

RLI（Remote Labor Index）是拿真实外包活考模型的科目，这次涨得最狠：5.1 是 17.9%，5.2 开 High 到 41.3%，翻了一倍还多，把 Opus 5.5 的 21.3% 甩开了一截。写代码的 FrontierCode 2.0，Xhigh 档 49.1%（5.1 是 32.4%，Opus 是 45.5%）。机器人模拟 RoboDojo 从 5.1 的 27.6% 跳到 64.9%。

独立榜单那边，Artificial Analysis 综合智能榜 Fable 5.2 开满是 65 分，居榜首，比 Gemini 4 Carbon 高 5 分，比自家 Opus 5.5 高 6 分，上一代 5.1 只有 49。

基准数字全部出自官方发布文，榜单数字出自 Artificial Analysis 公开榜。图表转录的边界写在诚实边界里。

但 Fable 不是全榜通吃：业务流程那个 AutomationBench，Gemini 4 Carbon 的 53.9 压在 Fable 的 51.4 头上；FrontierCode 上 GPT-6 家族的 Astra 也有 42.8。榜单结构是综合智能居首，单项各有失手，引数字的时候别只看自家那张表的行，要看列。

几个顺带钉住的：OSWorld 电脑操作 89.3%，5.1 是 83.5%；agent 搜索 WANDR 82.1%，Opus 72.3%；图表识别 Chartography 从 5.1 的 44.8% 跳到 73.4%，是全表涨幅最大的单项。外部有用户说 5.2 用 JS 画图能跟专用图像模型掰手腕，图表分给这句话落了地。

性价比：两个官方点加一个外部复测#

官方图上有两个点最重要。一个：5.2 开 High，写代码得分跟 Opus 5.5 开满差不多，钱花一半左右。另一个：最低档 Low 做 Humanity’s Last Exam，追平 Opus 5.5 开满的分数，钱不到十分之一。

这两点就是这次发布的内核：贵模型不是开满来用的，是降档来用的。

外部数据补位：Artificial Analysis 公开榜上，Max 档每道综合任务约 26.5 美元，是那张成本图最右端的点；High 档 62 分、每任务 9.08 美元，反而比 Opus 5.5 的 Max 档（59 分、每任务 10.04 美元）分高钱少。一位跑自建 agent 管线的开发者复测，三十个常规 coding 任务：Fable 5.2 和 Opus 5.5 都解出 26 个，5.1 解出 25 个——日常 coding 两个模型体感拉不开。

争议在 token 上：外部实测每任务输出 token 从 5.1 的 11.8 万涨到 5.2 的 27.4 万，其中 19.2 万是推理 token。分数涨但 token 涨得更凶，边际递减的说法有实据。值不值看用途：开放硬题，推理的花费买回来了；日常 coding 题，买不回来。System Card 里还有个数：Cognition FrontierCode 2.0 测试上，High 档每任务平均 6.72 美元（VentureBeat 从 System Card 转引的）。

以前做不了的事，现在做得了#

费马三十小时是头牌。细节更稀：agent 只拿到一份中间定理命题清单当进度打分，不许查任何数学资料，怎么协调是它自己长出来的。全程用的 action token 只有头次形式化的三分之一，最后产出的证明短七倍。同款的还有：一个工程师给 5.2 一个空文件夹，它协调一千多个子 agent 连跑八天，搓出能在笔记本上开机的操作系统原型，驱动、文件系统、窗口、登录界面、安装程序都在。

硬件那条线更离奇：三个设备——家用语音助手、USB 扬声器电话、掌机电子宠物。规格它自己写，零件它自己选，四层板它自己画，外壳它建模，固件它写，每块板一天内进入可制造状态，Diode 造回来零电气修改。

理论物理补上了两道黑洞 方向的开放题，结果已经挂了预印本。蛋白质那边，AAV 衣壳结构预测 34 个里做准 28 个。内部工程把关键生产服务从 Python 迁到 Rust，启动快了 26 倍。

还有一条容易被漏掉：误拦截率降了约 55%。前一代有个毛病，正常请求动不动被安全系统当成危险请求拦下来，这次官方说法是误伤砍了一半多。

模型还能扮演两种新角色：Advisor，让 Haiku、Sonnet、Opus 干活卡住了去问它；Orchestrator，它自己把小任务派给更便宜的模型。官方定位很明确：日常任务用 Opus 5.5，硬题往上切 Fable，简单题往下切 Sonnet 或 Haiku。

Mythos：同一个模型，换了一条裤子#

Fable 和 Mythos 是同一个底层模型。区别在护栏：Mythos 拆掉一部分网安和生物限制，只给审核过的机构，走 Anthropic 的 Cyber 和 Life Sciences 两个验证计划。

网安数据：CyScenarioBench 上 Mythos 5.2 是 76.3%，5.1 是 61.7%；一家安全公司复测，Mythos 确认的漏洞里每六个就有一个是他们测过的所有其他 frontier 模型全漏掉的。产品侧还有 Claude Security：Enterprise 客户可以让最强模型持续扫代码库、盯漏洞修复、通过 API 和 MCP 接进自家工具链。网安这条线从模型一直铺到了产品。

时点是另一层：CNBC 的报道里，这是 Dario Amodei 九月喊出「放慢 frontier 节奏」之后，Anthropic 放出的唯一 frontier 模型，而且距离公司那场可能很快落地的 IPO 只剩一周。模型是产品，产品要上台面。

API 降价 20% 是同一笔账的另一半：旗舰档往市场里放，整个价目表在变密。

Pro 白嫖额度怎么拿#

白嫖额度是官方促销，两个档两套规则，细则都写在官方支持文档里。

Pro 这一档：11-09 到 11-16 太平洋时间（北京时间 11-17 15:59 截止），每周额度最多 50% 可以花在 Fable 模型上，不额外收钱，再送一张免费重置卡。

重置卡作用在两个额度上。周额度里 Fable 那部分回满，其他模型花的不动；五小时额度整体回满，包括其他模型花的。官方例子：周额度用掉 80%，其中 Fable 占 50%、其他模型占 30%，点完重置回到 30%。

黑盒社区整理的玩法，例子更好算：周额度按 100 算，Fable 最多用 50。先用 Fable 用满 50，再用 Opus 用满 50，周额度见底；点重置，Fable 那 50 从已用量里扣掉，这一周实际可用 150，是平时的 1.5 倍。

两个细节别漏：官方自己写了 Fable 烧额度比其他模型快，别头三天就烧完；重置不可逆，取消或降档就作废。

Max 和 Ultra 不一样：Fable 本来就在周额度的 50% 里，这次不限时一周，只送卡。卡数按订阅时长：不到半年 1 张，半年到一年 2 张，一年以上 3 张，一直用到 2027 年 3 月 8 日。资格线是 11-09 太平洋时间上午 10 点前已有付费账单，订阅时长按首次付费算，中间断订过也认。

Pro 这周到头之后，Fable 在 Pro 计划上回到 usage credits 计费，没用完的 50% 不结转，没用掉的卡直接作废。也就是说 11-17 之前，白嫖额度就是白嫖，过了这条线 Fable 重新按量收费。

诚实边界#

「High 打平 Opus 满配、钱花一半」「Low 档 HLE 追平满配、钱不到十分之一」两个点，是官方发布文里图表的转录，本机没跑过模型。Max 档每任务 26.5 美元、High 档 62 分 9.08 美元、每任务 27.4 万输出 token，全部是外部公开数据，本文没有复测原始 eval。三十任务 26/26/25 那个数是社区开发者的自报复测，未逐条核源。基准表所有数字均为发布方自报，发布文明确写了没有任何外部机构审阅过这些数字。

五个常被问到的问题#

Fable 5.2 日常用值得吗？ 官方自己的推荐就是：日常 coding 和知识工作用 Opus 5.5，硬题才切 Fable。外部复测也站官方这边：三十个常规 coding 任务，5.2 和 Opus 5.5 都解 26 个。Fable 的价值在开放难题，不在替代日用。

Fable 和 Mythos 差在哪？ 同一个模型，两档护栏。Fable 带全套安全护栏，人人可用；Mythos 只走机构验证通道。做防御性安全工作的注意：Fable 的护栏会拦掉大部分网安任务，这是产品设定不是 bug，要 Mythos 通道。

Pro 卡怎么用最划算？ 先 Fable 用到 50% 上限，再 Opus 用到周额度见底，点重置，再 Fable。三趟合起来一周 150%。截止北京时间 11-17 15:59，重置不可逆，取消降档作废。

「快 30%」实不实？ 官方说法是比 5.1 快最多三成，另有一个 2.5 倍的 fast mode（价格翻倍）。外部反馈 5.2 解决了 5.1 又慢又溢出的毛病，但没有人复测出 30% 这个具体数。

IPO 背景是什么？ CNBC 报道：这是 Dario 喊「放慢节奏」后放出的首个 frontier 模型，IPO 最快下周启动。以上是背景，不是预测。

你是哪一派#

这次发布的核心是一道账：旗舰档贵一倍，但降档用能省钱。一派性价比派：日常九成任务跑 Opus 5.5，Fable 只用来 Low/High 档啃那 10% 的硬题。一派前沿派：Max 拉满当先锋，一道题 26.5 美元认了。

你手上现在跑的是哪一档，额度算得过来没有——站里说一声。

这道账可以转给那个一直把 Fable 开满档烧的同事——他缺的不是更强的模型，是降档的习惯。

常见问题

Fable 5.2 日常用值得吗？

官方推荐日常用 Opus 5.5，硬题才上 Fable。外部复测 30 个常规 coding 任务，5.2 和 Opus 5.5 都解 26，分差在开放难题（硬件、机器人、形式化）不在日用。
