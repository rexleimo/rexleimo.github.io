Winc 开仓：119 ms 起的 Rust 编辑器，AI 写完代码之后人只做 review

Rust 编辑器 Winc 2026-11-04 开仓（v0.1.452）：官方自报 119 ms 冷启动、十万行 52 MB，带词级 diff 与内置终端，定位是 AI 写代码之后人只做 review。

November 5, 2026 · 1 min · 97 words · 梦兽编程 -  |  English

Winc 在 2026-11-04 开了 GitHub 仓库，Rust 写的编辑器，当前版本 v0.1.452。作者给的定位很直白：AI 写完代码之后，人只做 review。

官方自报的四组数字（macOS 测量、未独立复现）：

  • 119 ms 冷启动
  • 52 MB 内存，开十万行文件
  • 220 ms 打开 1 GB 文件
  • 7.83 MB 空闲 RSS

结构上值得看的几处：渲染走 winit + 自研 CPU rasterizer（macOS 帧写 IOSurface）；没有 language server，跳转与引用是轻量本地实现；格式化外借 rustfmt、Prettier、Black、Ruff、gofmt。crate 拆成 winc-core / syntax / editor / config / i18n(Fluent) / app 加 xtask，i18n 用 Fluent，界面全英文加简中。协议 Apache 2.0，构建工具链 Rust 1.99.1。

开仓当日 47 颗 star、4 个 fork（GitHub API 实测），作者原话是「Vibe Coding 之后，一个 Winc 就够了」。产品页在 winc.si 与 winc.ovinc.tech。

常见问题

119 ms、52 MB 可信吗？

全是作者官方自报、macOS 测量、未独立复现：119 ms 冷启动、十万行文件 52 MB 内存、220 ms @1GB、7.83 MB RSS。引用时请保留这四个前提。

它是 AI 编辑器吗？

定位是 AI 写完代码之后给人做 review 用的编辑器：词级 diff 是主界面，带内置终端，无 language server（跳转/引用为轻量本地实现），格式化外借 rustfmt/Prettier/Black/Ruff/gofmt。

能装吗？

Apache 2.0，v0.1.452。macOS 11+（dmg）、Linux x86_64（AppImage/deb）、Windows 10 1809+（NSIS/MSI/portable zip），签名内应用更新。开仓当日 47 star（GitHub API 实测）。
