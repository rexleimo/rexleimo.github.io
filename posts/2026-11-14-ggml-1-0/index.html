ggml 首个 1.0：砍掉一批旧 API，RPC v9 直接拒绝不兼容对端

llama.cpp 底层张量库 ggml 首个 1.0：废弃 API 清空、RPC 协议 bump 到 v9 拒连、FP8 支持上线；本机 2 核 EPYC 干净构建中位 102.3s。全文与讨论沉在 BBS。

November 14, 2026 · 2 min · 219 words · 梦兽编程 -  |  English

2026 年 11 月 13 日，ggml-org 把 ggml 的版本号从 v0.29.0 直接抬到 1.0.0，同一天 llama.cpp 也发布了 1.0.0。

对本地推理生态来说，ggml 不是某个模型，而是底下那层张量库：llama.cpp 的量化算子、各硬件后端的 kernel，全都长在它的 C API 上。纯 C/C++ 无依赖，跨 x86、ARM、RISC-V、LoongArch、PowerPC、s390x 和 WebAssembly，量化格式覆盖 2-8 位整型外加 MXFP4/NVFP4 微缩放格式。

1.0 锁住了什么#

Hugging Face 官方博客把话写直了：llama.cpp 和 ggml 从今往后按语义化版本走，API 和 ABI 的破坏性变更只允许出现在主版本号里。一个用了 3.5 年的库把接口锁死，下游拿 libggml 自己拼推理管线的团队，才第一次有资格把「升级不炸」写进发布流程。

1.0 的砍刀落在废弃 API 上：ggml 清理 deprecated 公共接口，删掉遗留的 DIAG_MASK_INF/DIAG_MASK_ZERO 两个算子；RPC 协议升到 v9，加载更快，端点不可达或握手失败时直接失败而不是挂住——对端版本对不上直接拒连，兼容性问题从运行期挪回连接期。同一天发的 llama.cpp 1.0 是配对的刀口：llama.h 删掉 llama_set_warmup 加 35 个 deprecated 函数，NextN/speculative 那套 API 从 llama-ext.h 提进 llama.h。

加了什么#

FP8 是 1.0 里最重的新能力：CUDA 端支持 OCP FP8，MMQ 里把 NVFP4 的 gate/up 矩阵乘与 GLU 熔成一个 kernel；llama.cpp 1.0 这边接上了 FP8 KV 缓存（-ctk/-ctv f8_e4m3），KV 缓存的内存账能再砍一刀。YaRN truncation 也开放成可配置（ggml_rope_set_truncate），OpenVINO、SYCL、Vulkan、WebGPU、RPC 五个后端都跟上。

各后端的性能账分开记：CUDA 新增 few-row 量化 matmul（batch 2-24）与 MoE 融合；Metal 把可融合 MoE 节点组塞进单个 command buffer；Vulkan prefill 走 Intel FlashAttention 路径；SYCL 上设备侧 MoE 调度器；WebGPU 新增 batched tensor API 与一组新 kernel；Hexagon 补 Q5_0/Q5_1 与 conv_3d。

本机实测#

环境是 2 核 EPYC 9354P（32 核芯片只分到 2 个 vCPU）、无 GPU、CMake 4.4.4 + clang 18.1.3。克隆 v1.0.0 tag（417a024）做三次干净构建：109.3s / 102.3s / 102.0s，中位数 102.3 秒。ctest 全套 21 项全过，总耗时 9.61 秒。单独跑 test-backend-ops -b CPU -o MUL_MAT 正确性套件，225.9 秒后 1/1 backends passed——1.0 把精度门控写进了测试，全参数量化校验在 2 核上跑满一轮要 3 分半。

诚实边界#

本机无 GPU：CUDA / Metal / Vulkan / SYCL / OpenCL / WebGPU / Hexagon 全部后端未复现，release notes 里的性能改进按官方自报，没有独立验证。没有做 v0.x 与 v1.0.0 的同口径对照（tag 之间公共 API 有删改，对比代码没法共用同一套构建），只测了 v1.0.0 自身。

常见问题

ggml 1.0 会 breaking 现有的 llama.cpp 程序吗？

llama.cpp 1.0 删掉了 llama_set_warmup 等 35 个 deprecated 函数，用旧 API 的跟着换；只用 libllama 公共接口的，升级后编译报错就是清单。

RPC v9 的旧对端还能连吗？

不能。v9 直接拒绝不兼容对端，握手失败即终止，这是 1.0 刻意的行为。

各 GPU 后端的性能提升实测过吗？

本机 2 核 EPYC 无 GPU，CUDA/Metal/Vulkan/SYCL/OpenCL/WebGPU/Hexagon 全部未复现，数字按官方 release notes 自报口径。
