Rust off Rails：一个 0 行框架代码的 Web 栈，给 AI 写代码用的

Rust off Rails 发 60 个 Markdown 文件、0 行框架代码：约定写在散文里，agent 照着写全部代码。Axum + SeaORM + htmx 的选型我拆了一遍，HN 104 条里的两条高赞也引了。

October 22, 2026 · 2 min · 232 words · 梦兽编程 -  | 

这周 Rust Web 圈出了第三种路线。前两篇（10-05 Topcoat、10-18 Proa）都在测「Rust 框架本身多快」，Rust off Rails 干脆不发布框架代码：它发布的是判断。

官网一句话：「A web framework that ships zero lines of code.」

它是 60 个 Markdown 文件，规定一套被认可的全栈：crate 选型、文件布局、命名、错误处理、测试。agent 照文档写代码，人写意图——product/ 里的 spec、interview 里的回答、对话里的反馈，不写代码。

栈本身（官网 docs 逐字摘）#

  • Axum on hyper——二进制即 Web 服务器（HTTP/1.1 + HTTP/2，不需要 nginx 或 app server）
  • Tokio + SeaORM——本地 SQLite、生产 Postgres，同一套代码
  • Tailwind
  • 前端开应用时定死四种模式之一：
    • htmx（默认）：Askama 编译期模板 + htmx，无 Node，可选 React/Svelte islands
    • inertia：React 或 Svelte 页 + 生成式 Inertia 适配器
    • spa：Vite SPA（React Router / SvelteKit）+ JSON API
    • api：无 UI，进行中

对比 10-05 发 Topcoat 那篇的结论——Tokio 系全栈框架的价值在「双栈」（Rust/JS 双表达式语言）；这篇的价值在「零决策成本」：ORM 不让 agent 选，模板引擎不让 agent 选，连目录结构都写死了。HN 上 theptip 那句高赞说准了：「大部分评论都在阴阳，这货实际做的事是——」然后贴了上面这段清单。

创始规则：所有代码由 AI 写#

官网把这条写在最前面：Rust、SQL、HTML、CSS、TypeScript、Dockerfile，全由 agent 写。人类只出意图。它自述「Markdown 即框架」：别家框架发布库，它发布精确 spec；job queue、session、Inertia 适配器都渲染成你应用里你拥有的代码——不是黑盒依赖。

官网展示了一段 7 个 prompt 建 Kanban 的 agent session：/offrails:new bookshelf 起，interview 问账号方案/数据归属/前端模式，出 plan，生成迁移 + 模型 + 控制器 + 71 个前端文件，clippy -D warnings 全过，142 个 nextest 在 SQLite 和 Postgres 18 上各跑一遍全绿。

和本系列前两篇的关系#

Topcoat（10-05）Proa（10-18）Rust off Rails（本篇）
形态全栈框架（双栈）SSR 框架（多目标渲染）0 行框架代码 + 60 份 Markdown
卖点首构建 3m57s / 增量 13.6s渲染比 React 快 35 倍（窄场景成立）agent 零决策成本
面向人 + 框架人 + agent 双目标纯 agent（人只写 spec）

争议（HN 75 分 45 评，挑实的）#

  • theptip（高赞）：认可「stack skill」价值，但不买「markdown 为真源」的脚手架账——他更贴近 agent harness 工作，迭代对话完再落文档。
  • 反方集中在：约定写死在散文里，改约定的成本比改代码高；agent 时代框架的价值本该是「可机读 + 可热更」，Markdown 反而落后一拍。
  • 官方回应逻辑：「Inconsistency is the enemy, not imperfection」——一致性比正确性优先，agent 场景下每次即兴决策都是不一致的来源。

诚实边界#

  • 本机没跑：142 测试在 SQLite/Postgres 双库全绿是官网展示 session 的数字，未独立复现；官网也没给可下载的最小示例仓（装法是一行 curl，脚本拉 60 份 Markdown）
  • 项目很新（官网 self-reported，HN 75 分还在爬），star 数、贡献者数都还没起量
  • 「AI 时代 opinionated」是它的自我定位，争议还没定论，这篇按「出现了一条新路线」写，不下「比 Topcoat/Proa 好」的结论

常见问题

它到底是什么？

一套 Markdown 规范 + 脚手架二进制（bin/setup、bin/dev），规定好 crate 选型、文件布局、命名、错误处理、测试。它不发布库代码，job queue / session / Inertia adapter 这些渲染成你应用里你自己拥有的代码。安装是一行 curl 或 Claude Code 的 /plugin marketplace add。

和 Topcoat、Proa 什么关系？

10-05 的 Topcoat、10-18 的 Proa 都是「Rust Web 框架实测」：测它们的渲染速度和首构建。这篇是第三条路——不发布框架代码本身，发布判断：所有 agent 本该即兴做的选择，预先做掉写进文档。

前端怎么选？

四种模式开应用时定死：htmx（默认，Askama 编译期模板 + htmx，无 Node）、inertia（React 或 Svelte 页 + 生成式 Inertia 适配器，Rails 式服务端路由）、spa（Vite + React Router/SvelteKit + JSON API）、api（纯后端，进行中）。

本机验证了吗？

没跑应用。本机 2 核无 GPU，数字全部引自官网展示 session（142 测试在 SQLite 和 Postgres 18 各跑一遍全绿）和官网自述，未独立复现。
