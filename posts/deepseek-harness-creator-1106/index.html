DeepSeek 官方甩出 7 套插件提示词：一句话搓出视频剪辑工作台

DeepSeek Harness 官方「创造模式」玩法指南：一句话提需求，Agent 读插件开发文档、写代码、装进自己的工作界面，官方顺手放 7 套示例提示词（3D 展厅 / Transformer 交互游戏 / 视频剪辑工作台 / 海报 / 论文阅读 / 界面换肤 / Token 计费板）。真正值得盯的不是「AI 会做东西」，是 GUI 扩展层的官方化和权限确认模型。

November 6, 2026 · 3 min · 538 words · 梦兽编程 -  | 

DeepSeek 官方刚丢出一份「创造模式」玩法指南，顺手放出 7 套可以直接抄的插件提示词。里面最能打的一条，是让 AI 现场开发一套视频剪辑工作台：上传素材、拖动时间线、自然语言指挥剪辑、一键导出，整套流程官方演示里全跑通了。

这不是一条「AI 好厉害」的标题党素材。它值得单独拆开看，因为 DeepSeek 这次动的不是模型能力，而是把自己应用的扩展层开放了出来。

先说清楚：新鲜的不是「AI 写代码」#

AI 能写代码，2024 年就在刷屏，没人会真信「会写代码」本身是新闻。

DeepSeek 这次的新鲜点，是把「造插件」做成了官方支持的一等玩法，给了固定的入口叫创造模式（Creator Mode）；官方自己写了 7 套提示词当示例，把「能搓出什么」的边界直接标给你看；插件能装进 Harness 自己的工作界面，改的是宿主应用的界面，不是隔空写个脚本。

AI 写的代码有地方落、有地方跑、有地方给你装，还带权限确认。这才是要盯的东西。

创造模式动了哪一层#

把整个链路捋一遍：你在聊天框用一句自然语言提需求，Agent 去读 Harness 的插件开发文档，写插件代码，跑起来，把新功能挂到侧边栏或工作台里，安装前还有一次权限检查。

这条链路里最容易被忽略的环节是「读开发文档」这四个字。它意味着官方把插件怎么做、能调什么、界面往哪挂，写成了一套机器也能读的规范。

过去你给 AI 提需求，它写的是「一段能跑的代码」；现在它写的是「一个符合宿主规范、能挂进界面、能过权限检查的插件」。从交付一段代码，到交付一个能装进应用的组件，这是扩展层的官方化。

7 套官方提示词，能搓出什么#

官方给的 7 条提示词，基本是能力清单：3D 建筑展厅、Transformer 交互游戏、视频剪辑工作台、海报设计工作台、论文阅读器、界面换肤、Token 计费板。

每条都是完整英文提示词，直接复制进创造模式就能跑。下面把原文照录，一条配一句点评。

3D 建筑展厅：侧边栏挂个 3D 视图，随手渲染埃菲尔铁塔、长城、故宫加一座自选建筑。

Create a DeepSeek Harness plugin with a left sidebar entry that renders 3D models of the Eiffel Tower in Paris, the Great Wall of China, the Forbidden City, and one more famous building of your choice.

这条是入门样板：需求一句话，交付一个可视组件，验证「能不能挂侧边栏」。

Transformer 交互游戏：把大模型内部的计算过程做成能上手操作的 3D 演示，专门解释数据怎么流动、注意力怎么算。

Create a DeepSeek Harness plugin with a left sidebar entry: an interactive 3D demonstration game that helps me understand the computation inside a Transformer. Keep the panel title and toolbar clear of the native macOS window buttons so they do not overlap.

这条最容易被低估。它不炫技，是把论文里的架构图变成了能拖的 3D 场景，而且提示词里还写死了「别和 macOS 窗口按钮重叠」这种工程细节。

视频剪辑工作台：上传多个视频、时间线剪辑、自然语言指挥改片、导出。

Create a video editing workbench accessible from the conversation, using the dark interface and familiar interactions of established video editors. Support uploading multiple videos, editing, and exporting. Place a large preview at the top and a timeline below for importing and editing clips. Also let me import and edit videos through natural-language requests in the conversation.

7 条里最重的一条，官方单独给了演示。下面专门拆。

海报设计工作台：自带 Harness 官网的动态背景纹理和英文字体，标题、文案、背景色可自定义，默认标题就是「Everything is a plugin」。

Create a poster design workbench plugin accessible from the conversation. Use the shader background pattern and English font from the DeepSeek Harness website. Let me customize the poster title, text, and shader colors. Keep the default page minimal, with no unnecessary subheadings or information. Set the default poster title to "Everything is a plugin".

默认标题这句值得记一下，它本身就是一句产品宣言。

论文阅读器：挂在右侧边栏，上传 PDF 后保留原文排版、字体、图片，划选文字就能高亮、做笔记、或者让 AI 解释。

Create a paper reader accessible from the right sidebar. Let users upload papers and preserve the original layout, fonts, images, and all other content without any loss. When text is selected, show a floating menu with options to highlight it, add a note, or ask about it in the conversation. Match the default question prompt to the interface language.

科研场景的刚需：读论文时连阅读器都能自己定制。

界面换肤：让 AI 给整个 Harness 应用换一套外观，五套风格任选，其中一套是像素风。

Create a DeepSeek Harness plugin with a left sidebar entry that lets me change the look of the entire app. Offer five different styles to choose from, with a pixelated look as one option.

改的是宿主自己，这条单独拎出来看。

Token 计费板：基于你真实对话数据，一屏看清 token 消耗、对话次数、预估费用、预算、用量时间线、单次对话成本，外加 CPU 占用。

Create a statistics plugin based on my actual conversation data. Show total token usage, conversation count, and estimated costs and budget based on token usage. Include a token-usage timeline, usage and costs for individual conversations, and CPU activity and utilization.

这条是官方在放一个信号：成本可观测，是 agent 运营绕不开的需求。

视频剪辑工作台：为什么值得单独拆#

官方给这条单独配了演示，因为它最像「生产力软件」，而不只是一个花活。

![DeepSeek 创造模式搓出的视频剪辑工作台（官方演示 GIF）](/images/posts/deepseek-harness-creator-1106/p3-video-editing.gif

把这条提示词拆开，规定得很细：界面要沿用成熟剪辑工具的深色风格和操作习惯；要能传多个视频；上方大预览、下方时间线的布局；还能直接在对话里用自然语言让 AI 导入素材、改视频。

用自然语言指挥剪辑这条最关键。它说明交付的不是「一个会剪辑的按钮」，而是把「用自然语言指挥剪辑」这个动作本身做成了插件的一部分。上传、预览、时间线、导出这些原本要人动手的环节，被一句话的需求整体接管了。

这条最能说明扩展层开放到什么程度：AI 不只是生成一段剪辑脚本，而是把剪辑工作台整个塞进了对话界面。

界面换肤与 Token 计费板：两个「元」案例#

剩下 7 条里，最有意思的不是最炫的，而是最「元」的两条：一条改宿主自己的界面，一条盯宿主自己的成本。

![Harness 界面换肤插件，多套风格可切换（官方演示）](/images/posts/deepseek-harness-creator-1106/p6-ui-restyle.png

界面换肤这条，改的是 Harness 应用本身。Agent 不光给你做功能，还能重新设计它的壳。提示词里「五套风格、其中一套像素风」这种约束，说明它能接受审美层面的指定，而不只是功能层面的。

![Token 计费板：消耗、费用、CPU 占用一屏看全（官方演示）](/images/posts/deepseek-harness-creator-1106/p7-token-stats.png

Token 计费板这条更值得琢磨。它统计的是你真实对话产生的 token、费用、预算、单次对话成本，还带 CPU 占用。官方专门给这个做插件，等于亲口承认：跑 agent 的人，需要一屏看懂自己花了多少钱、资源吃在哪个对话上。

这两条放在一起看，指向同一个判断：DeepSeek 把「agent 该管什么」的边界，从「帮你干活」延伸到了「管住 agent 自己」。

三步上手，门槛低到什么程度#

官方给的上手路径很短，三步：

打开 Harness，新建会话，选「创造模式（Creator Mode）」；把想试的提示词粘进对话框发出去，让 Agent 读开发文档、写插件、跑起来；检查生成结果和安装权限，不满意就继续提修改要求。

![三步上手：开 Harness、选创造模式、粘提示词（官方演示 GIF）](/images/posts/deepseek-harness-creator-1106/three-step-setup.gif

整个门槛就是「会粘提示词」。这也是为什么官方敢一口气放 7 套示例——它希望你零门槛开始搓。

官方自己承认的限制#

这条要老实交代，因为它直接决定你该有多高的预期。

官方原话：部分演示插件经过多轮对话修改完善，单凭一条提示词未必能完全复现视频效果。

翻译成人话：官方演示里那些成品，不是一次性生成，是人跟 Agent 来回磨出来的。你拿同一条提示词冷启动，能搓出个能用的骨架，但离演示里那个精致版本有距离，需要你自己继续多轮迭代。

本文没有在本机跑 Harness 复现任何一条，以上关于「能搓出什么」的判断，都基于官方教程和官方演示 GIF 的转述，不是实测。

反套路判断：真正值得盯的#

回到开头那个问题：一条新闻，真正值得记下来的到底是什么。

「AI 会写代码」不新鲜，新鲜的是官方把扩展层开放了，且把它做成了带权限确认的一等玩法。AI 写的东西有地方装、有地方跑、有检查点，这才从「炫技」变成了「能力」。

7 套提示词表面是教程，实际是一份能力清单：它告诉你这套扩展层现在够得着 3D、视频、设计、阅读、界面定制、成本统计这些场景。清单本身比任何一条提示词都更有信息量。

而界面换肤和 Token 计费板这两条，暴露了官方对「agent 该管什么」的想象：不止干活，还要能重新设计自己、管住自己的成本。这是比单个插件更长期的信号。

一句话收：DeepSeek 这次把「agent 造 GUI」从社区野路子，变成了官方带权限模型的扩展层——盯该盯这个，而不是盯「一句话搓个玩具」。

五个常被问到的问题#

创造模式和普通对话有什么区别？ 入口不同。普通对话是问答；创造模式选上之后，Agent 会去读插件开发文档、写代码、装进界面，交付的是一个能挂进 Harness 的插件，而不是一段文字。

那 7 套提示词怎么拿到？ 官方指南里直接给了完整英文提示词，复制进创造模式的对话框就能跑。本文把 7 条原文都照录了，直接抄。

一条提示词能不能一次搓出官方演示的效果？ 官方明确说，部分演示插件是多轮对话磨出来的，单条提示词不一定完全复现。冷启动出骨架，精致效果靠你自己继续迭代。

这些插件是跨平台的吗？ 官方演示在 macOS 上跑，有提示词明确提到「别和 macOS 原生窗口按钮重叠」。跨平台支持本文没有实测依据，不展开。

Token 计费板用的真是我的数据吗？ 官方提示词写的是基于「my actual conversation data」统计，即你自己对话产生的真实 token 和成本。具体怎么取数、准不准，官方没有展开说明。

你是哪一派#

把「agent 该不该能改自己的界面」摆到台面上，能分出两派。

一派觉得该管住：宿主界面被 AI 随手改，权限边界一旦模糊，出问题谁负责说不清。另一派觉得放开才好玩：agent 能重设计自己的壳、能管自己的成本，这才叫把 agent 当「运维对象」而不是「一次性工具」。

你站哪边？评论区说说，你是「管住派」还是「放开派」。攒够一批，下一篇把「agent 改宿主界面」的权限模型单独拆开。

资料出处#

本文素材来自 DeepSeek Harness 官方「创造模式」玩法指南，经量子位原创、不会笑青年公众号转载（文末营销段落未采用）。7 套提示词为官方原文照录，视频剪辑工作台、界面换肤、Token 计费板等画面均为官方演示 GIF/截图。

本文未在本机实测 Harness，所有「能搓出什么」的描述为官方教程与演示的转述，未独立复现。

转给那个还在手动切模型、手动算 token 花了多少的同事——他缺的不是工具，是知道官方已经把这些都做成了一句话的事。
