前端动效这事，这两年悄悄换了个打法：不再是每个框架各写一遍，而是同一套效果被官方逐个框架移植，源码直接进你的仓库，参数交给 AI 改。React Bits 一个仓库就拿到 50,489 星、216 个组件，Vue Bits 和 Svelte Bits 作为官方 port 跟进，前端三大框架第一次被同一套视觉语言凑齐。

这篇不吹「又多了个动画库」，要说的是：为什么「源码进项目 + AI 改参」这件事，现在成了 React、Vue、Svelte 三家的默认工作流。所有数字都标了出处，可逐条核对。

为什么值得写：不是又一个动画库#

真正值得记一笔的，是 Ant Design、Element Plus 那类「组件库」和 Bits 这类「效果库」的方向差异。前者给你表格、表单、后台管理件，解决的是「功能」；Bits 从头到尾只解决一件事——让你的网站变帅。官网把组件分成五类，数量钉在这：文字动画 33、动效 38、组件 48、微交互 34、背景 63，合计 216（react-bits 仓库 README 的官方分项）。这套「源码型」库也没停更：react-bits README 内嵌的活动面板显示近 30 天还有 16 次 push，top contributor 至今是作者本人 DavidHDev。

三大框架被「一锅端」了#

这三套 Bits 不是三个团队各写一遍，都是同一个作者 David Haz（GitHub 的 DavidHDev）名下的官方 port：React 那套 2024 年 8 月开仓，Vue 和 Svelte 都在 2025 年 7 月分叉出去。

星数差两个数量级是纯时间差：React 50,489，Vue 4,622，Svelte 391，React 先跑了约一年。但效果本身是同一批：Aurora、Ballpit、Magic Rings，React 官网能拿到的，另外两家基本都能拿到；两家各挂 130+ 组件，React 这边 216。

三个官网各自独立，但长同一套视觉语言。React 侧是 reactbits.dev：

Vue 侧是 vue-bits.dev：

Svelte 侧是 sveltebits.xyz：

源码进项目，不是黑盒依赖#

三家的安装姿势一样，也是这套生态真正的设计选择：不给你一个黑盒 npm 包，而是把组件源码整个拷进你的仓库。三个官方渠道都能拉源码——shadcn CLI、jsrepo、或者直接打开组件页的 Code 标签手抄。每个组件还带四种口味：JavaScript 或 TypeScript，配 CSS 或 Tailwind，用后缀选。

落到命令就三行：

npx shadcn@latest add @react-bits/SplitText-TS-TW   # React
npx jsrepo add https://vue-bits.dev/r/Aurora.json    # Vue
npx jsrepo add https://sveltebits.xyz/r/aurora.json  # Svelte

进来之后它就是仓库里的普通文件，Vue 官网原话「The code is yours」：组件直接基于 ogl、GSAP 这类底层库，不挂 vue-bits 依赖，官网哪天没了，拉进来的照样能跑。

交给 AI 改，是现在的主线用法#

React Bits 接了 shadcn 的 MCP server，配一次之后 Claude Code、Cursor 这些 agent 能替你查组件、拉源码；Svelte 官网挂了 AI-Ready 标签。配合「源码进项目」，做效果就三步：官网挑效果、一条命令抄进仓库、把配色交互丢给 AI 改好直接进产品。以前做一个高级动效折腾一下午，现在一句话的事。

几个经典效果，点名记一下#

不用全背，记这几个就够用了。背景类最出效果的是 Aurora（动态极光）和 Ballpit（满屏带物理碰撞的 3D 小球，鼠标可交互），放在首屏视觉冲击最强。交互类有 Blob Cursor、Splash Cursor、Pixel Trail、Magic Rings、Antigravity（3D 粒子场，被鼠标排斥）。文字类多到可以按场景挑：Blur Text、Shiny Text、Decrypted Text、Glitch Text、ASCII Text，Svelte 官网还单列了 Dot Field、Line Waves、Metallic Paint。Vue 官网拿 ColorBends（流动弯曲的彩带）直接做首页展示。

它不解决什么#

动效库解决的是「视觉层」，不是「逻辑层」。表单校验、路由、状态管理这些还是你原来的活，Bits 一根手指都不碰。另外两件要心里有数的事：React Bits 已经开了 Pro 付费版（整页模板加 Agent Kit，一次买断、源码归你、含后续更新），但核心那 216 个组件继续免费，免费版就够绝大多数官网用了。还有一件：AI 帮你改出来的东西，动效类组件在低端机上的掉帧问题要自己验一遍再上线，别直接信 AI 的产出。

三个官网，直接收藏#

reactbits.dev、vue-bits.dev、sveltebits.xyz。React 党点第一个，Vue 党点第二个，Svelte 党点第三个，都免费、都能直接抄源码。

常见问题#

三大框架的组件是完全一样的吗？ 不是逐行相同，是同一套视觉效果被官方逐框架移植，Vue 侧遇到 React 独有的依赖（比如 framer-motion）会换成等价物（motion-v），目标是「看起来和 reactbits.dev 上一致，或尽量接近」。

我项目是 Nuxt / Vite / Astro，能用吗？ Vue Bits 官网写了支持 Vite、Nuxt、Astro、Vitesse，按对应脚手架装就行。

是不是要装一个大 npm 包？ 不用。它反过来：不装那种一揽子整包，单个组件源码进你仓库，用多少拉多少，Svelte 侧每个组件就是一个单独的 .svelte 文件。

免费吗？有没有坑？ 三家核心组件都免费。要留意的是许可证是 MIT + Commons Clause（带一条商用限制条款），做闭源商业产品前把许可证读一遍；React 侧另有一个自愿付费的 Pro 版，不强制。

AI 改参真的靠谱吗？ 组件本身是可定制的源码，AI 只是帮你调 props、换色、改交互。产出要在目标机型上自己验，尤其低端机的掉帧，别拿 AI 的输出直接当成品上线。

诚实声明：star 数取自 GitHub API（DavidHDev/react-bits、vue-bits、svelte-bits），组件分项数取自 react-bits 仓库 README，Vue/Svelte 的 130+ 取自两个官网首页快照，均为 2026-10-28 抓取；安装命令与各官网的 AI 工具支持情况以官方文档为准，笔者未逐一在本机跑通全部命令。
