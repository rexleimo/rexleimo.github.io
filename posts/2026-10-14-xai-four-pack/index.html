再见 Codex：15 刀拿下 Cursor + Grok + X 四件套，马斯克把比赛打完了

一位博主暂停了用了一年多的 Codex（烧掉近 100 亿 token），转投马斯克的 15 刀 xAI 全家桶：一次订阅，同时拿到 Cursor、Grok、Grok Bot、X 四件套，外加 OpenAI 自家旗舰模型随意切。这篇是视频口播稿，把这笔账、那个 megpie 转发的骚操作、以及它藏着的「模型不再被绑定」的信号一次讲透。

October 14, 2026 · 2 min · 214 words · 梦兽编程 -  | 

开场：一个博主停掉了用了一年多的 Codex#

大家好，我是梦兽编程。

今天这条，来自一位做 AI 实践的博主的真实操作：他把用了一年多、烧掉将近 100 亿 token 的 Codex 停了续费，成了「光荣的 Free 用户」，转头把预算押到了马斯克这边——15 刀，拿到 Cursor + Grok + Grok Bot + X 的四件套。

标题写得很直白：再见 Codex，马斯克把比赛打完了。

我为什么认真看这条？因为它不是「我换了个更便宜的订阅」这种个人选择，它踩中了 2026 年 AI 工程里一个正在发生的转向——模型不再被绑定。这条判断，比那 15 刀本身值钱。

一、Codex 停了之后，他没歇着：megpie 把壳接上别的模型#

先说他把停订后的 Codex 拿来做了一件事，这也是这条里技术密度最高的一下。

他用了 yetone 大佬开源的一个工具，叫 megpie——一句话：给你任意一个 agent，配任意一家供应商的模型。

操作很傻瓜：

  • 给停订的 Codex 配上 DeepSeek V4.1 Flash，重启，Codex 继续跑，底层换成了 DeepSeek；
  • 同一套配置，把供应商换成他最近很上头的 Gemini 3.8 Flash，也能接。

注意这里有个他自己也点名的坑：用 Gemini 走这条转发有封号风险，他已经被封过一次，所以没继续。能接，但不一定划算——这就是「路由自由」的另一面：供应商侧的条款你也得认。

把这一段翻成一句话：agent 是壳，模型是可插拔的引擎。壳还在，引擎随时换。谁便宜、谁强、谁不封号，就切谁。

二、15 刀四件套，到底含什么#

真正让他「走不动道」的，是马斯克那一次订阅。

15 刀，同时解锁四样东西：

  • Grok：xAI 系的聊天模型入口；
  • Grok Bot：作者原话，「我试过 ChatGPT 的 Dot 没觉得惊艳，但大家公认 Grok Bot 才是最强的，这次能好好体验」；
  • X 高级会员：X 四件套里最显眼的那一块；
  • Cursor 会员：这个是惊喜点。

作者付款进 Cursor 一看，发现里面直接挂着各家旗舰模型：

模型归属
Claude Opus 5.5Anthropic
Gemini 3.8 FlashGoogle
Grok 4.7xAI 自家
GPT-5.6 SolOpenAI

一次订阅，同时拥有四家旗舰。 作者的评价很直接：「无脑充 15 刀的 Premium，已经很值得。」

落地细节也顺手给了：

  • 国内友好，持双币信用卡就能付；
  • 付款后务必去 Grok 设置里把所有账号合并，点 Get started，四件套才一起亮起来。

三、这笔账，值不值#

把数字摆一起。

项目原状现状（15 刀方案）
模型供应商OpenAI 独家（Codex）四家旗舰 + 可路由多供应商
月成本Codex 订阅（一年 100 亿 token）$15/月
壳（agent）绑定 OpenAI壳不变，引擎可换（megpie）
风控无Gemini 转发有封号记录，需自担

我不替 100 亿 token 的重度用户下结论——你一年烧的量级和 15 刀不是一个量级。但有一个方向性是成立的：

当「旗舰模型 + 编辑器 + 助手」能被一个低价订阅打包，模型的边际成本就被拉平了。 拉平之后，真正稀缺的东西从「我有哪家最强模型」变成「我能不能把最合适的模型，最省事地接到我的壳上」。

这就是标题那句「把比赛打完了」的准确含义：拼单家旗舰的时代，正在被「壳 + 任意引擎 + 低价全家桶」的组合打穿。

四、三条我得说清楚的事#

把「我核过的」和「我没核过的」分清楚，别把没验证的说成我验过：

  1. 100 亿 token、停订、15 刀四件套、四家旗舰——都是这位博主自述，他发的原帖里带截图；原帖里还有几张操作截图（「你发现了什么」那种），原图我没拿到，没做独立核验，以他原帖为准。
  2. 模型版本号（Opus 5.5 / Gemini 3.8 Flash / Grok 4.7 / GPT-5.6 Sol）——原帖原样照录，我没逐一去各家官网对版本，别当官方口径。
  3. megpie 与封号风险——工具名、作者 yetone、Gemini 转发被封一次，都是博主自述，我没复跑，自担合规。

一句话收口：这篇是「改述自外文/外网长文」，数字与操作均出自原作者原帖，我只做了结构重排与判断补白，没有独立复现。

结尾：这是信号，不是让你去砍订阅#

回到我自己。这条最大的信息量不在「马斯克便宜」，在那句「模型不再被绑定」。

我自己的日常，壳是固定的（我跑的这套 agent 环境），引擎是可换的——今天挂 DeepSeek，明天挂 Gemini，哪个划算切哪个，跟博主用 megpie 接 Codex 是同一个道理。

所以这条我判断成一个信号：

  • 对重度用户：别为「独占某家最强模型」长期锁死，保留可路由的能力比锁单一供应商更抗风险；
  • 对刚入门的人：15 刀全家桶是低门槛试错的好入口，四家旗舰一次摸一遍，比单点订阅划算得多。

转给那个还在纠结「订阅哪家 AI 才不亏」的同事——答案可能不是「选最强」，是「别被绑定」。

常见问题

15 刀 xAI 四件套到底含什么？

一次订阅同时解锁 xAI 系产品：Grok、Grok Bot、X 高级会员，以及 Cursor 编辑器的会员档；作者实机还看到 Cursor 里直接挂上 Claude Opus、Gemini、GPT-5 系列各家旗舰模型。四件套以官方结账页为准。

megpie 是干什么的？

yetone 开源的 agent 模型路由工具：给任意 agent（Codex/Claude Code 等）配任意供应商的模型。作者用它把停订后的 Codex 接到 DeepSeek V4.1 Flash 和 Gemini 3.8 Flash 上继续跑，绕开「订阅一停就废」的问题。

国内能订阅 xAI 吗？

作者实测国内用户友好，持双币信用卡即可在 xAI 侧完成付款，付款后按官方提示在 Grok 设置里合并账号（Get started）。合规与风控责任自担。

为什么要停掉 Codex？

不是因为 Codex 不好，而是「模型不再被绑定」：agent 壳 + 可换的模型供应商，谁便宜谁强切谁。15 刀把四大厂旗舰同时摆到桌前，边际成本被拉平，长期订阅的独占价值被稀释。
