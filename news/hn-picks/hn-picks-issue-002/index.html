① Ollaya：把「Jev 决策模型」做成 Ollama#

LLM 不是万能胶水——很多任务不需要逐 token 生成，一个单遍前向就够。Ollaya 就是冲着这点去的：把 Convai 的开源 Laya 决策模型搬进本地，体验照抄 Ollama（一条 ollaya run laya 拉起来），并且直接兼容 TypeSafe 的 API——官方 Python SDK 改一个 TYPESAFE_BASE_URL 就能指到本地。官方给出的对照数字：RTX 4090 上五个类型化问题端到端约 8ms，托管的 TypeSafe API 中位 236–276ms，差 30 倍，而且数据不出机器。144 条评论里吵得最凶的是「决策模型是不是又一个营销壳」，反对派要的是独立基准。

② LLM 时代如何继续享受编程#

Haskell 论坛一个万字长文，作者开宗明义：100% 纯手写、无 AI 辅助，怕被误会。核心不是反技术，是反焦虑——AI 疲劳、代码质量滑坡、以及「没有编程技能但有大 Claude 账号的人」竞争带来的真实压力。他的处方很老派：把编程当手工艺重新认领，享受「把想法一步步变成能跑的机器」这个过程本身。HN 评论区 216 条，吵的不是技术细节，是「写代码这件事还值不值得用旧方式享受」。

③ Ask HN：谁家公司还靠 DOS 机器活着#

论坛考古现场，比题目还精彩：某核电站用 Windows NT 4.0 跑到 2007 年，任务是「报告控制棒插没插」——只报告，不控制；某波兰修车店用 Commodore 64 跑车轮校准；有人用 dBase 3.x 当前台点单机，「零动机升级」，但已经把它搬进 qemu 了。还有 FTSE 100 公司一台 1993 年的 SCO UNIX，跑在 100% 隔离网络上，「一颗没人敢拆的定时炸弹」。所有人都在卷新框架，评论区在晒 30 年前的绿屏——这是本期最解压的一屏。

⑥ Reladraw：位置你自己定的图表语言#

Mermaid/PlantUML 的自动布局永远不满意？这个图 DSL 让你写死每个节点放哪、连线从哪侧绕过去；画不出来的组合会拒绝并告诉你原因。一份反自动布局宣言，开源（262 star），仓库里还自带了 .claude/skills/——AI agent 读着它画图。
